# チケット32: パズルセレクトのサムネイル表示とクリア状態表示の分離・デバッグパネル整理

## 目的

パズルセレクト画面で、クリアフラグがないにもかかわらず完成サムネイルが表示されており、見た目上「クリア済み」に見えてしまう問題を整理する。

サムネイル表示とクリア状態表示は別の情報として扱う。

```text
サムネイル:
- 問題データの完成図プレビュー
- 未クリアでも表示してよい

クリアフラグ:
- ユーザーごとの進行状況
- CLEAR表示、クリア数、クリア済み装飾にのみ使う
```

また、現在パズルセレクト中央付近に表示されている開発用データメニューは、画面を圧迫しているため、右上などに小さく畳めるデバッグパネルとして移動する。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\data.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. サムネイル表示とクリア状態を明確に分離する

パズルセレクトの表示ロジックで、以下を別々に扱う。

```text
thumbnail:
- 問題データから生成した完成図
- puzzle.thumbnail または grid から生成

clearState:
- ユーザーごとのクリア状況
- localStorage / userData / server user file などから取得
```

注意:

- サムネイルがあるだけでCLEAR扱いしない
- クリアフラグがない場合はCLEARバッジを出さない
- クリア数にも含めない
- クリア済み特有の装飾を付けない

### 2. 未クリアサムネイルの見え方を調整する

未クリアでも完成サムネイルを表示する場合、クリア済みと誤解しない見た目にする。

最小実装:

```text
未クリア:
- サムネイル表示
- CLEARバッジなし
- クリア済み装飾なし

クリア済み:
- サムネイル表示
- CLEARバッジあり
- クリア済み装飾あり
```

必要なら、未クリア時のサムネイルに `PREVIEW` など小さな表示を付ける。

### 3. クリア数はクリアフラグだけで計算する

パズルセレクト上部のクリア数は、サムネイルの有無ではなく、クリアフラグだけで計算する。

期待動作:

```text
サムネイル20件あり
クリアフラグ0件
→ クリア数 0 / 20
```

### 4. 開発用データメニューを右上デバッグパネルへ移動する

現在、開発用データメニューがパズルセレクト中央付近に表示されている。  
これを右上に小さく配置するか、折りたたみ式のデバッグパネルにする。

配置候補:

```text
右上:
[開発データ ▼]
```

展開時表示:

```text
開発データ
クリアフラグ: なし
保存キー: picross_v2_solved
全件: 0
[クリア状況リセット]
[ユーザーデータ削除]
```

注意:

- 通常のパズル選択UIを邪魔しない
- デバッグ操作は開発中に使いやすくする
- 本番公開時に非表示化しやすい構造にする
- クリア状況リセットやユーザーデータ削除の機能はチケット31の仕様を維持する

### 5. デバッグパネルは折りたたみ可能にする

可能であれば、開発用データメニューは初期状態で閉じる。

期待動作:

```text
初期表示:
[開発データ ▼]

クリック:
デバッグ情報と削除ボタンを表示
```

最小実装では、右上に常時小さく表示でもよい。

## 受け入れ条件

- クリアフラグなしでもサムネイルは表示できる
- サムネイル表示だけでCLEAR扱いにならない
- クリアフラグなしの場合、CLEARバッジが出ない
- クリアフラグなしの場合、クリア数に含まれない
- サムネイル20件、クリア0件なら `クリア数 0 / 20` になる

- クリア済みの問題だけクリア数に含まれる

- 開発用データメニューが右上など邪魔にならない位置にある
- クリア状況リセットが引き続き使える
- ユーザーデータ削除が引き続き使える
- パズル選択導線が壊れない
