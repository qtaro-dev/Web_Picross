# チケット140fix1：お知らせ画像の右クリック保存・ドラッグ操作を抑止

## 目的

チケット140では、`news-images` Storage bucket を public bucket として継続し、URLを知っている人は画像を閲覧可能であることを明示した。

一方で、一般お知らせ画面の画像上で右クリックすると、ブラウザ標準メニューから「画像アドレスをコピー」「画像を保存」などができてしまう。  
public bucketである以上、DevToolsやNetworkからURLを完全に隠すことはできないが、一般的な右クリック保存・ドラッグ操作は抑止したい。

このチケットでは、セキュリティ対策ではなく、**casual copy防止・誤操作防止**として、お知らせ画像に限定して右クリックメニューとドラッグ操作を抑止する。

## 対象ファイル（推定）

- `js/render.js`
- `js/actions.js`
- `styles.css`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. 一般お知らせ画面の画像に右クリック抑止を追加する

- 一般向けお知らせ画面に表示される画像に対して、右クリックメニューを抑止する。
- 対象はお知らせ本文下に表示されるメイン画像のみとする。
- `contextmenu` イベントで `preventDefault()` を行う。
- 画面全体ではなく、画像要素に限定する。
- お知らせ本文、ボタン、リンク、管理画面全体などには影響させない。

### 2. 画像ドラッグを抑止する

- お知らせ画像に `draggable="false"` を付与する。
- 画像のドラッグ保存・ドラッグコピーを抑止する。
- CSSまたは属性で、画像が選択・ドラッグされにくい状態にする。
- 例：
  - `draggable="false"`
  - `user-select: none;`
  - 必要に応じて `-webkit-user-drag: none;`

### 3. 管理画面プレビュー画像にも必要に応じて適用する

- 管理者のお知らせ編集画面に表示される画像プレビューにも、同じ抑止を適用してよい。
- ただし、管理者が画像URLをコピーする導線は既存どおり維持する。
- 管理者用の「画像URLをコピー」ボタンは壊さない。
- 管理画面での画像削除・画像URL解除・Storage削除には影響させない。

### 4. ゲーム盤面の右クリック操作に影響させない

- Webピクロスの実プレイ画面では右クリックを×入力に使うため、画面全体の右クリック禁止は行わない。
- 盤面セル、エディタセル、ゲーム操作領域には影響させない。
- `document` 全体の `contextmenu` を禁止しない。
- 既存の右クリックメニュー抑止処理がある場合も、ゲーム操作と競合しないようにする。

### 5. DevToolsや直接URL取得を完全に防げないことをREADMEに明記する

- 右クリック抑止は、画像の完全な保護ではない。
- `news-images` はpublic bucketであるため、URLを知っている人は画像を閲覧可能である。
- DevTools、Network、HTMLソース、スクリーンショット、直接URLアクセスは防げない。
- READMEに、今回の対応は「一般的な右クリック保存・ドラッグ操作の抑止」であり、セキュリティ対策ではないことを明記する。

### 6. 既存仕様を壊さない

- 一般お知らせ画面の画像表示を壊さない。
- 画像キャプション表示を壊さない。
- 画像URL文字列を本文に表示しない既存仕様を維持する。
- 管理者のお知らせ編集機能を壊さない。
- 画像アップロード、画像URLコピー、画像URL解除、Storage削除を壊さない。
- ログイン、ゲーム選択、実プレイ、エディタ、ランキングを壊さない。
- ゲーム盤面の右クリック×入力に影響させない。
- 既存テーマ・ライブラリ構成を維持する。
- ハードコード文字列は禁止。
- ICommand構造を崩さない。

## 受け入れ条件（目視確認基準）

### 一般お知らせ画像の右クリック抑止

- 一般ユーザーまたは未ログイン状態でお知らせ画面を開く。
- 画像付きのお知らせ記事を選択する。
- 画像の上で右クリックする。
- OK：ブラウザの画像用コンテキストメニューが表示されないこと。
- OK：ページ全体が壊れないこと。
- NG：画像アドレスコピーや画像保存のメニューが通常どおり出ること。
- NG：右クリック時にJavaScriptエラーが出ること。

### 一般お知らせ画像のドラッグ抑止

- 一般お知らせ画面で画像付き記事を開く。
- 画像をマウスでドラッグしようとする。
- OK：画像をドラッグできない、またはドラッグ保存しにくいこと。
- OK：画像表示自体は通常どおり見えること。
- NG：画像をそのままドラッグして別タブやデスクトップへ持っていけること。
- NG：画像が表示されなくなること。

### 画像URL直接表示は仕様として維持

- 管理者画面で画像URLをコピーする。
- コピーしたURLを別タブで開く。
- OK：画像が表示されること。
- NG：public bucket方針なのに直接URL表示が壊れること。

※このテストは、右クリック抑止がセキュリティ保護ではなく、UI上の抑止であることを確認するために行う。

- OK：画像プレビューが表示されること。
- OK：画像URLコピー、画像URL解除、Storage削除が従来どおり使えること。
- NG：右クリック抑止追加により管理操作が壊れること。

### ゲーム盤面右クリック

- 盤面セルを編集する。

- NG：お知らせ画像対策の影響でエディタ操作が壊れること。

- NG：画像なし記事で不要な画像枠が出ること。
- NG：画像付き記事のレイアウトが崩れること。
