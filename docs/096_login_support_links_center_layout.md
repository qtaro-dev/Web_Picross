# チケット96：ログイン補助リンクの中央寄せレイアウト調整

## 背景

チケット92・95で、ログイン画面に以下の補助リンクが追加された。

```text
パスワードを忘れた場合
確認メールを再送する
```

現在はログインフォーム右寄せ寄りに表示されており、ログイン画面全体の見た目として少し偏って見える。

ログイン画面の中央配置デザインに合わせて、補助リンクも中央寄せに揃える。

## 現在の問題

ログイン画面内の補助リンクが中央揃えになっていない。

対象リンク:

```text
パスワードを忘れた場合
確認メールを再送する
```

## 期待する動作

ログイン画面の補助リンクを、ログインフォーム幅の中央に配置する。

表示形式は以下とする。

```text
パスワードを忘れた場合　確認メールを再送する
```

リンク同士の間隔は、全角スペース1文字分を基準にする。

## 対象ファイル

推定対象:

```text
js/render.js
styles.css
js/config.js
README.md
docs/ticket_status.json
```

主に確認する箇所:

```text
ログイン画面の描画処理
ログイン補助リンクのHTML構造
ログインフォーム周辺のCSS
```

## 実装内容

### 1. 補助リンクを中央寄せにする

ログイン画面に表示している以下のリンク群を中央寄せにする。

```text
パスワードを忘れた場合
確認メールを再送する
```

ログインフォーム全体の幅に対して中央に見えるよう調整する。

### 2. リンク間のスペースを調整する

2つのリンクの間隔は、全角スペース1文字分を基準にする。

表示イメージ:

```text
パスワードを忘れた場合　確認メールを再送する
```

ただし、実装上はCSSの `gap` など既存設計に合わせてもよい。

その場合も、見た目として全角スペース1文字程度の間隔になるようにする。

### 3. レスポンシブ時も中央寄せを維持する

画面幅が狭い場合、リンクが折り返されても中央寄せを維持する。

期待する見た目:

```text
パスワードを忘れた場合
確認メールを再送する
```

または、横幅に余裕がある場合は1行表示を維持する。

### 4. 認証処理は変更しない

このチケットでは見た目のみ調整する。

以下の処理は変更しない。

```text
パスワード再設定メール送信処理
確認メール再送処理
ログイン処理
ユーザー登録処理
メール確認必須化処理
```

## 受け入れ条件

### ログイン画面

ログイン画面を表示する。

期待結果:

```text
「パスワードを忘れた場合」と「確認メールを再送する」が中央寄せで表示される
2つのリンクの間隔が全角スペース1文字程度になっている
```

### リンク動作

各リンクをクリックする。

期待結果:

```text
「パスワードを忘れた場合」は従来通りパスワード再設定メール送信処理を実行する
「確認メールを再送する」は従来通り確認メール再送処理を実行する
```

### レスポンシブ確認

画面幅を狭くする。

期待結果:

```text
リンクが崩れない
折り返されても中央寄せを維持する
ログインフォーム全体のレイアウトが崩れない
```

## メモ

このチケット96では、ログイン補助リンクの配置調整のみを行う。

パスワード再設定・確認メール再送の処理内容は変更しない。
