# チケット130：お知らせ編集フォームのレイアウト整理

## 目的

チケット129でお知らせ編集画面に `現在日時を入れる`、`下書き保存`、`今すぐ公開` などの操作を追加したが、管理者画面で確認したところ、タイトル・公開日時・現在日時ボタン・表示順・公開チェックの並びが窮屈で、ボタン配置も不自然になっている。

お知らせ編集フォームを整理し、管理者が記事を作成・編集しやすいレイアウトへ改善する。

## 対象ファイル（推定）

- `styles.css`
- `js/render.js`
- `js/actions.js`
- `js/admin.js`
- `js/state.js`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. 編集フォーム上部の項目配置を整理する

- お知らせ編集フォーム上部の以下項目を見やすく整理する。
  - タイトル
  - 公開日時
  - `現在日時を入れる` ボタン
  - 表示順
  - `公開する` チェックボックス
- 現在のように `現在日時を入れる` ボタンが公開日時と表示順の間に大きく挟まって、レイアウトを圧迫しないようにする。
- 項目同士の余白を整える。
- 入力欄とボタンの高さが不自然にズレないようにする。

### 2. 推奨レイアウト

- PC幅では以下のような構成を推奨する。

```text
[タイトル                              ]

[公開日時              ] [現在日時を入れる]
[表示順                ] [公開する □      ]
```

または、横幅に余裕がある場合は以下でもよい。

```text
[タイトル              ] [公開日時              ] [現在日時を入れる]
[表示順                ] [公開する □            ]
```

- `現在日時を入れる` ボタンは、縦長にならないようにする。
- ボタン文言が2行になりにくい幅を確保する。
- `公開する` チェックボックスは、公開日時付近に寄せて意味が分かりやすい配置にする。

### 3. 本文欄以降の視認性を維持する

- 本文欄は横幅を広めに確保する。
- 画像URL、画像alt、画像キャプションの入力欄は、本文欄の下に整理して配置する。
- 画像アップロード説明、画像選択、アップロード、URLコピー、URL解除、Storage削除の導線が混乱しないようにする。
- 画像プレビューがフォーム全体を押しつぶさないようにする。

### 4. 操作ボタンの配置を整理する

- フォーム下部の操作ボタンを分かりやすく配置する。
- 対象ボタン：
  - `下書き保存`
  - `今すぐ公開`
  - `削除`
- 推奨配置：
  - 保存系ボタンは左または右にまとめる
  - 危険操作である `削除` は他の保存ボタンと少し離す
  - `削除` は赤系など既存の危険操作スタイルを維持する
- ボタンが密集しすぎないようにする。

### 5. レスポンシブ対応

- 1920×1080相当で自然に表示されること。
- 1366×768相当でもフォームが大きく崩れないこと。
- 1024×768相当では、必要に応じて縦積みレイアウトに切り替える。
- 画面幅が狭い場合、入力欄やボタンがはみ出さないようにする。
- `現在日時を入れる` ボタンが過剰に縦長にならないようにする。

### 6. 既存機能を壊さない

- チケット126のお知らせ管理機能を維持する。
- チケット127の画像アップロード機能を維持する。
- チケット128の複数記事作成修正とページングを維持する。
- チケット129の以下機能を維持する。
  - `下書き保存`
  - `今すぐ公開`
  - `現在日時を入れる`
  - 本文なし・画像あり記事の保存
  - タイトルのみ記事の保存不可
  - 画像URLコピー
  - HTML不可説明
  - アップロード画像は本文下のメイン画像として表示される説明
- 一般向けお知らせ画面の表示は変更しない。
- ログイン、ゲーム選択、実プレイ、エディタ、既存管理者機能を壊さない。
- 既存テーマ・背景・ボタンデザインを維持する。
- 既存ライブラリ構成を維持する。
- ハードコード文字列は禁止。
- ICommand構造を崩さない。

- 管理者が管理者画面を開く。
- 管理者が「お知らせ管理」で記事編集フォームを表示する。

- OK：公開日時と表示順の入力欄が窮屈に見えないこと。

- OK：公開日時欄に現在日時が入ること。

- OK：`下書き保存` と `今すぐ公開` が分かりやすく配置されていること。
