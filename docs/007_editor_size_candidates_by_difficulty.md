# チケット7: エディタ難易度選択に応じた盤面サイズ候補表示

## 目的

エディタモードで難易度を選択したとき、その難易度で使用可能な盤面サイズ候補だけを選べるようにする。  
現在のように幅・高さが独立して固定表示される状態ではなく、チケット6で定義した難易度別の盤面候補に連動させる。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\editor.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. 難易度変更時に盤面サイズ候補を更新する

エディタ画面の難易度セレクト変更時に、盤面サイズ候補を更新する。

例:

```text
ビギナー選択時:
- 5x5
- 5x10

イージー選択時:
- 10x10
- 5x10
- 10x5

ノーマル選択時:
- 15x10
- 10x10
- 5x10
- 10x5

ハード選択時:
- 20x20
- 15x10
- 10x10

エンドレス選択時:
- 20x20以上
- 最大50x50まで
```

### 2. 盤面サイズ選択UIを用意する

現在の幅・高さセレクトを維持するか、盤面サイズ候補セレクトを新設する。

候補UI:

```text
盤面サイズ:
[ 10 x 10 ▼ ]
```

または既存UIを活かす場合:

```text
幅: [10] 高さ: [10]
```

ただし、難易度ごとの候補から外れる組み合わせを選べないようにする。

### 3. エンドレスは自由入力または候補範囲指定にする

エンドレスは 20x20 以上、最大 50x50 までとする。

対応案:

```text
- 幅 / 高さを 20〜50 の範囲で選択可能にする
- 代表候補として 20x20 / 25x25 / 30x30 / 40x40 / 50x50 を出す
- 必要なら幅・高さの個別入力を許可する
```

最小実装では、代表候補を出す方式でもよい。

### 4. 難易度変更時にカラー選択UIも連動させる

チケット6の定義に従い、カラー可否をUIへ反映する。

期待動作:

```text
ビギナー: モノクロ固定、カラー無効
イージー: モノクロ固定、カラー無効
ノーマル: モノクロ / カラー選択可
ハード: モノクロ / カラー選択可
エンドレス: モノクロ / カラー選択可
```

### 5. 盤面サイズ変更時にエディタ盤面を再生成する

盤面サイズ候補を選択して「サイズ変更」した場合、エディタ盤面を指定サイズで再生成する。

注意:

- 既存の「サイズ変更」ボタンがある場合は、それを活かす
- サイズ変更前に編集済みデータが消える場合は、確認ダイアログを出すことが望ましい
- 最小実装では既存の全消去 / サイズ変更動作に合わせてよい

### 6. 読み込み済みデータとの整合性

ローカルJSONを読み込んだとき、読み込んだパズルの難易度・サイズに合わせてUIを更新する。

例:

```text
normal / 15x10 のデータを読み込む
→ 難易度: ノーマル
→ 盤面サイズ: 15x10
→ 種別: 読み込んだ値
```

## 受け入れ条件

- エディタ画面を開ける
- 難易度を変更すると、盤面サイズ候補が変わる
- ビギナーでは 5x5 / 5x10 の候補が出る
- イージーでは 10x10 / 5x10 / 10x5 の候補が出る
- ノーマルでは 15x10 / 10x10 / 5x10 / 10x5 の候補が出る
- ハードでは 20x20 / 15x10 / 10x10 の候補が出る
- エンドレスでは 20x20以上、最大50x50までの候補または入力範囲になる
- ビギナー / イージーではカラーを選べない
- ノーマル / ハード / エンドレスではカラーを選べる
- 盤面サイズ変更後、エディタ盤面が指定サイズになる
- JSON読み込み後、難易度・盤面サイズ・種別UIが読み込み内容に合う
- 既存のJSON読込・JSONダウンロード機能が壊れない
- エディットプレイ導線が壊れない
- `node --check js/editor.js` が通る
- 変更したJSファイルすべてで `node --check` が通る
