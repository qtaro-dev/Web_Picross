# チケット27: 右クリックメニュー抑止範囲の拡張とページ更新時タイトル復帰

## 目的

ゲーム中の右クリック操作そのものは禁止しない。  
右クリックで `×` を置く操作は、ピクロスの基本操作として維持する。

修正したいのは、右クリック時にブラウザ標準のコンテキストメニューが出てしまうこと。  
現在、ゲームフィールドの盤面にフォーカスがある時はメニューが出ないため、その状態をゲーム画面全体、または必要な操作領域へ広げる。

また、キーボードのF5キーやブラウザの更新ボタンでページ更新された場合は、再読み込み後にタイトル画面へ戻るようにする。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\main.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. 右クリックで×を置く操作は維持する

ゲーム中の右クリック操作は、従来どおり `×` を置く操作として維持する。

維持する操作:

```text
右クリック単発:
- 未入力 → ×
- × → 未入力
- 塗り済み / 色付き → ×、塗りや色は消える

右ドラッグ:
- 通過セルに×を連続設置
- 塗りや色は消える
```

禁止事項:

```text
- 右クリック操作自体を無効化しない
- 右クリックで×を置けなくしない
- 右ドラッグ×を壊さない
```

### 2. ブラウザ標準の右クリックメニューだけを抑止する

右クリック時にブラウザ標準のコンテキストメニューが表示されないようにする。

対象候補:

```text
- ゲーム画面全体
- 盤面
- ヒント領域
- パレット
- 左側操作ボタン群
- 右側パネル
```

最小実装では、ゲーム画面中の操作領域に対して `contextmenu` を抑止する。

期待動作:

```text
ゲーム画面中に右クリック
→ ブラウザメニューは出ない
→ 盤面上なら従来どおり×操作が動く
```

注意:

- `event.preventDefault()` はコンテキストメニュー抑止のために使う
- ただし、既存の右クリック×処理は止めない
- 盤面以外のボタンやパレット上で右クリックした場合も、メニューだけ出さない
- 入力欄やエディタ画面など、通常の右クリックメニューが必要な場所まで過剰に禁止しない

### 3. 現在できている盤面上の抑止状態を広げる

現状では、ゲームフィールドの盤面にフォーカスがある時は右クリックメニューが出ない。  
この実装を参考にして、ゲーム画面の周辺UIにも同じ抑止を広げる。

対象例:

```text
- ゲーム画面ルート要素
- board周辺コンテナ
- controlsパネル
- paletteパネル
```

注意:

- document全体で無条件に `contextmenu` を禁止しない
- エディタ画面では既存仕様を確認し、必要ならエディタ盤面でもメニュー抑止だけ行う
- 入力欄上では右クリックメニューを残してよい

### 4. 左クリック・右クリック・ドラッグ操作は維持する

このチケットで変えるのは「ブラウザメニューの表示」だけであり、ゲーム操作は維持する。

維持する操作:

```text
左クリック単発:
- モノクロなら塗りON/OFF
- カラーなら選択色で塗り/解除

左ドラッグ:
- モノクロなら連続塗り
- カラーなら選択色で連続塗り

右クリック単発:
- × ON/OFF

右ドラッグ:
- 連続×
```

### 5. F5 / ブラウザ更新でタイトルに戻る

F5キーまたはブラウザの更新ボタンでページ更新された場合、再読み込み後はタイトル画面を初期表示する。

期待動作:

```text
ゲーム画面中
→ F5 またはブラウザ更新
→ ページ再読み込み
→ タイトル画面
```

注意:

- sessionStorage / localStorage 等で前回画面を復元している場合は、更新時にタイトルへ戻す
- URLハッシュやクエリで画面復元している場合も、更新時はタイトルへ戻す
- 保存済みデータやユーザー情報は不用意に削除しない
- 現在プレイ中の一時入力状態は消えてよい

### 6. エディタモードとの整合性

エディタモードではチケット26の右ドラッグ×操作を維持する。

エディタ盤面で右クリックメニューが邪魔になる場合は、エディタ盤面上でも `contextmenu` だけを抑止してよい。

注意:

- エディタの右クリック×は壊さない
- エディタの入力欄上では右クリックメニューを残してよい
- エディタ画面全体で過剰に右クリック禁止しない
