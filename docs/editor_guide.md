# エディタ機能

エディタはSupabase管理者ユーザー専用です。通常ユーザーが内部的にエディタ遷移を呼び出した場合も、メニューへ戻して利用を拒否します。

## 主な機能

- 難易度、盤面サイズ、モノクロ / カラーの設定
- 盤面クリック、ドラッグによる作成
- JSON読み込み / 出力
- 読み込み済みJSONスロット管理
- スロット保存、読込、空きスロット追加
- エディットプレイ
- 50%から200%までのエディタ盤面ズーム
- 完成プレビュー
- `grid_strings` 複数行文字列から盤面作成
- 現在の盤面から `grid_strings` 文字列生成

## JSONと `grid_strings`

パズルJSONの `id` はSupabase上の管理用 `puzzle_key` として扱い、Supabase `puzzles.id` のUUID主キーとは別物です。

推奨命名規則は次の形式です。

```text
{difficulty}_{mode}_id{8桁連番}
```

例:

```text
normal_mono_id00000001
normal_color_id00000002
```

`grid_strings` は `0` から `F` の文字を使う複数行文字列です。入力欄では現在の盤面高さに合わせて表示行数を広げ、`0`から`9` / `A`から`F` / `a`から`f` / 改行だけを受け付けます。

詳細は [詳細仕様メモ](project_details.md) を参照してください。
