# チケット141：エディタにgrid_strings文字列入力・反映機能を追加

## 目的

現在のエディタでは、完成盤面のJSON出力に `grid_strings` が含まれている。

例：

```json
"grid_strings": [
  "0000EE0000",
  "000EBBE000",
  "EEEEBBEEEE"
]
```

この形式は、AIや外部メモで作った小型ピクロス案をそのまま貼り付けて盤面化する用途に向いている。

そこで、エディタ画面に `grid_strings` 形式の文字列入力欄を追加し、`0`〜`F` の文字列を貼り付けるだけで現在の盤面へ反映できるようにする。

また、現在の盤面から `grid_strings` 文字列を生成できるようにし、ユーザーが作成中の盤面を外部へ共有・再編集しやすくする。

## 対象ファイル（推定）

- `js/editor.js`
- `js/render.js`

- `js/state.js`
- `js/config.js`

## 実装内容

### 1. 開閉式の入力パネルを追加する

エディタ画面の下部、既存の「データプレビュー」の上に、開閉式の `grid_strings` 入力パネルを追加する。

表示名候補：

- `文字列から盤面作成`
- `grid_strings入力`
- `0-F文字列入力`

初期状態は閉じていてよい。

既存のデータプレビューと同じように、画面下部で邪魔になりにくい構成にする。

### 2. textareaを追加する

パネル内に複数行入力用の `textarea` を追加する。

入力例：

```text
0000EE0000
000EBBE000
EEEEBBEEEE
ED6EEEE6DE
EEEEDDEEEE
E66E8EE66E
E66E66E66E
E66E66E66E
EEEEEEEEEE
0000000000
```

仕様：

- 1行 = 盤面1行
- 1文字 = 1マス
- 使用可能文字は `0`〜`9` / `A`〜`F`
- 小文字 `a`〜`f` は自動で大文字へ正規化
- 空白、タブ、全角文字、カンマ、引用符などは原則エラー
- 行頭・行末の空白はトリムしてよい
- 空行は無視せず、入力不備として扱う方針にする

### 3. 現在の盤面サイズに合わせて検証する

現在のエディタ盤面サイズに対して入力文字列を検証する。

検証条件：

- 行数が現在の `h` と一致すること
- 各行の文字数が現在の `w` と一致すること
- 各文字が `0`〜`9` / `A`〜`F` のいずれかであること

エラー例：

- `10行で入力してください`
- `3行目は10文字で入力してください`
- `使用できる文字は 0〜9 / A〜F のみです`
- `現在の盤面サイズは 10x10 です`

エラーがある場合は盤面へ反映しない。

### 4. 「盤面へ反映」ボタンを追加する

textareaの内容を検証し、問題がなければ現在の盤面へ反映する。

反映仕様：

- `0`〜`F` を既存のカラーインデックスとして扱う
- 既存の `grid` 内部形式に合わせて保存する
- 反映後、完成プレビューも更新する
- 反映後、既存のJSON出力内容にも反映される
- 反映後、必要であれば一時保存データの状態も更新する

注意：

- 既存のパレット色番号と対応を崩さない
- `ICommand` 構造を崩さない
- 既存のエディタ操作、スロット保存、JSON出力を壊さない

### 5. 「現在の盤面から文字列生成」ボタンを追加する

現在の盤面を `grid_strings` 形式に変換し、textareaへ出力する。

仕様：

- 現在の盤面の各行を `0`〜`F` の文字列として出力
- 1行ごとに改行する
- 出力結果はJSON配列ではなく、貼り付けしやすい素の複数行文字列にする

例：

```text
0000EE0000
000EBBE000
EEEEBBEEEE
```

この機能により、作成中の盤面をAIや外部メモへ貼り付けやすくする。

### 6. 「入力クリア」ボタンを追加する

textareaの内容を消すボタンを追加する。

- 盤面は変更しない
- 入力欄だけをクリアする
- エラーメッセージも消す

### 7. UI文言を分かりやすくする

パネル内に簡単な説明を追加する。

表示例：

```text
0〜Fの文字を、現在の盤面サイズに合わせて入力してください。
1行が盤面の1行になります。小文字a〜fは自動で大文字に変換されます。
```

10x10なら補足として、

```text
現在の盤面サイズ：10x10
10行、各行10文字で入力してください。
```

のように出せるとよい。

### 8. 既存JSON出力との互換性を維持する

現在のJSON出力にある `grid_strings` と互換の形式にする。

- `grid` と `grid_strings` が一致すること
- 文字列入力から反映した盤面をJSON出力した場合、同じ `grid_strings` が出ること
- 既存のJSON読み込み・保存・スロット機能を壊さないこと

### 9. スタイルを既存テーマに合わせる

- 既存の黒背景・枠線・ボタンデザインに合わせる
- エディタ下部に置いても画面が崩れないようにする
- textareaは読みやすい等幅フォントを使う
- 文字が詰まりすぎないようにする
- 横幅が長い盤面でも破綻しにくくする
- レスポンシブ崩れを避ける

### 10. 既存仕様を壊さない

- エディタの手動編集を壊さない
- パレット選択を壊さない
- 完成プレビューを壊さない
- スロット保存・読込を壊さない
- JSON出力を壊さない
- JSON読込を壊さない
- 既存のパズルデータを変更しない
- 既存テーマ・ライブラリ構成を維持する
- ハードコード文字列は禁止
- ICommand構造を崩さない
