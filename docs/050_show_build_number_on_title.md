# チケット50: タイトル画面へのビルドナンバー表示

## 目的

アプリの修正回数・チケット対応状況を視覚的に確認できるようにするため、タイトル画面の左下あたりにビルドナンバーを表示する。

今回からビルドナンバーを導入し、初期値は以下とする。

```text
Build #0000050
```

今後、チケットでの訂正・修正・編集などを行うたびに、ビルドナンバーを `+1` する運用にする。

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\config.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 実装内容

### 1. ビルドナンバーを設定として管理する

ビルドナンバーは画面表示用の固定文字列として分散配置しない。

推奨:

```js
build: {
  number: 50,
  label: "Build #0000050"
}
```

### 2. タイトル画面の左下あたりに表示する

タイトル画面の左下付近に、以下の文字列を表示する。

```text
Build #0000050
```

仕様:

```text
- タイトル画面の左下あたりに表示する
- タイトル、メインボタン、背景画像の邪魔にならない位置にする
- 背景画像がある場合でも読める色と透明度にする
```

CSS例:

```css
.build-number {
  position: fixed;
  left: 16px;
  bottom: 12px;
  font-size: 12px;
  opacity: 0.75;
  color: rgba(255, 255, 255, 0.8);
  pointer-events: none;
  z-index: 10;
}
```

### 3. タイトル画面以外には出さない

```text
- タイトル画面では表示する
- ログイン画面、メニュー画面、ゲーム画面、エディタ画面などでは表示しない
```

### 4. READMEに運用を追記する

READMEに以下の方針を追記する。

```text
ビルドナンバーはチケット修正・訂正・編集のたびに +1 する。
チケット50時点の初期ビルドは Build #0000050 とする。
```

## 受け入れ条件

```text
- http://127.0.0.1:8000/ で確認できる
- タイトル画面の左下あたりに Build #0000050 が表示される
- 表示がボタンやタイトルの邪魔をしない
- 背景画像があっても読める
- タイトル画面以外では表示されない
- ビルドナンバーが設定として管理されている
- READMEにビルドナンバー運用が追記されている
- node --check が変更したJSファイルすべてで通る
```

```bat
cd /d E:\Dev\web_picross_Ver2
npm start
```

```text

```

```text
→ Build #0000050 が表示されないことを確認する
```
