# チケット84: 管理者ページの進行状況テーブルで「クリア」列の文字が縦になる問題の修正

## 目的

管理者ページのユーザー詳細内にある進行状況テーブルで、`クリア` 列のヘッダー文字が縦に折り返されて表示される問題を修正する。

## 背景

管理者ページの進行状況テーブルで、`クリア` という列名が以下のように縦表示になっている。

```text
ク
リ
ア
```

これは列幅が狭すぎる、またはCSSの折り返し設定が原因と考えられる。

管理画面の可読性が落ちるため、`クリア` は横書きで表示する。

## 対象ファイル（推定）

```text
styles.css
js/admin.js
js/render.js
docs/ticket_status.json
```

## 実装内容

### 1. 進行状況テーブルの「クリア」列幅を調整する

`クリア` 列のヘッダーとチェックボックスが自然に表示されるよう、列幅を調整する。

目安:

```text
min-width: 56px 〜 72px 程度
```

または、対象列に専用クラスを付ける。

例:

```text
admin-progress-clear-column
```

### 2. ヘッダーの折り返しを禁止する

`クリア` ヘッダーが縦に折り返されないようにする。

CSS例:

```css
white-space: nowrap;
word-break: keep-all;
```

### 3. テーブル全体の横幅を確認する

列幅を広げることで他の列が崩れないか確認する。

必要であれば、管理画面のテーブルに横スクロールを許可する。

```text
overflow-x: auto
```

### 4. チェックボックス位置を整える

`クリア` 列のチェックボックスが中央に見えるようにする。

候補:

```text
text-align: center;
vertical-align: middle;
```

### 5. 他のテーブルへ影響しないようにする

ランキング一覧やプレイ履歴テーブルには不要な影響を出さない。

必要であれば、管理者ページの進行状況テーブル専用CSSとして実装する。

## UI仕様

- `クリア` が横書きで表示される
- チェックボックスが見やすい
- テーブル全体が極端に崩れない
- PC幅で見やすい
- スマホ幅では必要に応じて横スクロールでよい
- 既存テーマを壊さない

## 受け入れ条件

- 管理者ページの進行状況テーブルで `クリア` が横書き表示になる
- `クリア` が縦に折り返されない
- チェックボックスが列内で不自然に寄っていない
- Progress Key / ベストms / 最新ms / クリア数 / 失敗 / ギブアップ / ヒント / 保存ボタン列が崩れていない
- ランキング管理テーブルの表示が崩れていない
- プレイ履歴テーブルの表示が崩れていない
- スマホ幅で見た場合も最低限操作できる
- `node --check` が通る
- ビルド番号を +1 する
- `docs/ticket_status.json` にこのチケットを追加し、初期状態を `未修整` にする
