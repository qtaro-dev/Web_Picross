# チケット117：大盤面スクロール位置の保持

## 目的

大盤面プレイ中に、盤面コンテナ内のスクロール位置がセル操作や再描画のたびに初期位置へ戻ってしまう問題を修正する。

Endlessや20×20以上の盤面では、ユーザーが手動でスクロールして見たい範囲へ移動しているため、操作後もその位置を維持し、ゲームを継続しやすくする。

## 対象ファイル（推定）

- `js/render.js`
- `js/actions.js`
- `js/state.js`
- `styles.css`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容（具体的変更指示）

- 実プレイ画面の盤面コンテナ内スクロール位置を保持する。
- 盤面再描画が発生する場合、再描画前に以下を保存する。
  - `scrollTop`
  - `scrollLeft`
- 盤面再描画後に、保存した `scrollTop` / `scrollLeft` を復元する。
- 対象は、少なくとも以下の操作後とする。
  - セルを塗る
  - セルを消す
  - 右クリックで×を付ける
  - ドラッグ操作
  - ヒント使用
  - 判定後に画面更新が発生する場合
  - 拡大縮小操作後に可能な範囲で位置を維持する場合
- 可能であれば、セル操作時に盤面全体を再描画せず、対象セルだけ更新する方向を優先する。
- ただし、既存のゲームロジックや正誤判定処理は変更しない。
- クリック位置計算がスクロール位置復元後もズレないようにする。
- 盤面外のブラウザ全体スクロールではなく、盤面コンテナ内スクロールを優先して扱う。
- 既存テーマ・ボタンデザイン・ICommand構造を崩さない。
- 判定ボタンの内部仕様変更は本チケットでは行わない。
- 大盤面の描画負荷軽減はチケット118で扱うため、本チケットではスクロール位置保持を主目的とする。

## 受け入れ条件（目視確認基準）

### Endless #01 / #02

- ユーザーがEndless #01またはEndless #02を開く。
- ユーザーが盤面コンテナ内の横スクロールを右方向へ動かす。
- ユーザーが盤面コンテナ内の縦スクロールを下方向へ動かす。
- ユーザーが表示中のセルをクリックして塗る。
- OK：クリック後も、盤面コンテナ内のスクロール位置が大きく初期位置へ戻らないこと。
- NG：クリック後に左上や初期位置へ戻ること。

### セル消去

- ユーザーがスクロールした位置で、塗ったセルをもう一度クリックして消す。
- OK：消去後もスクロール位置が維持されること。
- NG：消去後にスクロール位置が戻ること。

### 右クリック×操作

- ユーザーがスクロールした位置で、右クリックにより×を付ける。
- OK：×を付けた後もスクロール位置が維持されること。
- NG：×を付けた後に初期位置へ戻ること。

### ドラッグ操作

- ユーザーがスクロールした位置で、複数セルをドラッグ操作する。
- OK：ドラッグ中またはドラッグ後にスクロール位置が勝手に戻らないこと。
- NG：ドラッグ操作の途中や終了時に盤面位置が飛ぶこと。

### カラー問題

- ユーザーがカラーの大盤面を開く。
- ユーザーがスクロールした位置で色を変えてセルを塗る。
- OK：色変更後や塗り操作後もスクロール位置が維持されること。
- NG：色変更または塗り操作で初期位置へ戻ること。

### 拡大縮小

- ユーザーが盤面をスクロールした状態で、縮小 / 100% / 拡大を押す。
- OK：倍率変更後も、可能な範囲で近い位置を表示すること。
- NG：毎回完全に左上へ戻り、プレイ継続が困難になること。

### クリック位置

- ユーザーがスクロールした状態で任意のセルをクリックする。
- OK：クリックしたセルと実際に変化するセルが一致すること。
- NG：スクロール位置保持の影響で、クリック位置と更新セルがズレること。
