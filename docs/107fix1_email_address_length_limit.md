# チケット107fix1：メールアドレス変更フォームの文字数制限修正

## 背景

チケット107で、ユーザーデータ画面から本人がメールアドレス変更申請できる機能が実装済み。

テスト中に、Gmailエイリアスを使った以下のようなメールアドレスを入力したところ、画面上の文字数制限により途中で入力が止まり、メールアドレス形式エラーになった。

```text
qtaro.dev.project1977+webpicross-testuser2@gmail.com
```

現在の画面ではメールアドレス入力欄に「50文字まで」と表示されており、実用上短すぎる。

メールアドレスは実運用では254文字まで受け付けられる想定で扱うのが一般的なため、メールアドレス変更フォームの最大文字数を254文字に修正する。

## 目的

ユーザーデータ画面のメールアドレス変更フォームで、50文字を超える有効なメールアドレスを入力・申請できるようにする。

## 対象ファイル（推定）

- `js/render.js`
- `js/actions.js`
- `js/supabaseAuth.js`
- `js/config.js`
- `README.md`
- `docs/vercel_supabase_production_checklist.md`
- `docs/ticket_status.json`
- 必要に応じて、ユーザーデータ画面の入力バリデーションを定義している関連ファイル

## 実装内容

### 1. メールアドレス入力欄のmaxlengthを254へ変更

ユーザーデータ画面の以下入力欄について、最大文字数を254文字に変更する。

- 新しいメールアドレス
- 新しいメールアドレス確認

現在、`maxlength="50"` 相当の制限がある場合は、以下に変更する。

```text
maxlength="254"
```

### 2. 画面表示の文字数説明を修正

現在の表示：

```text
50文字まで
```

修正後：

```text
254文字まで
```

対象はメールアドレス変更欄のみ。

ユーザー名、表示名、パスワードなど、メールアドレス以外の既存文字数制限は変更しないこと。

### 3. バリデーションの上限値を254へ変更

JavaScript側でメールアドレスの長さを50文字以下として判定している処理があれば、254文字以下に変更する。

例：

```text
email.length > 50
```

のような条件があれば、以下の考え方に変更する。

```text
email.length > 254
```

エラーメッセージも、50文字前提の文言が残っていれば254文字へ更新する。

### 4. 既存のメール形式チェックは維持

メールアドレス形式チェックそのものは維持する。

以下は引き続きNGにする。

- `@` がない
- ドメイン部がない
- 空欄
- 確認欄と一致しない
- 255文字以上のメールアドレス

### 5. チケット管理・ドキュメント更新

以下を更新する。

- `docs/ticket_status.json` に `107fix1` を追加
- READMEまたは本番チェックリストに、メールアドレス変更欄は254文字まで対応する旨を必要に応じて追記
- Build番号を更新する

## 受け入れ条件（目視確認基準）

### 入力欄表示

1. ユーザーでログインする
2. ユーザーデータ画面を開く
3. アカウント管理のメールアドレス変更欄を見る

OK：

```text
新しいメールアドレス欄の説明が「254文字まで」になっている
新しいメールアドレス確認欄も同じ仕様になっている
```

NG：

```text
50文字まで の表示が残っている
50文字を超えると入力できなくなる
```

### 50文字超えメールの入力

以下のようなGmailエイリアスを入力する。

```text
qtaro.dev.project1977+webpicross-testuser2@gmail.com
```

OK：

```text
最後まで入力できる
同じ内容を確認欄にも入力できる
メールアドレス形式エラーにならない
```

NG：

```text
途中で入力が切れる
形式チェックエラーになる
```

### メールアドレス変更申請

1. 新しいメールアドレス欄に50文字超えの有効なメールアドレスを入力する
2. 確認欄にも同じメールアドレスを入力する
3. メールアドレス変更申請ボタンを押す

OK：

```text
変更申請が受け付けられる
確認メール送信の成功メッセージが出る
Gmailに確認メールが届く
```

NG：

```text
50文字制限由来のエラーが出る
メール形式エラーになる
申請できない
```

### 確認メール後の反映

1. Gmailに届いた確認メールを開く
2. 確認リンクを押す
3. Webピクロスに戻る
4. ユーザーデータを再読込する

OK：

```text
現在のメールアドレスが新しいメールアドレスへ更新される
管理者ページ側のメール欄にも反映される
ログインできる
```

NG：

```text
Auth側とprofiles側でメールアドレスがズレる
ユーザーデータ画面に旧メールアドレスが残る
管理者ページに旧メールアドレスが残る
ログインできなくなる
```

## 備考

このチケットでは、メールアドレス変更フロー自体の設計変更は行わない。

修正対象は、メールアドレス入力欄の最大文字数制限と、それに関連する表示・バリデーションのみとする。
