# チケット25: 空白行・空白列の0ヒント表示とセル正方形保証

## 目的

ゲーム中のパズル表示で、正解として塗るマスが存在しない行または列にも、必ず `0` を表示するようにする。

また、盤面の1マスが必ず正方形になるようにし、縦横比の崩れや枠線の歪みを防ぐ。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\engine.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\styles.css`

必要に応じて:

- `E:\Dev\web_picross_Ver2\js\data.js`

## 実装内容

### 1. 塗るところがない行には必ず0を表示する

行ヒント計算で、正解マスが1つもない行の場合、空配列ではなく `0` をヒントとして表示する。

期待表示:

```text
0
```

例:

```text
行の正解:
0 0 0 0 0

表示:
0
```

### 2. 塗るところがない列にも必ず0を表示する

列ヒント計算でも同様に、正解マスが1つもない列の場合、`0` を表示する。

期待表示:

```text
0
```

### 3. カラー問題でも空白行・空白列は0を表示する

カラー問題でも、その行・列に塗る色付きマスが1つもない場合は `0` を表示する。

注意:

- `0` がMinecraftカラーコードの黒IDとして使われる場合があるため、空白ヒントの `0` とカラーID `0` を内部的に混同しない
- ヒント表示用の0は「空行/空列」を意味する
- カラーIDの黒 `0` は「黒で塗るマス」を意味する
- 表示上の区別が必要なら、空行/空列の0は通常ヒント色で表示する

### 4. ヒントデータ構造で空白ヒントを明確にする

可能であれば、内部では以下のように区別する。

```js
{ count: 0, colorId: null, empty: true }
```

または既存構造に合わせて安全に扱う。

注意:

- 既存のモノクロヒント計算を壊さない
- チケット21のカラー付きヒント表示を壊さない
- 空白ヒントの0に背景色を付ける場合は、通常ヒントとして扱う

### 5. 1マスが必ず正方形になるようにする

盤面セルのCSS/描画を見直し、1マスが必ず正方形になるようにする。

確認すること:

```text
- width と height が同じ値になっているか
- CSS grid の列幅・行高が同じになっているか
- border の影響で縦横比が崩れていないか
- box-sizing が適切か
- aspect-ratio を使えるか
- line-height や padding の影響がないか
```

期待実装候補:

```css
.cell {
  width: var(--cell-size);
  height: var(--cell-size);
  aspect-ratio: 1 / 1;
  box-sizing: border-box;
}
```

既存構造に合わせて調整すること。

### 6. 盤面サイズごとのセル正方形を確認する

以下のサイズで確認する。

```text
5x5
5x10
10x5
10x10
15x10
20x20
50x50
```

特に 5x10 / 10x5 のような長方形盤面で、セル自体が正方形を維持すること。

### 7. グリッド線の等間隔を維持する

チケット13のグリッド等間隔化を壊さない。

期待動作:

```text
- 縦線と横線が等間隔
- セルが正方形
- 外枠が歪まない
- ヒント位置がセルに揃う
```
