# チケット89：ユーザー登録成功メッセージの文言調整

## 背景

新規ユーザー登録完了後、ログイン画面上に以下のメッセージが表示されている。

```text
登録しました。ログインしてください
```

ただし、登録完了後も画面自体はログイン画面のままであり、ログインボタンも同じ画面内に表示されている。

そのため「ログインしてください」まで表示すると、やや説明が重複して見える。

## 現在の問題

ユーザー登録成功時のメッセージが少し長い。

現在の表示:

```text
登録しました。ログインしてください
```

## 期待する動作

ユーザー登録成功時のメッセージを、以下に変更する。

```text
登録しました。
```

## 対象ファイル

推定対象:

```text
js/config.js
js/actions.js
README.md
docs/ticket_status.json
```

主に確認する箇所:

```text
ユーザー登録成功時のメッセージ定義
ユーザー登録成功後の画面表示処理
```

## 実装内容

### 1. 登録成功メッセージを変更する

ユーザー登録成功時に表示している文言を変更する。

変更前:

```text
登録しました。ログインしてください
```

変更後:

```text
登録しました。
```

### 2. 既存の登録処理は変更しない

文言のみの調整とし、以下の処理は変更しない。

```text
ユーザー登録処理
Supabase Auth登録処理
profiles作成処理
登録後の画面状態
ログイン処理
```

### 3. ハードコードを増やさない

既存の文言管理・メッセージ定義がある場合は、その構造に合わせて修正する。

同じ文言が複数箇所に重複している場合は、既存方針に合わせて整理する。

## 受け入れ条件

### 新規ユーザー登録

新規ユーザーを登録する。

期待結果:

```text
登録しました。
```

と表示される。

### 画面状態

登録完了後、ログイン画面のままであること。

期待結果:

```text
ログイン画面が表示されている
ログインボタンが表示されている
ユーザーデータ画面へ自動遷移しない
ゲーム画面へ自動遷移しない
```

### 既存ログイン

登録済みユーザーでログインする。

期待結果:

```text
通常通りログインできる
既存のログイン成功処理に影響がない
```

## メモ

このチケット89では、ユーザー登録後の処理フローは変更しない。

対象は、登録成功時に表示するメッセージ文言の調整のみ。
