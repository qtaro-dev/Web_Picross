# チケット81: 管理者ページにアカウント削除申請一覧と通知表示を追加する

## 目的

管理者ページで、ユーザーから届いたアカウント削除申請を一覧確認できるようにする。

管理者ログイン時に「削除申請が届いている」ことが分かる通知・件数表示を追加する。

## 背景

チケット80で `account_delete_requests` テーブルに削除申請を保存する。

次に、管理者がSupabase Table Editorを直接見なくても、アプリ上の管理者ページで申請状況を確認できるようにする。

## 前提

- チケット80で `account_delete_requests` が追加済み
- 管理者判定は `profiles.role = 'admin'`
- service role key はフロントに出さない
- このチケットでは申請の承認・拒否UIを追加するが、Authユーザーの実削除はまだ行わない
- 実削除処理は後続チケットで検討する

## 実装内容

### 1. 管理者ページに削除申請セクションを追加する

管理者ページに以下のセクションを追加する。

```text
アカウント削除申請
```

表示項目:

```text
申請日時
ユーザー名
表示名
メールアドレス
申請状態
管理者メモ
ユーザーID
申請ID
```

### 2. pending申請の通知を表示する

管理者ログイン時、pending状態の削除申請がある場合に通知を表示する。

表示例:

```text
アカウント削除申請が 2 件届いています
```

表示場所候補:

```text
管理者ページ上部
管理者ページのタブ
メニューの管理者ページボタン横
```

まずは管理者ページ上部でよい。

### 3. フィルターを追加する

削除申請一覧にフィルターを追加する。

```text
全状態
申請中
承認済み
拒否済み
```

検索欄:

```text
ユーザー名
メールアドレス
```

### 4. 申請詳細を表示する

一覧から申請を選択すると詳細を表示する。

詳細項目:

```text
申請ID
ユーザーID
ユーザー名
表示名
メールアドレス
申請日時
状態
管理者メモ
reviewed_at
reviewed_by
```

### 5. 承認・拒否UIを追加する

pending申請に対して、以下の操作ボタンを表示する。

```text
承認する
拒否する
```

承認・拒否ボタン押下時は確認ダイアログを出す。

承認時の注意:

```text
このチケットではAuthユーザーの実削除は行わない。
statusをapprovedに変更するだけ。
```

拒否時:

```text
statusをrejectedに変更する。
```

### 6. 管理者メモを入力できるようにする

承認・拒否時に管理者メモを残せるようにする。

例:

```text
本人確認後に削除予定
誤申請のため拒否
連絡待ち
```

### 7. 一般ユーザーには表示しない

削除申請一覧は管理者専用。

```text
role=user → 表示しない
未ログイン → 表示しない
ローカルユーザー → 表示しない
```

## UI仕様

- 管理者が申請状況を見つけやすい
- pending件数が目立つ
- 承認・拒否が分かりやすい
- 危険操作に見えるが、実削除ではないことを明示する
- 既存テーマに合わせる
- スマホ幅でも最低限確認できる

## 受け入れ条件

- 管理者ページに `アカウント削除申請` セクションが表示される
- pending申請件数が表示される
- 削除申請一覧が表示される
- ユーザー名・メールアドレスで検索できる
- 状態でフィルターできる
- 申請詳細が表示される
- pending申請に `承認する` / `拒否する` ボタンが表示される
- 承認時にstatusがapprovedになる
- 拒否時にstatusがrejectedになる
- 承認・拒否時に確認ダイアログが出る
- 管理者メモを保存できる
- Authユーザーは削除されない
- 一般ユーザーには削除申請一覧が表示されない
- service role key をフロントに出していない
- `node --check` が通る
- ビルド番号を +1 する
- `docs/ticket_status.json` にこのチケットを追加し、初期状態を `未修整` にする
