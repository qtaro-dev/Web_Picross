# チケット113：実プレイ画面のレスポンシブ基準整理

## 目的

実プレイ画面を、1024×768〜1920×1080程度の画面サイズで遊びやすくするため、レイアウト調整の基準を整理する。

特に、1366×768のノートPC環境でも重要UIが切れず、大きい盤面でも操作しやすい状態を目指す。

## 対象ファイル（推定）

- `index.html`
- `styles.css`
- `js/render.js`
- `js/actions.js`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

- 実プレイ画面の想定表示サイズを以下の範囲として整理する。
  - 最低想定：1024×768
  - 標準ノートPC想定：1366×768
  - 中間想定：1600×900
  - 最大想定：1920×1080
- 実プレイ画面では、盤面表示領域を最優先とする。
- 左操作UI、カラーパレット、盤面周囲の余白が、盤面表示を過度に圧迫しないようにする。
- 画面幅や高さが不足する場合でも、重要操作が画面外に完全に隠れないようにする。
- 既存テーマ・背景・ボタンデザインは維持する。
- 既存ゲームロジックは変更しない。
- 判定ボタンの内部挙動は本チケットでは変更しない。

## 受け入れ条件（目視確認基準）

### 1024×768

- 実プレイ画面を表示する。
- 重要操作UIが画面外に完全に隠れていないこと。
- 盤面が極端に小さくなりすぎず、拡大縮小操作と併用してプレイ可能であること。
- 画面全体の横スクロールに依存しすぎないこと。

### 1366×768

- 実プレイ画面を表示する。
- 左操作UI、パレット、盤面が大きく干渉しないこと。
- 大きめの盤面でも、UIを調整すれば遊べること。
- 重要ボタンがブラウザ下端や右端で切れないこと。

### 1600×900

- 通常表示で大きめの盤面がある程度快適に見えること。
- UIが盤面を過度に押し出さないこと。

### 1920×1080

- 通常表示で実プレイ画面が自然に見えること。
- 盤面、左操作UI、パレットの配置が不自然に離れすぎないこと。
- 既存の見た目が大きく崩れていないこと。
