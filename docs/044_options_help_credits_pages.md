## オプション画面仕様

### 1. クロスヘアの色設定

パズル中のクロスヘア色を変更できる設定を用意する。

表示項目:

```text
クロスヘア色
```

候補UI:

```text
- 色選択ボタン
- カラーパレット
- select
- input type="color"
```

最小実装では `input type="color"` でもよい。

期待動作:

```text
クロスヘア色を変更
→ ゲーム中のクロスヘア色に反映
→ 設定値を保存
→ 再読み込み後も設定が維持される
```

保存先:

```text
localStorage
```

または既存のユーザー設定保存がある場合はそこに統合する。

### 2. BGM音量スライダー

BGM音量を調整するスライダーバーを設置する。

表示:

```text
BGM音量
[0 ---- 100]
```

仕様:

```text
- 範囲: 0〜100
- 初期値: 50
- 値を変更したら保存
- 音源未実装の場合でもUIは作る
- 音源が未実装の場合は「BGM未実装」と小さく表示してもよい
```

### 3. SE音量スライダー

SE音量を調整するスライダーバーを設置する。

表示:

```text
SE音量
[0 ---- 100]
```

仕様:

```text
- 範囲: 0〜100
- 初期値: 50
- 値を変更したら保存
- 音源未実装の場合でもUIは作る
- 音源が未実装の場合は「SE未実装」と小さく表示してもよい
```

### 4. 表示モード切り替え

表示モードを切り替えるUIを設置する。

対象:

```text
- フルスクリーン
- ボーダーレスウィンドウ
- ウィンドウモード
```

注意:

Webブラウザ上ではOSネイティブの「ボーダーレスウィンドウ」は直接制御できない。  
そのため、Web版では以下のように扱う。

```text
フルスクリーン:
- Fullscreen APIで可能な範囲で実装

ボーダーレスウィンドウ:
- Web版では疑似モードとして扱う
- 余白や枠を減らした表示モードとして実装
- OSウィンドウ枠は制御しない

ウィンドウモード:
- 通常表示へ戻す
```

表示例:

```text
表示モード
[フルスクリーン] [ボーダーレス] [ウィンドウ]
```

期待動作:

```text
フルスクリーン
→ ブラウザのフルスクリーン表示を試行

ボーダーレス
→ アプリ領域を疑似ボーダーレス表示に切り替え

ウィンドウ
→ 通常表示へ戻す
```

### 5. 設定の保存と復元

オプション設定はブラウザに保存し、次回起動時に復元する。

保存項目:

```json
{
  "crosshairColor": "#00aaff",
  "bgmVolume": 50,
  "seVolume": 50,
  "displayMode": "window"
}
```

保存キー候補:

```text
web_picross_options
```

### 6. 初期値に戻すボタン

可能であれば、オプション画面に初期値に戻すボタンを設置する。

表示:

```text
初期値に戻す
```

動作:

```text
クリック
→ クロスヘア色、BGM音量、SE音量、表示モードを初期値へ戻す
→ 保存値も更新
```

## ヘルプ画面仕様

### 1. ピクロス自体のルール説明

ヘルプ画面には、ピクロスの基本ルールを説明する。

入れる内容:

```text
- 数字は、その行または列に連続して塗るマス数を表す
- 複数の数字がある場合は、塗るかたまりが複数ある
- 数字と数字のかたまりの間には、最低1マス以上の空白が入る
- 正しいマスをすべて塗るとクリア
- 塗らないと分かったマスには×を付けられる
```

### 2. このゲームアプリ自体の説明

このWebピクロスアプリの操作説明を入れる。

入れる内容:

```text
- ゲームセレクトから難易度を選ぶ
- パズルを選んでプレイ開始
- 左クリックで塗る / 解除
- 右クリックで×を付ける / 解除
- 左ドラッグで連続塗り
- 右ドラッグで連続×
- 判定ボタンで正解判定
- 全消去で入力をリセット
- ヒントで一部の正解を表示
- ギブアップでプレイを終了
- クリアするとユーザーデータに記録される
```

### 3. カラーピクロスの説明

カラーピクロスがあるため、カラーの説明も入れる。

入れる内容:

```text
- カラー問題では、右側のパレットから色を選んで塗る
- 数字の背景色が、その列や行で使う色を表す
- 右クリックの×は色に関係なくマークとして使う
```

### 4. ヘルプの見た目

読みやすいように、セクションごとに分ける。

セクション候補:

```text
- ピクロスの基本ルール
- 操作方法
- カラーピクロス
- ユーザーデータ
```

## クレジット画面仕様

### 1. 映画風の流れるクレジットを作る

クレジット画面では、下から上にゆっくり流れる映画のようなクレジット表示を行う。

仕様:

```text
- 画面下から文字が出てくる
- ゆっくり上へ流れる
- 最後まで流れたら最初に戻ってループ
- ずっとループする
- メニューへ戻れる
```

注意:

- CSS animationで実装してよい
- 既存テーマに合わせた黒背景・白文字
- 戻るボタンはアニメーションに巻き込まれず固定表示
- 文字が読みづらい速度にしない

### 2. クレジット内容

以下の内容を入れる。

```text
Web Picross

制作
Qtaro

コーディング
CODEX

要件定義
ChatGPT

仕様作成
ChatGPT

開発支援
ChatGPT

テスト・確認
Qtaro

Special Thanks
AI Development Tools
```

表記は既存の日本語UIに合わせる。

### 3. ループ仕様

クレジットは最後まで流れた後、自動的に最初から再生される。

CSS例:

```css
animation: credits-scroll 40s linear infinite;
```

秒数は見やすさを優先して調整する。

### 4. メニューへ戻る

クレジット再生中でも、左上の「← メニューへ戻る」ボタンでメニューに戻れること。
