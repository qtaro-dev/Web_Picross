# チケット114：実プレイ画面の左操作パネル折りたたみ対応

## 目的

大きい盤面でプレイする際に、左操作パネルが盤面表示領域を圧迫しないよう、実プレイ画面の左操作UIを折りたたみ可能にする。

1024×768や1366×768など、画面が狭い環境でも盤面を広く使える状態を目指す。

## 対象ファイル（推定）

- `index.html`
- `styles.css`
- `js/render.js`
- `js/actions.js`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

- 実プレイ画面の左操作パネルを開閉可能にする。
- 開閉用のボタンを追加する。
  - 表示例：`操作パネルを隠す`
  - 表示例：`操作パネルを表示`
- 左操作パネルを閉じた状態でも、最低限ゲームを継続できるようにする。
- 閉じる対象は、以下のような左側操作群を想定する。
  - 残り時間
  - やりなおし
  - 判定
  - ヒント
  - ギブアップ
  - メニューへ戻る
  - セレクトに戻る
- 開閉状態は、可能であれば `localStorage` に保存する。
- 盤面サイズや画面幅に応じて、自動的に閉じる処理を入れる場合は、既存挙動を壊さない最小限の実装にする。
- 既存のボタン文言、ゲーム進行、判定処理、ヒント処理は変更しない。
- 判定ボタンの内部挙動調整は別チケット扱いとし、本チケットでは行わない。

## 受け入れ条件（目視確認基準）

### 通常表示

- 実プレイ画面を開く。
- 左操作パネルが従来どおり表示されていること。
- 既存の各ボタンが押せること。

### 折りたたみ操作

- `操作パネルを隠す` 相当のボタンを押す。
- 左操作パネルが非表示、またはコンパクト表示になること。
- 盤面表示領域が広くなること。
- 盤面のクリック位置がズレないこと。

### 再表示操作

- `操作パネルを表示` 相当のボタンを押す。
- 左操作パネルが再表示されること。
- 再表示後も各ボタンが押せること。

### 再読み込み

- 左操作パネルを閉じた状態でページを再読み込みする。
- `localStorage` 対応を行った場合、閉じた状態が維持されること。
- `localStorage` 対応を行わない場合は、仕様としてREADMEまたはチケット状態に明記すること。

### 画面サイズ確認

- 1024×768で、左操作パネルを閉じると盤面が広く使えること。
- 1366×768で、左操作パネルを閉じると横スクロールの負担が軽くなること。
- 1920×1080で、通常表示が不自然に崩れないこと。
