# チケット124：判定結果メッセージを正解率に応じて変更

## 目的

チケット123で判定結果から具体的な間違い数・未入力数を削除したが、現在の `まだ違うところがあります` という文言は少し硬く、ゲーム中のフィードバックとして自然さに欠ける。

判定ボタン押下時の表示を、具体的な数値は出さないまま、正解率や状態に応じて柔らかい文言へ変更する。

## 対象ファイル（推定）

- `js/actions.js`
- `js/render.js`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. 判定結果メッセージを正解率に応じて変更する

- 判定ボタン押下時、正解率に応じて表示文言を変える。
- 具体的な間違い数・未入力数・残りマス数は表示しない。
- 正解率は、原則として以下を基準に算出する。
  - `正しく塗れているマス数 / 正解で塗るべきマス数`
- Xマークはチケット122の仕様どおり、塗り扱いにしない。
- 空白正解セル上のXは誤り扱いしない。
- 正解セル上のXは塗り扱いにせず、未完成扱いにする。

### 2. 表示文言の候補

- 完全正解：
  - `正解です！`
- 正解率90%以上：
  - `あと少しです`
- 正解率70%以上：
  - `いい感じに進んでいます`
- 正解率40%以上：
  - `まだ見直しが必要です`
- 正解率1%以上：
  - `もう少し塗ってみましょう`
- 正解率0%、またはほぼ未入力：
  - `まだ完成していません`

### 3. 誤って塗っているセルがある場合の文言

- 塗ってはいけないセルを塗っている場合、またはカラー問題で色違いの塗りがある場合は、正解率が高くても誤塗り向けの文言を優先する。
- 表示文言：
  - `塗ったマスを少し見直してみましょう`
- この文言でも、具体的な間違い数や場所は表示しない。
- 判定連打で攻略ヒントになりすぎないようにする。

### 4. 完全正解時のクリア処理を維持する

- 完全正解時は `正解です！` を表示し、既存のクリア処理へ進む。
- クリア後の進行状況保存、ランキング保存、タイム記録などは既存挙動を維持する。
- 管理者機能やデバッグ機能に影響を出さない。

### 5. 既存仕様を壊さない

- チケット122のX判定仕様を維持する。
- チケット123の「具体的な数を出さない」方針を維持する。
- セルクリック、右クリック、ドラッグ操作を維持する。
- カラー問題の判定を維持する。
- Endlessの大盤面判定を維持する。
- 判定、ヒント、ギブアップ、やりなおし、メニューへ戻る、セレクトに戻るの動作は変更しない。
- ペナルティや時間減少は本チケットでは実装しない。
- チャレンジモード新設は本チケットでは行わない。
- 既存テーマ・ライブラリ構成を維持する。
- ハードコード文字列は禁止。
- ICommand構造を崩さない。

## 受け入れ条件（目視確認基準）

### 完全正解

- ユーザーが問題を完全に正しく解く。
- ユーザーが判定ボタンを押す。
- OK：`正解です！` と表示されること。
- OK：従来どおりクリア処理へ進むこと。
- NG：正解なのに別文言になること。

### 正解率90%以上

- ユーザーが正解にかなり近い状態まで塗る。
- 誤って塗っているセルは作らない。
- ユーザーが判定ボタンを押す。
- OK：`あと少しです` と表示されること。
- NG：具体的な残りマス数が表示されること。

### 正解率70%以上

- ユーザーがある程度正しく塗る。
- 誤って塗っているセルは作らない。
- ユーザーが判定ボタンを押す。
- OK：`いい感じに進んでいます` と表示されること。
- NG：具体的な正解率や残り数が表示されること。

### 正解率40%以上

- ユーザーが半分前後まで正しく塗る。
- 誤って塗っているセルは作らない。
- ユーザーが判定ボタンを押す。
- OK：`まだ見直しが必要です` と表示されること。
- NG：間違い数や未入力数が表示されること。

### 正解率1%以上

- ユーザーが少しだけ正しく塗る。
- 誤って塗っているセルは作らない。
- ユーザーが判定ボタンを押す。
- OK：`もう少し塗ってみましょう` と表示されること。
- NG：具体的な数値が表示されること。

### 未入力またはほぼ未入力

- ユーザーがほとんど塗らない状態で判定ボタンを押す。
- OK：`まだ完成していません` と表示されること。
- NG：`まだ違うところがあります` のような硬い文言が残ること。

### 誤って塗っているセルがある場合

- ユーザーが塗ってはいけないセルを塗る。
- ユーザーが判定ボタンを押す。
- OK：`塗ったマスを少し見直してみましょう` と表示されること。
- OK：具体的な間違い数は表示されないこと。
- NG：`間違い3個` などの数値が表示されること。

### カラー問題の色違い

- ユーザーがカラー問題を開く。
- 正解セルとは違う色でセルを塗る。
- ユーザーが判定ボタンを押す。
- OK：`塗ったマスを少し見直してみましょう` と表示されること。
- OK：色違い数などの具体情報は表示されないこと。

### Xマークとの整合性

- ユーザーが空白正解セルにXを置く。
- ユーザーが判定ボタンを押す。
- OK：X自体は誤り扱いされないこと。
- ユーザーが正解セルにXを置く。
- ユーザーが判定ボタンを押す。
- OK：完成扱いにはならないこと。
- OK：正解率に応じた未完成系メッセージになること。

### 判定連打

- ユーザーが未完成状態で判定ボタンを複数回押す。
- OK：文言は進捗感を示すだけで、具体的な数値を表示しないこと。
- OK：判定連打で攻略ヒントになりすぎないこと。
- NG：押すたびに誤り数や未入力数が分かること。

### 回帰確認

- ユーザーがBeginner / Easy / Normal / Hard / Endlessを一通り開く。
- OK：判定ボタンが従来どおり押せること。
- OK：完全正解時のクリア処理が壊れていないこと。
- OK：ヒント、ギブアップ、やりなおし、メニューへ戻る、セレクトに戻るが従来どおり動くこと。
