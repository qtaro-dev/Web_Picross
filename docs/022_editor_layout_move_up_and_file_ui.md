# チケット22: エディタモードの上部余白削減と読込UI・説明文配置整理

## 目的

エディタモード画面の上部に空白領域が多いため、全体レイアウトを上へ詰めて、作業領域を見やすくする。

あわせて、ファイル選択とJSON読込のUIを上部へ移動し、その右側に保存仕様の説明文を配置する。

表示したい説明文:

```text
スロット保存は画面内データへの反映です。
PC上のJSONファイルを更新するにはJSON出力したファイルを保存してください。
```

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\editor.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. エディタ画面全体を上へ移動する

現在、エディタ画面上部に大きな空白があるため、メインUIをより上に配置する。

期待動作:

```text
- エディタUIが画面上部寄りに表示される
- 左カラム、中央操作、盤面が上へ詰まる
- 画面下部の無駄なスクロールが減る
```

注意:

- 「← メニューへ」ボタンと重ならない
- ブラウザ上部やスクロールバーに不自然に被らない
- 既存の黒背景・枠線テーマを維持する

### 2. ファイル選択・JSON読込を上部に配置する

ファイル選択とJSON読込ボタンを、エディタ上部の分かりやすい位置へ移動する。

期待配置:

```text
上部左寄り:
[ファイルを選択] [JSON読込]
```

または、左カラム上端と横並びでもよい。

注意:

- チケット20で左カラム側へ整理した場合でも、今回の要望では「上に移動」を優先する
- 読み込み済みJSONスロット一覧と関連が分かる位置にする
- ファイル未選択時の表示を維持する

### 3. 保存仕様の説明文をファイル読込UIの右側へ配置する

ファイル選択・JSON読込の右側に、以下の説明文を表示する。

```text
スロット保存は画面内データへの反映です。
PC上のJSONファイルを更新するにはJSON出力したファイルを保存してください。
```

注意:

- 1行目と2行目の間で改行する
- 文字が横に長くなりすぎないようにする
- 既存テーマに合う小さめの説明テキストにする
- 目立ちすぎないが、読めること

### 4. 中央操作UIと盤面の位置を調整する

上部UIの移動に合わせて、以下が重ならないように調整する。

```text
- 盤面サイズ
- サイズ変更
- 全消去
- モード切替
- 難易度
- 種別
- 面数
- パズル名
- JSON出力ボタン
- エディットプレイ
- 盤面
```

注意:

- 横に詰め込みすぎない
- 盤面が大きい場合でも操作UIに被らない
- 左カラムのスロット一覧と中央UIが重ならない

### 5. レスポンシブ崩れを避ける

ブラウザ幅が広い場合を優先しつつ、狭めた場合も大きく破綻しないようにする。

## 受け入れ条件

- エディタ画面の上部空白が減っている
- エディタUIが今より上寄りに表示される
- ファイル選択が上部に表示される
- JSON読込ボタンが上部に表示される
- ファイル選択・JSON読込の右側に説明文が表示される
- 説明文が2行に分かれている
- 左カラムのスロット一覧が壊れない
- 中央盤面が壊れない
- JSON読込が従来どおり動く
- スロット保存が従来どおり動く
- JSON出力が従来どおり動く
- エディットプレイ導線が壊れない
- `node --check js/render.js` が通る
- `node --check js/editor.js` が通る
- 変更したJSファイルすべてで `node --check` が通る
