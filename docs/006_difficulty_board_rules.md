# チケット6: 難易度別の盤面サイズ・カラー設定の再定義

## 目的

現在、エディタ画面で難易度や種別を選択できるが、難易度ごとの盤面サイズ候補やカラー可否の定義が不足している。  
各難易度ごとに使用可能な盤面サイズと、モノクロ / カラーの可否を明確に定義し、エディタ・通常問題・エディットプレイで同じ基準を使えるようにする。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\editor.js`
- `E:\Dev\web_picross_Ver2\js\data.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 難易度別定義

以下の定義を基準にする。

```text
ビギナー:
- 5x5
- 5x10
- モノクロのみ
- カラー無し

イージー:
- 10x10
- 5x10

ノーマル:

ハード:

エンドレス:

- モノクロ・カラー
- 最大 50x50 まで
```

## 実装内容

### 1. 難易度設定の定義を共通化する

難易度ごとの設定を、JS内で一元管理する。

定義に含める候補:

```text
- difficulty key
- 表示名
- 選択可能な盤面サイズ一覧
- カラー可否
- モノクロ可否
- 最小サイズ
- 最大サイズ
```

既存に難易度定義がある場合は、それを拡張する。  
同じ定義を複数ファイルに重複して書かないこと。

### 2. 最大マス目数を 50x50 までに制限する

エンドレスであっても、最大サイズは 50x50 までとする。

注意:

- 50x50を超えるサイズを入力できないようにする
- 不正値が入った場合は、安全な値に補正するかエラー表示する
- 最小値も極端に小さくならないよう、既存仕様に合わせて安全に扱う

### 3. カラー可否を難易度に連動させる

ビギナーとイージーではカラー選択不可にする。

期待動作:

```text
ビギナー: モノクロのみ
イージー: モノクロのみ
ノーマル: モノクロ / カラー
ハード: モノクロ / カラー
エンドレス: モノクロ / カラー
```

注意:

- カラー不可の難易度では、カラー選択UIを無効化する
- カラー不可の難易度に変更したら、自動でモノクロへ戻す
- 既存データにカラー指定があっても、難易度側で不可なら安全に扱う

### 4. 既存のパズルデータ互換を維持する

既存データに難易度・盤面サイズ・カラー種別が不足していても読み込めるようにする。

不足時の候補:

```text
- difficulty が無い場合: beginner または既存の読み込み文脈に合わせる
- colorMode が無い場合: mono
- width / height が無い場合: 既存盤面から推定
```

## 受け入れ条件

- 難易度ごとの盤面サイズ定義が共通化されている
- ビギナーでは 5x5 / 5x10 が基準になる
- イージーでは 10x10 / 5x10 / 10x5 が基準になる
- ノーマルでは 15x10 / 10x10 / 5x10 / 10x5 が基準になる
