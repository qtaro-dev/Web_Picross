# チケット83: 管理者ページにアカウント削除申請一覧が表示されない問題の修正

## 目的

一般ユーザーがアカウント削除申請を送信したあと、管理者ページ上でその申請が確認できるようにする。

現在、ユーザー側で削除申請操作は完了しているように見えるが、管理者ページに「削除申請が届いている」表示や申請一覧が出ていないため、申請の保存・取得・表示の流れを確認して修正する。

## 背景

想定している動作は以下。

```text
testuser2 がユーザーデータ画面でアカウント削除申請
↓
account_delete_requests に pending 申請が保存される
↓
管理者ユーザーで管理者ページを開く
↓
「testuser2 から削除申請が届いています」のように表示される
↓
管理者が申請許可 / 拒否を選べる
```

しかし現状では、管理者ページ上に削除申請が表示されていない。

考えられる原因:

```text
account_delete_requests に申請が保存されていない
保存はされているが管理者ページで取得していない
取得しているがUIに表示していない
RLSで管理者がselectできていない
管理者ページの表示セクションが未配置
フィルター条件が pending 申請を除外している
```

## 前提

- チケット80で `account_delete_requests` テーブルが追加済みであること
- チケット81で管理者ページの削除申請一覧UIが実装済み、または実装予定であること
- チケット82で申請承認時の利用停止処理が実装済みであること
- 管理者判定は `profiles.role = 'admin'` を使う
- service role key はフロントに出さない

## 実装内容

### 1. 削除申請がDBへ保存されているか確認する

ユーザー側で削除申請したあと、`account_delete_requests` にレコードが入るか確認する。

確認対象:

```text
user_id
username
display_name
email
status = pending
requested_at
created_at
updated_at
```

もし保存されていない場合は、ユーザー側の削除申請処理を修正する。

### 2. 管理者ページで削除申請を取得する

管理者ページ読み込み時、または再読込ボタン押下時に `account_delete_requests` を取得する。

取得条件の例:

```text
全件取得
または status = pending を優先表示
```

表示上は pending を目立たせる。

### 3. 管理者ページに削除申請セクションを表示する

管理者ページ内に以下のセクションを追加、または既存セクションを正しく表示する。

```text
アカウント削除申請
```

表示項目:

```text
申請日時
ユーザー名
表示名
メールアドレス
状態
管理者メモ
申請ID
ユーザーID
```

### 4. pending件数を表示する

pending状態の申請がある場合、管理者ページ上部に件数を表示する。

表示例:

```text
アカウント削除申請が 1 件届いています
```

対象ユーザー名が分かる場合は、一覧上で以下のように表示する。

```text
testuser2 から削除申請が届いています
```

### 5. 承認・拒否ボタンを表示する

pending申請には以下のボタンを表示する。

```text
申請許可
申請拒否
```

承認・拒否の処理自体はチケット82の仕様に合わせる。

承認時:

```text
account_delete_requests.status = approved
profiles.account_status = disabled
```

拒否時:

```text
account_delete_requests.status = rejected
profiles は変更しない
```

### 6. RLSエラーを分かりやすく表示する

RLSや権限不足で取得できない場合、管理者ページ上に日本語で表示する。

表示例:

```text
アカウント削除申請を取得できませんでした。
RLSポリシーで管理者のselectが許可されているか確認してください。
```

### 7. 取得結果が0件の場合の表示

申請が0件の場合は、何も表示しないのではなく、以下のように表示する。

```text
現在、アカウント削除申請はありません
```

## UI仕様

- 管理者ページ内で削除申請が見つけやすい
- pending申請は目立つ
- 申請者のユーザー名・メールアドレスが分かる
- 申請許可 / 申請拒否の操作が分かりやすい
- 既存テーマを壊さない
- スマホ幅でも最低限確認できる

## 受け入れ条件

- 一般ユーザーが削除申請すると `account_delete_requests` に pending レコードが保存される
- 管理者ページで pending 申請が表示される
- 管理者ページ上部または該当セクションに pending 件数が表示される
- testuser2 が申請した場合、管理者ページで testuser2 の申請が確認できる
- 申請が0件の場合、「現在、アカウント削除申請はありません」と表示される
- RLSなどで取得失敗した場合、日本語エラーが表示される
- pending申請に `申請許可` / `申請拒否` ボタンが表示される
- `申請許可` はチケット82の利用停止処理につながる
- `申請拒否` は profiles を変更しない
- 一般ユーザーには削除申請一覧が表示されない
- service role key をフロントに出していない
- 既存のユーザー管理・ランキング管理が壊れていない
- `node --check` が通る
- ビルド番号を +1 する
- `docs/ticket_status.json` にこのチケットを追加し、初期状態を `未修整` にする

## 確認手順

```text
1. 一般ユーザー testuser2 でログイン
2. ユーザーデータ画面でアカウント削除申請を送信
3. Supabaseの account_delete_requests に pending 申請があるか確認
4. 管理者ユーザーでログイン
5. 管理者ページを開く
6. testuser2 の削除申請が表示されることを確認
7. 申請許可 / 申請拒否ボタンがあることを確認
```
