# チケット49: ゲームセレクト画面のレイアウト崩れ修正

## 目的

背景画像を設定した影響で、ゲームセレクト画面のレイアウトが大きく崩れている。

現在はスクリーンショットのように、メニューへ戻るボタン、難易度ボタン、ページ表示、パズルカードの位置関係が不自然になっているため、ゲームセレクト画面の配置を再整理する。

背景画像は `E:\Dev\web_picross_Ver2\image` 配下のファイルを使用する。

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\js\actions.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 実装内容

### 1. ゲームセレクト画面の基本配置を修正する

ゲームセレクト画面は以下の順番で縦に配置する。

```text
1. 左上: ← メニューに戻る
2. 上部中央: 難易度ボタン
3. 難易度ボタンの下: ページ数と左右矢印
4. ページ表示の下: クリア数表示
5. その下: パズルデータのカードパネル一覧
6. 各パズルカードの下: パズル番号、必要に応じてパズル名
```

### 2. 「← メニューに戻る」を左上に固定する

仕様:

```text
- 画面左上に配置する
- 背景画像の影響を受けて中央寄りにならないようにする
- 他のUIと重ならないようにする
```

### 3. 難易度ボタンを上部中央に配置する

仕様:

```text
- ビギナー、イージー、ノーマル、ハード、エンドレスを横並びにする
- 画面上部中央に配置する
- 背景画像の影響で上下にズレないようにする
```

### 4. ページ数と左右矢印を難易度の下に配置する

仕様:

```text
- 難易度ボタンの下に左右矢印とページ数を配置する
- 例: ◀ 1 / 1 ▶
- ボタンと数字の間隔を自然に揃える
```

### 5. クリア数表示をページ表示の下に配置する

仕様:

```text
- ページ表示の下に `クリア数 3 / 20` のように表示する
- 横幅が不自然に広がらないようにする
- 中央揃えにする
```

### 6. パズルカード一覧を整列させる

仕様:

```text
- パズルカードは中央寄せでグリッド表示する
- 画面幅に応じて自然に折り返す
- 背景画像の上でも見やすいようにする
- カード間の余白を統一する
- スクロールしても表示が破綻しない
```

推奨:

```css
display: grid;
grid-template-columns: repeat(4, ...);
gap: ...
justify-content: center;
```

レスポンシブ対応を行う場合は、画面幅に応じて列数を調整する。

### 7. パズル番号とパズル名の表示仕様を整理する

未クリアの場合:

```text
#03
#04
```

クリア済みの場合:

```text
#01 クロス
#02 カラー...
```

仕様:

```text
- 未クリアはステージ番号のみ表示する
- クリア済みはステージ番号 + パズル名を表示する
- パズル名が長い場合は省略表示する
- パズル番号とパズル名はカードの下に表示する
- 表示位置をカードごとに揃える
```

### 8. 背景画像は最背面に固定する

背景画像は `E:\Dev\web_picross_Ver2\image` 配下のファイルを使用する。

仕様:

```text
- 背景画像は最背面
- UIは背景より前面
- 背景画像はクリックに干渉しない
- 背景は暗めに表示する
- background-size: cover 相当
```

### 9. 既存機能を壊さない

以下の機能を維持する。

```text
- 難易度切り替え
- ページ切り替え
- パズルカード選択
- クリア済み表示
- 未クリアサムネイル非表示
- クリア済みサムネイル表示
- メニューへ戻る
```

## 受け入れ条件

```text

- 未クリアはパズル番号のみ表示される

- 背景画像が表示される

- ゲームセレクトからゲーム開始できる
- 難易度切り替えとページ切り替えが動作する
```
