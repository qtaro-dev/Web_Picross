# 管理者機能

管理者ページはSupabase Authログインかつ `profiles.role = admin` のユーザー専用です。

## 主な管理機能

- ユーザー一覧、進行状況、プレイ履歴、ランキング記録の確認
- 表示名、権限、進行状況、ランキングタイムの更新
- ユーザー別ランキング記録の削除
- アカウント削除申請の確認、承認、拒否
- 利用停止ユーザーの復活
- 管理者再設定メール送信
- 管理者メール修復
- パズルJSONアップロード
- お知らせ作成、編集、削除、公開設定
- お知らせ画像アップロードとStorage削除

## 初期管理者の作成

1. Supabase Dashboardを開きます。
2. Table Editorで `profiles` を開きます。
3. 管理者にしたいユーザーの `role` を `user` から `admin` に変更します。
4. アプリへ再ログインします。
5. メニューに「管理者ページ」が表示されることを確認します。

## 注意事項

- service role keyはフロントエンドへ配布しません。
- 管理者サーバーAPIはBearerトークン、`profiles.role = admin`、`profiles.account_status = active` を確認します。
- 管理者ユーザーの通常クリア記録はランキングへ新規保存しません。
- F1デバッグクリアはSupabase管理者ユーザーだけが利用できます。
