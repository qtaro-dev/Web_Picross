# チケット14: エディタモードのパズルデータ一覧カラム追加

## 目的

エディタモードで対象のパズルデータJSONを読み込んだ際、そのJSON内に含まれるパズル一覧を左カラムに表示する。  
一覧から対象パズルを選び、読込ボタンを押すと、中央のエディタ盤面にそのパズル内容が反映されるようにする。

現在の「保存済み」表示は、あくまでブラウザ内の一時保存データとして扱う。  
JSONファイルから読み込んだパズル一覧とは役割を分け、UI上でも混同しないように整理する。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\editor.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\data.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. JSON読込後にパズル一覧を保持する

エディタでJSONファイルを読み込んだら、そのJSON内のパズル配列をstate等に保持する。

保持する情報候補:

```text
- id
- stageNo
- title / name
- difficulty
- colorMode / mode
- width / height または w / h
```

注意:

- 読み込み時にチケット12の正規化処理を利用できるなら利用する
- 既存形式とエディタ出力形式の両方を扱えるようにする
- 読み込み直後に自動で1問目を盤面へ反映するかどうかは既存挙動に合わせる

### 2. 左カラムに「読み込み済みパズル一覧」を表示する

エディタ画面の左側に、読み込んだJSON内のパズル一覧を表示する。

表示例:

```text
読み込み済みパズル
[ #1 クロス ]
[ #2 ちいさいクロス ]
[ #3 ... ]

[読込]
```

一覧項目の表示候補:

```text
#stageNo タイトル
difficulty / サイズ / モード
```

ただし、画面が狭くなりすぎる場合は短縮表示でよい。

### 3. 一覧選択 + 読込ボタンで中央盤面へ反映する

左カラムでパズルを選び、読込ボタンを押したら、選択中のパズルを中央のエディタ盤面に反映する。

反映対象:

```text
- 盤面サイズ
- 正解セル配置
- パズル名
- 難易度
- 面数 / stageNo
- モノクロ / カラー
- 選択色やカラーパレット状態
```

注意:

- 既存のJSON読込機能を壊さない
- 読込後、サイズセレクトや難易度セレクトもデータに合わせて更新する
- カラー問題の場合はカラーIDも復元する
- モノクロ問題の場合は従来の塗り状態として復元する

### 4. 「保存済み」は一時保存データとして扱う

現在UIにある「保存済み」は、ブラウザ内の一時保存データとして扱う。

整理方針:

```text
- JSONファイルから読み込んだ一覧: 読み込み済みパズル一覧
- localStorage等に保存した一覧: 一時保存データ / 一時保存一覧
```

可能ならラベルを変更する。

例:

```text
保存済み
↓
一時保存
```

注意:

- 保存済みデータの機能自体は壊さない
- JSON読込一覧と一時保存一覧を混同しない
- どちらから読み込んだか、ユーザーが分かる表示にする

### 5. レイアウトを整理する

エディタ画面は情報量が増えているため、左カラム・中央盤面・右側操作の配置を大きく崩さないよう整理する。

方針:

```text
左カラム:
- 読み込み済みパズル一覧
- 一時保存一覧

中央:
- エディタ盤面

上部:
- サイズ、難易度、モード、保存、JSON読込などの操作
```

大規模な全面作り直しは避け、現状UIを維持しながら最小限で追加する。
