# チケット111：エディタ盤面の拡大・縮小操作追加

## 背景

エディタ画面では、盤面サイズが大きくなるとセルが見づらくなる。特に50×50などの大きな盤面では、全体確認と細部編集を切り替えながら作業したいため、盤面の拡大・縮小操作が必要。

## 目的

エディタ画面に拡大・縮小ボタンを追加し、盤面データを変更せずに表示倍率だけを調整できるようにする。

## 対象ファイル（推定）

- `js/render.js`
- `js/actions.js`
- `js/state.js`
- `styles.css`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. 拡大・縮小ボタンを追加する

エディタ操作エリアに以下のボタンを追加する。

```text
縮小
100%
拡大
```

または記号表記でもよい。

```text
－
100%
＋
```

### 2. 表示倍率を変更する

拡大・縮小は、盤面のセル表示サイズを変更する。

重要：

```text
盤面サイズ w/h は変更しない
塗りデータは変更しない
表示倍率だけを変更する
```

### 3. 倍率範囲

倍率は極端になりすぎないように制限する。

推奨：

```text
最小: 50%
標準: 100%
最大: 200%
刻み: 10% または 25%
```

### 4. 現在倍率の表示

現在の倍率を画面に表示する。

```text
表示倍率: 100%
```

### 5. スクロールとの併用

拡大時に盤面が画面に収まらない場合は、既存のスクロール表示を利用して編集できるようにする。

NG：

```text
拡大すると盤面がカード外に飛び出して操作不能になる
```

### 6. 状態保存

可能であれば、倍率を `localStorage` に保存する。

キー例：

```text
web_picross_editor_zoom
```

ただし、実装が重くなる場合は画面内状態だけでもよい。

### 7. 既存機能を壊さない

以下の既存機能は維持する。

- セルの塗り操作
- カラー選択
- モノクロ/カラー切替
- サイズ変更
- JSON読込
- JSON出力
- スロット保存
- エディットプレイ

### 8. Build / ドキュメント更新

- `js/config.js` のBuild番号を更新
- `docs/ticket_status.json` に `111` を追加
- 必要に応じてREADMEに追記

## 受け入れ条件（目視確認基準）

### 拡大・縮小

1. エディタ画面を開く
2. 拡大ボタンを押す
3. 縮小ボタンを押す
4. 100%ボタンを押す

OK：

```text
拡大でセルが大きくなる
縮小でセルが小さくなる
100%で標準表示に戻る
表示倍率が画面に表示される
```

NG：

```text
ボタンを押しても見た目が変わらない
盤面サイズそのものが変更される
塗りデータが消える
```

### 編集操作

OK：

```text
拡大状態でもセルを塗れる
縮小状態でもセルを塗れる
カラー選択が反映される
```

NG：

```text
倍率変更後にクリック位置がずれる
別セルが塗られる
セル操作ができなくなる
```

## 備考

このチケットでは、リアルタイムサムネイルプレビューは扱わない。対象は、エディタ盤面の表示倍率操作のみとする。
