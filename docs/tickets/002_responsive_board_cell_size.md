# チケット2: パズル盤面サイズに応じたセルサイズ自動調整

## 目的

パズルの盤面サイズによって、セル1つ1つの大きさを自動で拡大・縮小する。  
5x5、10x10、将来的な15x15以上の盤面でも、画面内に収まり、見やすく操作しやすい表示にする。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. 盤面サイズに応じてセルサイズを決める

現在のパズルサイズをもとに、セルサイズを算出する。

例:

```text
5x5   → 大きめ
10x10 → 標準
15x15 → 小さめ
20x20 → さらに小さめ
```

固定値だけで強引に分岐するのではなく、可能であれば盤面全体の最大表示サイズから逆算する。

### 2. CSS変数の利用を優先する

可能であれば、セルサイズはCSS変数で管理する。

例:

```css
.game-board {
  --cell-size: 24px;
}
```

JS側で盤面サイズに応じて `--cell-size` を設定し、CSS側で各セルに反映する。

### 3. ヒント数字部分も崩れないようにする

セルサイズだけを変えると、上・左のヒント数字と盤面の位置がずれる可能性がある。  
以下も合わせて確認する。

- 上ヒントの列幅
- 左ヒントの行高
- 盤面セルとの整列
- 数字がセルから大きくはみ出さないこと

### 4. 操作性を維持する

セルが小さくなりすぎてクリックしづらくならないようにする。

最低限の目安:

- PCブラウザでクリック可能なサイズを維持する
- 10x10では現在と同程度の操作感を維持する
- 5x5では大きめに表示されてもよい

### 5. 既存ロジックを壊さない

セルの描画サイズ変更にとどめ、以下の既存動作を維持する。

- 左クリック単発で塗りON/OFF
- 右クリック単発で×ON/OFF
- 左ドラッグで連続塗り
- 右ドラッグで連続×
- 塗りと×の排他制御
- 全消去
- 判定

## 受け入れ条件

- 5x5問題でセルが大きめに表示される
- 10x10問題で現在と同程度の見やすさを維持する
- 盤面サイズが変わっても、上ヒントと左ヒントが盤面セルに揃う
- セルが小さくなりすぎて操作不能にならない
- 盤面が操作ボタンや説明文に重ならない
- 左クリック・右クリック・ドラッグ操作が従来どおり動作する
- 塗りと×が同時に成立しない
- 全消去が従来どおり動作する
- 判定が従来どおり動作する
- `node --check js/render.js` が通る
- 変更したJSファイルすべてで `node --check` が通る
- CSS変更後、表示に明らかな崩れがない
