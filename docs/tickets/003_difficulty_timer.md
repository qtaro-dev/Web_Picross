# チケット3: 難易度別の時間表示と制限時間実装

## 目的

ゲーム中画面に残り時間表示欄を追加し、難易度ごとに制限時間を設ける。  
ビギナー・イージーは10分、ノーマル・ハードは30分、エンドレスは無制限とする。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. ゲーム中画面に時間表示欄を追加する

スクリーンショットの赤枠イメージに合わせて、ゲーム中画面の左側または操作エリア上部に残り時間表示欄を作る。

表示例:

```text
残り時間
09:58
```

エンドレスの場合:

```text
残り時間
無制限
```

### 2. 難易度ごとの制限時間を設定する

制限時間は以下とする。

```text
ビギナー: 10分
イージー: 10分
ノーマル: 30分
ハード: 30分
エンドレス: 無制限
```

秒換算の例:

```text
10分 = 600秒
30分 = 1800秒
```

### 3. タイマー状態をstateで管理する

最低限、以下の状態を管理する。

- 現在の難易度
- 制限時間
- 残り時間
- タイマー実行中かどうか
- setInterval等のタイマーID

既存のstate構造に合わせ、無理な大規模変更はしない。

### 4. ゲーム開始時にタイマーを開始する

問題を選択してゲーム画面へ入ったタイミングでタイマーを開始する。

注意:

- 別問題へ移動したときに古いタイマーが残らないこと
- セレクト画面やメニュー画面に戻ったときにタイマーを停止すること
- 同じ画面を再描画してもタイマーが二重起動しないこと

### 5. 残り時間を1秒ごとに更新する

表示は `MM:SS` 形式を基本とする。

例:

```text
10:00
09:59
09:58
```

### 6. 時間切れ時の処理を追加する

残り時間が0になったら、プレイを終了扱いにする。

期待動作:

- 時間切れであることをユーザーに知らせる
- クリア扱いにはしない
- 入力を停止する、またはセレクト画面へ戻す
- 可能であれば「時間切れ」状態を表示する

最小実装でよいが、時間切れをクリア済みにしてはいけない。

### 7. エンドレスではタイマーをカウントダウンしない

エンドレスは無制限とする。

期待動作:

- 表示は `無制限` またはそれに準じる表示
- カウントダウンしない
- 時間切れ処理が発生しない

### 8. クリア時にタイマーを停止する

判定で正解となりクリアした場合は、タイマーを停止する。

注意:

- クリア後も裏でカウントダウンが進まないこと
- クリア後に時間切れ処理が走らないこと

### 9. 全消去ではタイマーをリセットしない

全消去は盤面の入力状態を消す操作とし、タイマーは継続する。

## 受け入れ条件

- ゲーム画面に残り時間表示欄が出る
- ビギナー問題開始時に `10:00` 相当から開始する
- イージー問題開始時に `10:00` 相当から開始する
- ノーマル問題開始時に `30:00` 相当から開始する
- ハード問題開始時に `30:00` 相当から開始する
- エンドレスでは `無制限` と表示され、カウントダウンしない
- 残り時間が1秒ごとに更新される
- 時間切れ時にクリア扱いにならない
- メニューやセレクトに戻ったときにタイマーが停止する
- 別問題を開始してもタイマーが二重起動しない
- クリア時にタイマーが停止する
- 全消去してもタイマーはリセットされない
- 既存のセル操作、判定、全消去が壊れない
- `node --check js/state.js` が通る
- `node --check js/actions.js` が通る
- `node --check js/render.js` が通る
