# チケット115：実プレイ画面のカラーパレット配置変更とコンパクト表示

## 目的

カラー問題で表示されるカラーパレットが右上に固定されていると、大きい盤面で表示領域を圧迫するため、パレット位置と表示形式を調整する。

カラー数が増えても、盤面を押し出しすぎず、1024×768〜1920×1080の範囲で操作しやすい状態を目指す。

## 対象ファイル（推定）

- `index.html`
- `styles.css`
- `js/render.js`
- `js/actions.js`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

- 実プレイ画面のカラーパレットを、右上固定から盤面を圧迫しにくい位置へ移動する。
- 推奨配置は、左操作パネル上部とする。
  - 例：
    - パレット
    - 残り時間
    - やりなおし
    - 判定
    - ヒント
    - ギブアップ
- 左操作パネル折りたたみ時に、パレットも一緒に隠すか、別途コンパクト表示にする。
- カラー数が多い場合でも、パレットが横に広がりすぎないようにする。
  - 折り返し表示
  - コンパクトサイズ
  - スクロール可能な小領域
  - 開閉表示
  のいずれかを検討する。
- モノクロ問題では、不要なパレット表示が画面を圧迫しないようにする。
- 既存の色選択処理は維持する。
- 既存のカラー番号、パレット色、塗り操作の内部データは変更しない。
- 判定ボタンの内部挙動調整は別チケット扱いとし、本チケットでは行わない。

## 受け入れ条件（目視確認基準）

### モノクロ問題

- モノクロ問題を開く。
- 不要なカラーパレットが盤面を圧迫していないこと。
- 塗り操作が従来どおりできること。

### カラー問題

- カラー問題を開く。
- パレットが右上固定ではなく、盤面を圧迫しにくい位置に表示されること。
- 色を選択できること。
- 選択中の色が分かること。
- 色を変えてセルを塗れること。

### パレット表示量

- 使用色が少ないカラー問題で、パレットが自然に表示されること。
- 使用色が多いカラー問題でも、パレットが横に広がりすぎないこと。
- パレットが盤面を右や下へ大きく押し出さないこと。

### 左操作パネル折りたたみとの併用

- 左操作パネルを閉じる。
- パレットの表示が破綻しないこと。
- 必要な場合はパレットを再表示できること。
- パレット再表示後も色選択ができること。

### 画面サイズ確認

- 1024×768で、パレットが重要UIや盤面を大きく隠さないこと。
- 1366×768で、カラー問題をプレイしやすいこと。
- 1920×1080で、配置が不自然に離れすぎないこと。
