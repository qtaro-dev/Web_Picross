# チケット53: ヒント使用時に正解セルと×セルを同時表示する

## 目的

ゲーム中にヒントを使用した際、現在は正解として塗るセルだけが表示される。

これを変更し、ヒント対象になった1行または1列について、正解セルだけでなく、塗らないセルも `×` として同時に表示する。

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\actions.js
E:\Dev\web_picross_Ver2\js\engine.js
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 実装内容

### 1. ヒント対象行・列の未確定セルをすべて確定表示する

ヒントで選ばれた1行または1列について、正解データを参照し、以下のように表示する。

```text
正解セル:
- モノクロの場合は塗りセルとして表示
- カラーの場合は正解色で表示

非正解セル:
- × マークとして表示
```

### 2. 既存入力との整合性を保つ

```text
- 正解セルに誤って×が置かれていた場合は、×を消して正解塗りにする
- 非正解セルに誤って塗りがあった場合は、塗りを消して×にする
- 既に正しい塗り・×がある場合はそのまま維持する
```

### 3. カラーピクロスにも対応する

```text
- 正解セルは該当パレット色で表示
- 非正解セルは×で表示
- 色なしセルは×として確定表示
```

### 4. ヒント使用後にクリア判定と矛盾しないようにする

ヒントで確定したセルは、通常入力と同じく判定対象に含める。

### 5. ヒント表示メッセージを調整する

例:

```text
1列目の正解部分と×を表示しました。
3行目のヒントを表示しました。
```

## 受け入れ条件

```text
- http://127.0.0.1:8000/ で確認できる
- ヒント使用時、対象行または対象列の正解セルが表示される
- ヒント使用時、対象行または対象列の非正解セルに×が表示される
- 既存の誤入力がヒント結果で正しい状態に補正される
- モノクロピクロスで動作する
- カラーピクロスで動作する
- ヒント使用後も判定・クリア判定が壊れない
- node --check が変更したJSファイルすべてで通る
```
