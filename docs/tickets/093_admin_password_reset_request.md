# チケット93：管理者ページからパスワード再設定メールを送信できる機能の追加

## 背景

ユーザーがパスワードを忘れた場合、チケット92でユーザー自身が再設定メールを送信できる導線を追加する。

一方で、ユーザーから問い合わせがあった場合に、管理者ページから対象ユーザーへパスワード再設定メールを送れると運用しやすい。

ただし、管理者が直接パスワードを閲覧・取得することはできないし、行うべきではない。

また、Supabase Auth の管理者APIや service role key をフロントエンドへ出してはいけない。

そのため、このチケットでは「管理者が対象ユーザーへパスワード再設定メールを送信する」機能を対象にする。

## 現在の問題

管理者ページに、ユーザーのパスワード復旧を支援する操作がない。

現在できないこと:

```text
管理者ページから対象ユーザーにパスワード再設定メールを送る
パスワード再設定を促した履歴を管理者が確認する
```

## 期待する動作

管理者ページのユーザー詳細に、以下のボタンを追加する。

```text
パスワード再設定メール送信
```

押下すると確認モーダルを表示し、対象ユーザーのメールアドレス宛にパスワード再設定メールを送信する。

## 実装内容

### 1. 管理者ユーザー詳細にボタンを追加する

管理者ページのユーザー詳細操作欄に、以下のボタンを追加する。

```text
パスワード再設定メール送信
```

表示条件:

```text
Supabase管理者ユーザーのみ表示
対象ユーザーにメールアドレスが存在する場合のみ有効
```

### 2. 確認モーダルを表示する

ボタン押下時に確認モーダルを出す。

表示例:

```text
このユーザーにパスワード再設定メールを送信しますか？
```

対象情報として以下を表示する。

```text
ユーザー名
表示名
メールアドレス
```

### 3. パスワード再設定メールを送信する

対象ユーザーのメールアドレスに、Supabase Auth のパスワード再設定メールを送信する。

実装方式は既存構成に合わせる。

重要:

```text
service role key は絶対にフロントへ出さない
管理者APIを使う場合は、必ず信頼できるサーバー側で実行する
静的フロントだけで危険な実装をしない
```

初期実装では、フロントの anon key で可能な `resetPasswordForEmail` による再設定メール送信を優先する。

もし管理者専用の厳密な制御が必要な場合は、Supabase Edge Functions などのサーバー側処理を別途検討する。

### 4. 送信結果メッセージを表示する

送信成功時:

```text
パスワード再設定メールを送信しました。
```

送信失敗時:

```text
パスワード再設定メールの送信に失敗しました。
```

メールアドレスがない場合:

```text
メールアドレスが登録されていないため送信できません。
```

### 5. 管理者以外は実行できないようにする

UI非表示だけでなく、処理側でも管理者チェックを行う。

管理者以外が内部的に処理を呼び出しても実行しない。

表示例:

```text
この操作は管理者専用です。
```

## 受け入れ条件

### 管理者ユーザー

`AdminQtaro` でログインし、管理者ページを開く。

期待結果:

```text
ユーザー詳細に「パスワード再設定メール送信」ボタンが表示される
```

### メールありユーザー

メールアドレスがあるユーザーを選択し、再設定メール送信を実行する。

期待結果:

```text
確認モーダルが表示される
承認後に再設定メール送信処理が実行される
送信成功メッセージが表示される
```

### メールなしユーザー

メールアドレスがないユーザーを選択する。

期待結果:

```text
送信ボタンを無効化する
または送信時に「メールアドレスが登録されていないため送信できません。」を表示する
```

### 一般ユーザー

一般ユーザーでログインする。

期待結果:

```text
管理者ページに入れない
パスワード再設定メール送信ボタンが表示されない
内部処理を呼び出しても実行できない
```

## メモ

このチケット93では、管理者が対象ユーザーのパスワードを直接見る・知る・取得する機能は作らない。

原則として、管理者は再設定メールを送るだけにする。

管理者が直接パスワードを上書きする方式は、service role key やサーバー側処理が必須になるため、静的フロントだけでは実装しない。
