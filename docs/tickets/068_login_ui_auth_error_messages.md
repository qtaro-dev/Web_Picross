# チケット68: ログインUIと認証エラーメッセージ改善

## 目的

ログイン / ユーザー登録画面の入力順と、Supabase Auth由来の英語エラー表示を改善する。

## 背景

現在のログイン画面は入力欄が以下の順番になっている。

```text
ユーザー名
メールアドレス
パスワード
```

ただし、実際の入力感覚としては以下の順番の方が自然。

```text
ユーザー名
パスワード
メールアドレス
```

また、登録メールアドレスと違うメールアドレスでログインした場合などに、Supabase Auth由来の英語エラーがそのまま表示される。

例:

```text
Invalid login credentials
```

## 対象ファイル（推定）

```text
index.html
js/supabaseAuth.js
js/render.js
js/actions.js
js/config.js
styles.css
```

## 実装内容

- ログイン / ユーザー登録画面の入力欄の並びを変更する
  - 変更前:
    - ユーザー名
    - メールアドレス
    - パスワード
  - 変更後:
    - ユーザー名
    - パスワード
    - メールアドレス
- 登録時 / ログイン時で必要な入力項目が分かりやすい表示にする
- Supabase Auth由来の英語エラーメッセージを日本語化する
- 最低限、以下のエラーを日本語表示に変換する

```text
Invalid login credentials
→ ユーザー名、メールアドレス、またはパスワードが違います
```

- 必要に応じて、以下のような認証系エラーも日本語化する
  - メールアドレス形式不正
  - パスワード文字数不足
  - 既に登録済みのメールアドレス
  - レート制限
  - 通信失敗
- 英語エラーをそのまま画面に出さない
- 既存のSupabase Auth登録 / ログイン処理を壊さない
- Supabase未設定時のローカルログイン導線を壊さない
- ビルド番号を +1 する

## 受け入れ条件

- 入力欄の順番が「ユーザー名 → パスワード → メールアドレス」になっている
- ログイン失敗時に `Invalid login credentials` がそのまま表示されない
- 登録済みメールアドレスと違う場合も日本語で案内される
- ユーザー登録が従来通りできる
- ログインが従来通りできる
- Supabase未設定時のローカル保存ログインが壊れていない
- `node --check` が通る

## 最終報告

- 変更したファイル
- 入力欄の変更内容
- 日本語化したエラー一覧
- Supabaseログイン確認結果
- ローカルフォールバック確認結果
