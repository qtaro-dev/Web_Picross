# チケット121：全難易度の盤面境界線と5マス補助線追加

## 目的

ピクロスでは、ヒントエリアと盤面入力エリアの境界線、および5マスごとの補助太線がないと、大きい盤面で行・列の位置を把握しづらくなる。

全難易度の実プレイ画面で、ヒントエリアと盤面入力エリアの境界を明確にし、盤面入力エリアには5マスごとの補助線を追加して、視認性とプレイしやすさを改善する。

## 対象ファイル（推定）

- `styles.css`
- `js/render.js`
- `js/actions.js`
- `js/state.js`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. ヒントエリアと盤面入力エリアの境界線を追加する

- 全難易度の実プレイ画面で、ヒントエリアと盤面入力エリアの境界線を強調する。
- 対象は以下とする。
  - 上ヒントエリアと盤面入力エリアの境界
  - 左ヒントエリアと盤面入力エリアの境界
- 境界線は、通常グリッド線や5マス補助線よりも優先して見えるようにする。
- 境界線の色は、既存テーマ上で視認しやすい色にする。
- 例：黄色系、または既存アクセントカラーに近い強調色。
- 既存テーマ・背景・盤面デザインを大きく崩さない。

### 2. 盤面入力エリアに5マスごとの補助太線を追加する

- 全難易度の実プレイ画面で、盤面入力エリアに5マスごとの補助線を追加する。
- 対象は以下とする。
  - 5列ごとの縦線
  - 5行ごとの横線
- 補助線は通常グリッド線より少し太く、見分けやすくする。
- 補助線はヒントエリアではなく、盤面入力エリア側に適用する。
- 5×5、5×10、10×10、15×10、20×20、Endlessなど、全サイズで自然に表示されるようにする。
- 盤面サイズが5未満または5の倍数でない場合でも表示崩れしないようにする。

### 3. 境界線と5マス補助線が重ならないようにする

- ヒントエリア境界線と5マス補助線が同じ位置に重ならないようにする。
- 優先順位は以下とする。
  1. ヒントエリアと盤面入力エリアの境界線
  2. 5マスごとの補助太線
  3. 通常グリッド線
- 境界線の位置に5マス補助線を重ねて描画しない。
- 線の太さや色が干渉して、境界線が二重線・にじみ・ズレのように見えないようにする。

### 4. カラー問題でも視認性を維持する

- カラー問題でも境界線と5マス補助線が見えるようにする。
- 塗りセルの色、ヒント数字の背景色、×表示と干渉しないようにする。
- カラーセルを塗った後でも、5マス補助線が極端に見えなくならないようにする。
- ただし、セルの色やヒントの読みやすさを壊さない。

### 5. Endlessのstickyヒントと併用する

- チケット119fix1で実装したEndlessの上ヒント・左ヒントsticky表示と併用しても表示が崩れないようにする。
- Endlessでスクロールしても、境界線と5マス補助線が自然に見えること。
- sticky化されたヒント境界と、盤面入力エリアの補助線がズレないようにする。
- ミニマップの固定レイヤーと干渉しないようにする。

### 6. 既存仕様を壊さない

- セルクリック、右クリック、ドラッグ操作を維持する。
- 盤面の拡大・縮小・100%機能を維持する。
- 左操作パネル折りたたみ機能を維持する。
- Endlessミニマップ機能を維持する。
- スクロール位置保持を維持する。
- 判定、ヒント、ギブアップ、やりなおし、メニューへ戻る、セレクトに戻るの動作は変更しない。
- 判定ボタンの内部挙動調整は本チケットでは行わない。
- 既存テーマ・ライブラリ構成を維持する。
- ハードコード文字列は禁止。
- ICommand構造を崩さない。

## 受け入れ条件（目視確認基準）

### Beginner 5×5

- ユーザーがBeginnerの5×5問題を開く。
- OK：上ヒントと盤面入力エリアの境界線が見えること。
- OK：左ヒントと盤面入力エリアの境界線が見えること。
- OK：盤面が小さくても表示が不自然に太くなりすぎないこと。
- NG：境界線が表示されないこと。
- NG：境界線がセル操作を邪魔すること。

### Easy / Normal 10×10

- ユーザーが10×10前後の問題を開く。
- OK：5マス目ごとの補助線が見えること。
- OK：10マスを数えるときに、5マス区切りが分かりやすいこと。
- OK：通常グリッド線より補助線が見分けやすいこと。
- NG：5マス補助線が表示されないこと。
- NG：補助線がずれて4マス目や6マス目に見えること。

### Normal / Hard 15×10・20×20

- ユーザーが15×10または20×20の問題を開く。
- OK：5マスごとの縦線・横線が盤面入力エリアに表示されること。
- OK：境界線と5マス補助線の違いが分かること。
- OK：大きめの盤面でも、行・列の位置を数えやすいこと。
- NG：補助線がヒントエリアまで不自然に伸びること。
- NG：境界線と補助線が重なって二重線のように見えること。

### カラー問題

- ユーザーがカラー問題を開く。
- ユーザーが複数色でセルを塗る。
- OK：塗った後も5マス補助線が大まかに確認できること。
- OK：境界線がヒントと盤面の境目として見えること。
- OK：色選択・セル塗り・×操作が従来どおり動くこと。
- NG：カラーセルの色が補助線で極端に見づらくなること。
- NG：補助線の影響でヒント数字が読みにくくなること。

### Endless #01 / #02

- ユーザーがEndless #01またはEndless #02を開く。
- OK：上ヒントと盤面入力エリアの境界線が見えること。
- OK：左ヒントと盤面入力エリアの境界線が見えること。
- OK：5マスごとの補助線が盤面入力エリアに表示されること。
- OK：スクロールしても補助線の表示が大きく崩れないこと。
- OK：stickyヒントと境界線がズレないこと。
- NG：Endlessだけ境界線や補助線が消えること。
- NG：stickyヒントと補助線がズレて見えること。

### 境界線と5マス補助線の優先順位

- ユーザーが任意の難易度で盤面を確認する。
- OK：ヒントエリア境界線が最も分かりやすく表示されること。
- OK：5マス補助線は境界線と重ならず、盤面内に表示されること。
- OK：通常グリッド線、5マス補助線、境界線の役割が見分けられること。
- NG：境界線と5マス補助線が同じ位置で重なって見づらくなること。

### 拡大縮小

- ユーザーが任意の盤面で、縮小 / 100% / 拡大を押す。
- OK：倍率変更後も境界線と5マス補助線が表示されること。
- OK：倍率変更後も線の位置がセルとズレないこと。
- NG：拡大縮小後に補助線が消える、またはセル位置からズレること。

### 操作確認

- ユーザーがセルを塗る。
- ユーザーがセルを消す。
- ユーザーが右クリックで×を付ける。
- ユーザーがドラッグで複数セルを塗る。
- OK：クリック位置がズレないこと。
- OK：セル操作が従来どおり動くこと。
- OK：補助線追加によって操作が極端に重くならないこと。
- NG：補助線の影響でセルクリックやドラッグが壊れること。

### 回帰確認

- ユーザーがBeginner / Easy / Normal / Hard / Endlessを一通り開く。
- OK：すべての難易度で盤面が表示されること。
- OK：ミニマップはEndlessのみ表示されること。
- OK：通常難易度のヒント表示が崩れないこと。
- OK：ゲーム進行、判定、ヒント、ギブアップ、やりなおしが従来どおり動くこと。
