# チケット58: ランキング画面のパズル名を非表示にする

## 目的

ランキング画面に表示されている `パズル名` が、未プレイのパズル内容のネタバレになる可能性がある。

そのため、ランキング画面ではパズル名を表示しないようにする。

現状例:

```text
ノーマル #01 とけい
ノーマル #03 テレビ
ノーマル #02 ひこうき
```

修正後は、パズル名を非表示にし、難易度と面番号のみ表示する。

修正後例:

```text
ノーマル #01
ノーマル #03
ノーマル #02
```

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\js\actions.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\server.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 実装内容

### 1. ランキング画面の「現在の自分の順位」からパズル名を非表示にする

ランキング画面上部の `現在の自分の順位` エリアで、パズル名を表示しないようにする。

現状例:

```text
ノーマル #01 とけい　1位 / 3人中　00:19
```

修正後:

```text
ノーマル #01　1位 / 3人中　00:19
```

### 2. ランキング一覧テーブルから「パズル名」列を削除する

ランキング一覧テーブルに表示されている `パズル名` 列を削除する。

現状の列例:

```text
順位
難易度
面
パズル名
クリア時間
ユーザー名
クリア日時
```

修正後の列例:

```text
順位
難易度
面
クリア時間
ユーザー名
クリア日時
```

### 3. API側でパズル名を返している場合の扱い

`server.js` のランキングAPIでパズル名を補完・返却している場合でも、ランキング画面では表示しない。

対応方針はどちらでもよい。

#### 方針A: APIレスポンスには残すが画面には表示しない

```text
- API互換性を壊しにくい
- 今後管理画面などで使える
- 表示側だけ修正
```

#### 方針B: APIレスポンスからも削除する

```text
- ネタバレ情報をクライアントへ送らない
- より厳密
```

推奨は方針A。  
ただし、ネタバレ防止を強めたい場合は方針Bでもよい。

どちらを採用したか、最終報告に明記すること。

### 4. 画面上の表示幅を調整する

`パズル名` 列を削除したことで、ランキング表の幅や列バランスが崩れないように調整する。

確認対象:

```text
- 順位
- 難易度
- 面
- クリア時間
- ユーザー名
- クリア日時
```

### 5. 他画面のパズル名表示は維持する

ランキング画面のみパズル名を非表示にする。

以下の画面では、既存仕様を維持する。

```text
- ゲームセレクト画面
- クリア済みカード表示
- ユーザーデータ画面
- エディタ画面
- ゲーム中タイトル
```

ただし、ユーザーデータ画面にもネタバレ防止が必要と判断される場合は、勝手に変更せず、別チケットとして扱う。
