# チケット72fix: パスワード表示 / 非表示切り替えボタンの追加

## 目的

チケット72で定義した「パスワード表示 / 非表示切り替え仕様」が未実装、または実画面で確認できないため、ログイン・ユーザー登録・パスワード変更画面のパスワード欄に表示切り替えボタンを追加する。

## 背景

チケット72では、パスワード欄の右側に入力内容を表示 / 非表示するボタンを追加する仕様が含まれていた。

しかし、実画面確認では以下の状態になっている。

```text
パスワード強度メーター: 表示されている
文字数・入力制限: 表示されている
パスワード表示 / 非表示ボタン: 表示されていない
```

そのため、チケット72の未完了部分として `72fix` を作成する。

## 対象ファイル（推定）

```text
js/render.js
js/actions.js
js/supabaseAuth.js
js/config.js
styles.css
README.md
```

## 実装内容

### 1. ログイン / ユーザー登録画面のパスワード欄に表示切り替えボタンを追加

ログイン / ユーザー登録画面のパスワード入力欄右側に、表示 / 非表示を切り替えるボタンを追加する。

動作:

```text
通常時: type="password"
表示ボタン押下時: type="text"
再度押下時: type="password"
```

### 2. ユーザーデータ画面のパスワード変更欄にも追加

ユーザーデータ画面にあるパスワード変更欄にも、同じ表示 / 非表示ボタンを追加する。

対象候補:

```text
新しいパスワード
新しいパスワード確認
```

確認用パスワード欄がある場合は、その欄にも同様に追加する。

### 3. ボタンの見た目

ボタンは以下のどちらかでよい。

```text
目のアイコン
表示 / 非表示 テキストボタン
```

ただし、既存テーマに合わせること。

配置:

```text
パスワード入力欄の右端付近
入力欄と一体感がある位置
フォーム全体の横幅を崩さない位置
```

### 4. アクセシビリティ

以下を考慮する。

```text
button要素を使う
type="button" を指定する
aria-label を付ける
キーボード操作で押せる
```

例:

```html
<button type="button" aria-label="パスワードを表示">
```

表示中はラベルを切り替える。

```text
パスワードを表示
パスワードを非表示
```

### 5. 入力値を保持する

表示 / 非表示を切り替えても、入力中のパスワードが消えないようにする。

```text
入力値を保持する
カーソル位置が大きく崩れないようにする
再描画で入力欄がリセットされないようにする
```

### 6. コピペ・自動入力を妨げない

チケット72の方針を維持する。

```text
pasteイベントをキャンセルしない
パスワードマネージャーからの自動入力を妨げない
ブラウザ標準の保存・自動入力を妨げない
autocomplete属性を不自然に無効化しない
```

## UI仕様

- 既存テーマを壊さない
- ダークテーマ上で見やすい
- スマホ幅でも崩れない
- 入力欄の高さが不自然に変わらない
- 目のアイコンまたは表示ボタンが押せることが分かる
- ボタンがパスワード強度メーターや補足文と重ならない

## 受け入れ条件

- ログイン / ユーザー登録画面のパスワード欄に表示 / 非表示ボタンがある
- ユーザーデータ画面の新しいパスワード欄に表示 / 非表示ボタンがある
- 確認用パスワード欄がある場合、その欄にも表示 / 非表示ボタンがある
- 通常時は `type="password"` になっている
- ボタン押下で `type="text"` になり、入力文字列が見える
- 再度押下で `type="password"` に戻る
- 表示切り替えしても入力値が消えない
- パスワード欄への貼り付けができる
- パスワードマネージャーの自動入力を妨げない
- 既存のパスワード強度メーターが壊れていない
- 既存の文字数制限・入力制限が壊れていない
- 既存のログイン・登録・パスワード変更処理が壊れていない
- Supabase未設定時のローカル導線が壊れていない
- `node --check` が通る
- ビルド番号を +1 する
