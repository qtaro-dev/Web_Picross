# チケット105：管理者ランキング除外とユーザー別ランキング削除

## 背景

Vercel本番環境で、AdminQtaroがF1デバッグや確認プレイを行った結果、ランキングにAdminQtaroの記録が表示されている。

管理者のプレイ記録はテスト・確認用途であり、本番ランキングに混ざると一般ユーザーの順位が分かりにくくなる。

また、テストユーザーや特定ユーザーのランキング記録だけを削除したい場面がある。

## 目的

管理者ユーザーの記録をランキング対象外にする。

また、管理者ページから特定ユーザーのランキング記録を削除できるようにする。

## 対象ファイル（推定）

```text
js/supabaseProgress.js
js/admin.js
js/render.js
js/actions.js
styles.css
docs/supabase/002_rls.sql
README.md
docs/ticket_status.json
```

必要に応じて:

```text
api/admin-ranking.js
```

ただし、ランキング削除がRLS上の管理者権限で可能なら、secret keyを使うAPI化は必須ではない。

## 実装内容

### 1. 管理者ユーザーのランキング新規保存を抑止する

ゲームクリア時にランキング記録を保存する処理を確認する。

保存前に、現在ユーザーが管理者かどうかを判定する。

条件:

```text
profiles.role = admin
```

または既存の管理者判定関数を使う。

管理者ユーザーの場合:

```text
ランキング保存を行わない
ゲームクリア処理自体は通常通り完了する
進行状況の保存は必要に応じて維持する
```

表示メッセージは任意だが、出す場合は管理者にだけ分かる文言にする。

例:

```text
管理者ユーザーのためランキングには登録しませんでした。
```

### 2. 既存の管理者ランキング記録を表示対象外にする

ランキング取得処理を確認する。

ランキング一覧に表示する際、管理者ユーザーの記録を除外する。

方法候補:

```text
A. public_profiles と profiles を使って role != admin を判定する
B. ranking_records取得後に、管理者ユーザーID一覧を除外する
C. DB Viewを作成して非管理者ランキングだけを返す
```

推奨は、可能ならDB側Viewまたは取得処理で一貫して除外する。

表示対象:

```text
一般ユーザーのランキング記録のみ
```

非表示対象:

```text
role = admin のユーザー記録
```

### 3. 「現在の自分の順位」からも管理者記録を除外する

ランキング画面上部の「現在の自分の順位」でも、管理者記録を除外した順位を使う。

管理者ユーザーでログイン中の場合は、ランキング順位欄の扱いを決める。

推奨:

```text
管理者自身の順位は表示しない
または
管理者ユーザーはランキング対象外です と表示する
```

### 4. 管理者ページにユーザー別ランキング削除機能を追加する

管理者ページのランキング管理に、特定ユーザーのランキング記録削除機能を追加する。

最低限の操作:

```text
ユーザーを選択する
対象ユーザーのランキング件数を表示する
削除ボタンを押す
確認モーダルを出す
実行すると、そのユーザーの ranking_records を削除する
```

可能なら絞り込みを追加する。

```text
ユーザー名
難易度
面番号
期間
```

### 5. 削除前に確認モーダルを出す

削除実行前に、必ず確認モーダルを表示する。

表示内容:

```text
対象ユーザー名
対象ユーザーID
削除対象件数
この操作は元に戻せないこと
```

確認ボタン例:

```text
ランキング記録を削除する
```

キャンセルボタン例:

```text
キャンセル
```

### 6. RLSポリシーを確認する

`ranking_records` に対して、管理者がDELETEできるポリシーがあるか確認する。

既存ポリシー例:

```text
ranking_records_delete_admin
```

存在しない場合は `docs/supabase/002_rls.sql` に追加する。

条件例:

```sql
is_admin()
```

### 7. 削除後に画面を再読み込みする

ユーザー別ランキング削除後、以下を更新する。

```text
ランキング管理一覧
ランキング画面
対象ユーザーの件数表示
```

### 8. AdminQtaroの既存ランキングを消せるようにする

このチケット実装後、管理者ページからAdminQtaroの既存ランキング記録を削除できるようにする。

手動SQLで削除してもよいが、最終的には管理画面から削除できることを目標にする。

## 受け入れ条件

### 管理者プレイ確認

AdminQtaroでログインしてゲームをクリアする。

期待結果:

```text
ゲームクリアはできる
ランキングには登録されない
ランキング一覧にAdminQtaroの新規記録が増えない
```

### 管理者ランキング表示確認

ランキング画面を開く。

期待結果:

```text
AdminQtaroの既存記録が表示されない
一般ユーザーの記録だけが表示される
順位が管理者除外後の順位になっている
```

### 一般ユーザーランキング確認

一般ユーザーでログインしてゲームをクリアする。

期待結果:

```text
ランキングに登録される
ランキング一覧に表示される
現在の自分の順位に表示される
```

### ユーザー別削除確認

管理者ページで特定ユーザーのランキング記録を削除する。

期待結果:

```text
確認モーダルが出る
対象ユーザー名と削除件数が表示される
実行後、対象ユーザーのranking_recordsが削除される
他ユーザーのランキング記録は残る
```

### DB確認

Supabaseで `ranking_records` を確認する。

期待結果:

```text
削除対象ユーザーの記録が消えている
他ユーザーの記録は消えていない
```

## NG条件

```text
管理者の記録がランキングに新規登録される
ランキング画面にAdminQtaroが表示される
一般ユーザーのランキング保存まで止まる
ユーザー別削除で全ユーザーのランキングが消える
確認モーダルなしで削除される
```

## メモ

ランキング削除は危険操作なので、必ず確認モーダルを挟むこと。

削除対象件数を表示してから実行すること。

管理者記録の除外は、表示だけでなく新規保存抑止も行うこと。
