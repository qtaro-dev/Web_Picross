# チケット72fix2: パスワード表示 / 非表示ボタンのサイズ調整

## 目的

チケット72fixで追加したパスワード表示 / 非表示ボタンが大きすぎるため、既存フォームに自然に収まるサイズへ調整する。

## 背景

現在のログイン / ユーザー登録画面では、パスワード欄の右側に「非表示」ボタンが表示されるようになった。

ただし、ボタンの横幅・高さ・文字サイズが大きく、入力欄に対して目立ちすぎている。

現在の状態:

```text
パスワード入力欄の右側に「非表示」ボタンは表示されている
ただしボタンが大きい
表示 / 非表示の文字も大きい
フォーム全体の見た目に対して主張が強い
```

## 対象ファイル（推定）

```text
styles.css
js/render.js
js/actions.js
```

## 実装内容

### 1. パスワード表示 / 非表示ボタンを小さくする

パスワード欄右側の表示切り替えボタンを、入力欄に自然に収まるサイズへ調整する。

調整対象:

```text
ボタンの横幅
ボタンの高さ
padding
font-size
border-radius
```

目安:

```text
入力欄の高さより少し低い
文字サイズは補足文より少し大きい程度
ボタン幅は必要最小限
```

### 2. 表示 / 非表示の文字サイズを小さくする

現在の「表示」「非表示」テキストが大きいため、控えめなサイズにする。

目安:

```text
font-size: 0.8rem 前後
または既存フォーム補助テキストに近いサイズ
```

### 3. 入力欄との一体感を出す

ボタンが別パーツとして大きく見えすぎないようにする。

方針:

```text
入力欄右端に自然に付く
高さを入力欄と揃えすぎて巨大化させない
枠線や背景色は既存テーマに合わせる
押せることは分かるが、目立ちすぎない
```

### 4. 既存動作を壊さない

見た目調整のみを目的とし、表示 / 非表示の動作は維持する。

維持する動作:

```text
通常時は type="password"
ボタン押下で type="text"
再度押下で type="password"
入力値は消えない
コピペ可能
パスワードマネージャー自動入力を妨げない
```

## UI仕様

- 既存テーマを壊さない
- ダークテーマ上で見やすい
- ボタンが大きすぎない
- 表示 / 非表示の文字が大きすぎない
- スマホ幅でも崩れない
- パスワード強度メーターや補足文と重ならない
- 入力欄の横幅を不自然に圧迫しない

## 受け入れ条件

- パスワード表示 / 非表示ボタンが現在より小さくなっている
- 「表示」「非表示」の文字サイズが小さくなっている
- 入力欄の見た目と自然に馴染んでいる
- ボタンが押しにくいほど小さくなっていない
- ログイン / ユーザー登録画面で表示確認できる
- ユーザーデータ画面のパスワード変更欄でも表示確認できる
- 表示 / 非表示切り替え動作が壊れていない
- 入力値が切り替え時に消えない
- パスワード強度メーターが壊れていない
- 文字数制限・入力制限が壊れていない
- `node --check` が通る
- ビルド番号を +1 する
