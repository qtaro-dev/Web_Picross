# チケット109：管理者ページのパズル管理UI調整

## 背景

チケット108で、管理者ページに「パズル管理」セクションを追加し、難易度別JSONのアップロード前チェック・反映実行ができるようになった。

本番画面で確認したところ、機能自体は表示されているが、UI上で以下の改善点がある。

- ファイル選択欄の文字が途中で切れている
- 「アップロード前チェック」「反映実行」ボタンの配置が横並びで詰まって見える
- 読み込んだパズル一覧が一部しか見えず、全件確認しづらい
- 検証結果テーブルをスクロールして全件確認できるようにしたい

## 目的

管理者ページの「パズル管理」UIを調整し、管理者がアップロード前チェック結果を見やすく確認できるようにする。

## 対象ファイル（推定）

- `js/render.js`
- `js/admin.js`
- `js/actions.js`
- `styles.css`
- `js/config.js`
- `README.md`
- `docs/vercel_supabase_production_checklist.md`
- `docs/ticket_status.json`

## 実装内容

### 1. ファイル選択欄の文字切れを修正する

現在、ファイル選択欄で以下のように文字が途中で切れている。

```text
選...せん
```

これを、可能な範囲で自然に表示されるように調整する。

対応方針：

- ファイル選択欄の横幅を広げる
- 文字が切れないように `min-width` / `width` / `max-width` を調整する
- 画面幅が狭い場合は折り返しまたは縦並びにする
- ファイル名が長い場合は、ファイル名部分だけ省略表示してもよい

目標：

```text
ファイルを選択
選択されていません
```

または、ブラウザ標準表示が崩れない状態。

### 2. ボタン配置を変更する

現在、以下のボタンがファイル選択欄と横並びで詰まっている。

```text
アップロード前チェック
反映実行
```

これを下段に配置する。

推奨レイアウト：

```text
[難易度選択] [ファイル選択]

[アップロード前チェック] [反映実行]
```

または、画面幅によって自然に折り返すflexレイアウトにする。

重要：

- 「アップロード前チェック」と「反映実行」は同じ段に並べてよい
- ファイル選択欄とは別段にする
- ボタン同士の間隔を十分に取る
- 管理者がどちらを押すか迷わない配置にする

### 3. パズル一覧テーブルをスクロール表示にする

アップロード前チェック後に表示されるパズル一覧を、スクロールして全件確認できるようにする。

要件：

- テーブル表示エリアに最大高さを設定する
- 件数が多い場合は縦スクロールできる
- ヘッダー行は可能であれば固定する
- 横幅が足りない場合は横スクロールも許可する
- 表示件数を5件程度に制限している場合は、その制限を解除する
- 少なくともアップロードJSON内の全件を確認できる導線にする

推奨：

```text
max-height: 360px 〜 480px 程度
overflow-y: auto
overflow-x: auto
```

### 4. 検証結果の表示内容を維持する

既存の検証結果表示は維持する。

表示項目例：

- puzzle_key
- 面 / stageNo
- タイトル
- サイズ
- 種別

ただし、列幅や折り返しは見やすく調整してよい。

### 5. レスポンシブ対応

画面幅が狭い場合でも、UIが大きく崩れないようにする。

方針：

- 難易度選択とファイル選択は必要に応じて縦並び
- ボタンは下段に配置
- テーブルは横スクロール許可
- ボタンや入力欄がカード外にはみ出さない

### 6. 既存機能を壊さない

このチケットはUI調整のみを目的とする。

以下の仕様は変更しない。

- `/api/admin-upload-puzzles` の処理
- JSON検証ロジック
- DB反映方式
- `puzzles.id` uuid維持
- `puzzle_key` 管理
- `is_published=false` による非公開化
- 管理者専用制御

### 7. ドキュメント・Build更新

以下を更新する。

- `docs/ticket_status.json` に `109` を追加
- 必要に応じてREADMEまたは本番チェックリストに、パズル管理UIを調整した旨を追記
- Build番号を更新する
