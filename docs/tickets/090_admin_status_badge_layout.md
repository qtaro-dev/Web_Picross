# チケット90：管理者ページのユーザー詳細ステータス表示レイアウト調整

## 背景

管理者ページのユーザー詳細エリアで、利用停止中ユーザーを選択した際に表示される以下のボタン風表示が、他の入力欄・ボタンに比べて大きく見える。

```text
状態: 利用停止
```

現状では、表示名・権限・ユーザー情報保存・利用停止解除ボタンと同じ行に並んでいるが、ステータス表示だけサイズ感が大きく、レイアウトの統一感が崩れている。

## 現在の問題

管理者ページのユーザー詳細で、`状態: 利用停止` の表示が大きく、周囲のUI部品と高さ・余白・文字サイズが揃っていない。

特に以下の点が気になる。

```text
- 他のボタンより縦に大きく見える
- 同じ行の入力欄やボタンと高さが揃っていない
- ステータス表示としては目立ちすぎている
```

## 期待する動作

`状態: 利用停止` の表示を、他のUI部品と自然に揃うサイズに調整する。

期待する見た目:

```text
- 表示名入力欄、権限セレクト、保存ボタン、利用停止解除ボタンと高さを揃える
- ステータス表示はバッジまたは小さめのボタン風ラベルとして表示する
- 利用停止であることは分かるが、必要以上に大きくしない
- 既存の赤系警告色は維持してよい
```

## 対象ファイル

推定対象:

```text
styles.css
js/admin.js
README.md
docs/ticket_status.json
```

主に確認する箇所:

```text
管理者ページのユーザー詳細表示
ユーザー状態表示のHTML生成
ユーザー状態表示のCSSクラス
利用停止解除ボタン周辺のレイアウト
```

## 実装内容

### 1. ユーザー状態表示のサイズを調整する

管理者ページのユーザー詳細に表示される `状態: 利用停止` の表示を、周囲のボタンやフォーム部品と高さが揃うように調整する。

調整対象例:

```text
padding
height / min-height
line-height
font-size
border-radius
align-items
```

### 2. ステータス表示をバッジ寄りの見た目にする

現在のボタン風表示が大きすぎる場合は、ステータスバッジ用のCSSクラスを追加・整理する。

例:

```text
admin status badge
user status badge
disabled status badge
```

ただし、既存の命名規則がある場合はそれに合わせる。

### 3. 既存の警告色・意味は維持する

利用停止状態であることが分かるよう、赤系の背景色・枠線・文字色などの警告表現は維持する。

ただし、他の操作ボタンより過剰に目立たないようにする。

### 4. 他の管理者ページUIを崩さない

以下の表示に影響を出さないこと。

```text
ユーザー一覧
ユーザー詳細
ユーザー情報保存ボタン
利用停止解除ボタン
削除申請・利用停止カウント
進行状況編集
ランキング管理
アカウント削除申請一覧
```

## 受け入れ条件

### 利用停止ユーザーを選択した場合

管理者ページで `account_status = disabled` のユーザーを選択する。

期待結果:

```text
状態: 利用停止 の表示が他のボタン・入力欄と高さ感として揃っている
表示が大きすぎない
利用停止状態であることは視認できる
利用停止解除ボタンはこれまで通り表示される
```

### 通常ユーザーを選択した場合

管理者ページで `account_status = active` または通常状態のユーザーを選択する。

期待結果:

```text
状態表示が崩れない
不要な利用停止解除ボタンが表示されない
ユーザー詳細レイアウトが崩れない
```

### 管理者ページ全体

管理者ページ全体を確認する。

期待結果:

```text
ユーザー一覧の表示が崩れない
ユーザー詳細の横並びレイアウトが自然に見える
進行状況や各種管理セクションに影響がない
```

## メモ

このチケット90では、アカウント状態の判定処理や利用停止解除処理は変更しない。

対象は、管理者ページの `状態: 利用停止` 表示の見た目・レイアウト調整のみ。
