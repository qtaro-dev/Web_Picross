# チケット110：エディタ画面の読み込み済みJSONスロット折りたたみ対応

## 背景

エディタ画面では、左側に「読み込み済みJSONスロット」一覧が表示されている。50×50など大きな盤面を編集する場合、この一覧が常時表示されていると、編集盤面の表示領域が狭くなりやすい。

## 目的

エディタ画面の「読み込み済みJSONスロット」欄を折りたたみ可能にし、盤面編集時の作業スペースを確保する。

## 対象ファイル（推定）

- `js/render.js`
- `js/actions.js`
- `js/state.js`
- `styles.css`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. スロット欄に折りたたみボタンを追加する

「読み込み済みJSONスロット」の見出し付近に、開閉ボタンを追加する。

```text
読み込み済みJSONスロット  [閉じる]
読み込み済みJSONスロット  [開く]
```

### 2. 折りたたみ時の表示

閉じた場合は、以下を非表示にする。

- スロット一覧
- スロット読込ボタン
- スロットへ保存ボタン

ただし、見出しと「開く」ボタンは残す。

### 3. 状態管理

開閉状態は画面内操作中に維持する。可能であれば `localStorage` に保存し、再読み込み後も前回状態を復元する。

キー例：

```text
web_picross_editor_slot_panel_collapsed
```

### 4. 既存機能を壊さない

以下の既存機能は維持する。

- JSON読込
- JSON出力
- スロット読込
- スロット保存
- スロット一覧のサムネイル表示
- 選択中スロット表示
- エディットプレイ

### 5. Build / ドキュメント更新

- `js/config.js` のBuild番号を更新
- `docs/ticket_status.json` に `110` を追加
- 必要に応じてREADMEに追記

## 受け入れ条件（目視確認基準）

### 開閉表示

1. エディタ画面を開く
2. 「読み込み済みJSONスロット」欄を見る

OK：

```text
開閉ボタンが表示される
閉じる操作でスロット一覧が非表示になる
開く操作でスロット一覧が再表示される
```

NG：

```text
開閉ボタンがない
閉じても一覧が残る
開いても一覧が戻らない
```

### 既存機能

OK：

```text
開いた状態でスロット読込・保存が従来通り動く
閉じた状態でもエディタ盤面の編集はできる
```

NG：

```text
折りたたみ後にスロットデータが消える
JSON読込や保存が壊れる
```

## 備考

このチケットでは、盤面の拡大縮小やサムネイルプレビューは扱わない。対象は、読み込み済みJSONスロット欄の折りたたみUIのみとする。
