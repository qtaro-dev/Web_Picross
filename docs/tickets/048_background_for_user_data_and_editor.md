# チケット48: ユーザーデータ画面・エディタ画面への背景画像設定

## 目的

チケット45〜47で主要画面に背景画像を設定したが、まだ背景が割り当てられていない画面が残っている。

以下の画面にも `E:\Dev\web_picross_Ver2\image` 配下の背景画像を設定し、アプリ全体の画面トーンを統一する。

対象画面:

```text
- ユーザーデータ画面
- エディタ画面
```

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\config.js
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\js\actions.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 実装内容

### 1. ユーザーデータ画面に背景画像を設定する

ユーザーデータ画面の最背面に背景画像を表示する。

仕様:

```text
- 背景画像は最背面レイヤーとして表示する
- ユーザー情報、全体集計、難易度別、各データの表は背景より前面に表示する
- 表や文字が背景に埋もれないよう、濃色パネルまたは半透明パネルを維持する
- 背景画像は暗めに表示する
- 背景画像はクリック操作に干渉しない
```

### 2. エディタ画面に背景画像を設定する

エディタ画面の最背面に背景画像を表示する。

仕様:

```text
- 背景画像は最背面レイヤーとして表示する
- 左カラム、スロット一覧、編集盤面、カラーパレット、JSON読込・出力ボタンは背景より前面に表示する
- エディタ操作の視認性を優先する
- 背景画像が明るすぎる場合でも、盤面やボタンが読めるようにする
- 背景画像はクリック操作、ドラッグ操作、右クリック操作に干渉しない
```

### 3. 背景設定に画面キーを追加する

既存の背景設定に以下を追加する。

例:

```js
backgrounds: {
  userData: "image/user_data_background.jpg",
  editor: "image/editor_background.jpg"
}
```

既存の `menu`、`game`、`ranking`、`login`、`select`、`options`、`help`、`credits` の背景設定がある場合は、その構造を壊さずに拡張する。

### 4. 背景未設定時のフォールバック

画像が存在しない場合や読み込みに失敗した場合でも、画面は従来の黒背景で表示されるようにする。

仕様:

```text
- 背景画像未設定でも画面が壊れない
- 画像読込失敗でJSエラー停止しない
- 既存の黒基調テーマを維持する
```

## 受け入れ条件

```text
- http://127.0.0.1:8000/ で確認できる
- ユーザーデータ画面に背景画像が表示される
- エディタ画面に背景画像が表示される
- ユーザーデータ画面の文字と表が読める
- エディタ画面の盤面、ボタン、スロット一覧が読める
- 背景画像がクリック操作に干渉しない
- エディタのセル塗り、×、ドラッグ操作が壊れない
- 既存の画面遷移が壊れない
- 背景画像が存在しない場合も黒背景で表示される
```
