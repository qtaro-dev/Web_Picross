# チケット13: ゲーム画面のヒント列位置ずれ修正と盤面グリッド等間隔化

## 目的

ゲーム画面の盤面表示において、右側の縦ヒント列が1行下にずれて見える問題を修正する。  
あわせて、盤面の枠線・セル間隔がわずかに歪んで見えるため、縦横ともに等間隔で整ったグリッドになるように描画を修正する。

今回の主目的は以下の2点。

```text
1. 右側の縦ヒント列を、1行下がった状態から正しい位置へ修正する
2. 盤面グリッドとヒント領域を、縦横等間隔で歪みなく描画する
```

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\engine.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\styles.css`

必要なら:

- `E:\Dev\web_picross_Ver2\js\actions.js`

## 現象

ゲーム画面の 5x5 パズルなどで、右側の縦ヒント列が盤面の先頭行と揃わず、1行下へずれて見える。

期待する状態:

```text
右側ヒントの最上段が、盤面1行目の高さに揃う
```

現在の見え方:

```text
右側ヒントの表示開始位置が、盤面1行分ほど下にずれている
```

また、盤面の枠線やセルの形状も、場所によって少し歪んで見える。  
縦横の線やセル間隔が完全に揃っておらず、正方形グリッドとしての見た目が不安定になっている。

## 実装内容

### 1. 右側の縦ヒント列の描画基準位置を見直す

右側の縦ヒント列が、盤面1行目に対して正しい基準位置から描画されるようにする。

確認すること:

```text
- 右側ヒント列の描画開始Y座標
- 盤面セル1行目の描画開始Y座標
- 上側ヒント領域の高さ計算
- 左側/右側ヒント領域のオフセット計算
```

期待動作:

```text
- 右側ヒント列の最上段が盤面1行目の高さに揃う
- 行ヒントの各数字が、それぞれ対応する盤面行の中央高さに揃う
```

注意:

- 5x5 だけでなく、10x10、15x10、20x20 でも同様に揃うこと
- モノクロ問題・カラー問題の両方で崩れないこと
- エディットプレイでも同じ描画が崩れないこと

### 2. 上ヒント・左ヒント・右ヒント・盤面の基準座標を共通化する

ヒント描画と盤面描画で別々のオフセット計算を持っている場合、可能な範囲で共通化する。

実装方針:

```text
- 盤面左上の基準点を明確にする
- セルサイズを1つの値で統一する
- 盤面行/列インデックスから描画位置を一貫して算出する
- ヒント数字もセル中心基準または同等基準で配置する
```

期待効果:

```text
- 行ヒント/列ヒントのずれ防止
- サイズ変更時の再ズレ防止
- 難易度・盤面サイズ差による崩れの軽減
```

### 3. グリッド線・セルサイズを等間隔で描画する

盤面の枠線・セル間隔が歪んで見える問題を修正する。

確認すること:

```text
- セル幅とセル高さが一致しているか
- CSS の transform / scale / line-height / border の影響
- 1px境界の積み上がりでズレていないか
- box-sizing の影響
- grid / flex / absolute配置の計算ずれ
```

期待動作:

```text
- 各セルが正方形に見える
- 縦線と横線の間隔が等間隔になる
- 外枠と内側グリッドの線が均一に見える
- 盤面右端・下端だけ歪むことがない
```

注意:

- 盤面サイズに応じたセル縮小機能（チケット2）を壊さない
- 5x5、10x10、15x10、20x20、可能なら50x50でも極端に崩れないこと
- ヒント文字の位置とセル境界がずれないこと

### 4. セル中央基準でヒント文字を配置する

右側ヒント列・上側ヒント列の文字位置は、対応するセル中心に揃うようにする。

期待動作:

```text
- 行ヒントは各行セルの中央高さに揃う
- 列ヒントは各列セルの中央幅に揃う
- 複数段のヒント数字も整列して見える
```

注意:

- 行ヒント領域の幅や列ヒント領域の高さを固定値で雑に置かない
- `line-height` だけに依存してずれる構造は避ける
- フォントサイズが変わっても極端に崩れにくいようにする

### 5. 小サイズ盤面での見た目を優先チェックする

今回のズレは 5x5 で特に目立っているため、小サイズ盤面を優先的に確認する。

優先確認サイズ:

```text
- 5x5
- 5x10
- 10x5
- 10x10
```

追加確認:

```text
- 15x10
- 20x20
```

### 6. エディタ出力JSONを使った問題でも崩れないようにする

チケット12で互換対応したエディタ出力JSONから読み込んだ問題でも、ヒント列やグリッド描画が崩れないようにする。

確認対象:

```text
- data/beginner.json に配置したエディタ出力問題
- 既存問題データ
- エディットプレイ
```

### 7. デバッグ用ログは必要最小限にする

原因調査で `console.log` 等を入れる場合、最終的には必要最小限に留める。  
残す場合は、開発者向けに意味のある内容だけにする。

## 受け入れ条件

- 行ヒントの各数字が、対応する盤面行に正しく揃っている

- 盤面サイズに応じたセル縮小機能が壊れていない
- モノクロ問題で表示が崩れない
