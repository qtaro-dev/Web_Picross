# チケット65: クリア記録・ギブアップ・プレイ履歴をSupabaseへ保存

## 目的

ゲームクリア、失敗、ギブアップ、ヒント使用回数、プレイ時間などのユーザーデータをSupabase Databaseへ保存する。

## 保存対象

```text
- クリア状態
- ベストタイム
- 最新タイム
- クリア回数
- 失敗回数
- ギブアップ回数
- ヒント使用回数
- 最終プレイ日時
- クリア日時
- プレイ履歴
```

## 実装内容

- クリア時に `user_progress` を更新する
- クリア時に `play_history` を追加する
- ギブアップ時に `giveup_count` を増やす
- ランキング用に `best_clear_time_ms` を保存する
- 必要に応じて `ranking_records` へ追加する
- F1デバッグクリアを通常ランキングに含めるか、`debug_clear` として除外するか決める
- Supabase未設定時は既存ローカル保存へフォールバックする

## 受け入れ条件

- クリア記録がSupabaseへ保存される
- ベストタイムが更新される
- ギブアップ回数が保存される
- ヒント使用回数が保存される
- play_historyに履歴が追加される
- 二重保存されない
- node --check が通る
