# チケット16: ビギナー・イージーへのカラーパズル対応

## 目的

これまでビギナー・イージーはモノクロのみとしていたが、エディットモードおよびゲーム側仕様を見直し、ビギナー・イージーでもカラーパズルを扱えるようにする。

チケット6〜7で定義した「ビギナー・イージーはカラー無し」の制限を撤廃し、全難易度でモノクロ / カラーの両方を選択可能にする。

- `E:\Dev\web_picross_Ver2\js\editor.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\data.js`
- `E:\Dev\web_picross_Ver2\js\engine.js`
- `E:\Dev\web_picross_Ver2\styles.css`

ビギナー:

### 変更後

## 実装内容

### 1. 難易度定義を更新する

チケット6で共通化した難易度定義を修正し、ビギナー・イージーでもカラー可にする。

期待定義:

```text
beginner: mono / color
easy: mono / color
normal: mono / color
hard: mono / color
endless: mono / color
```

### 2. エディタでビギナー・イージーでもカラーを選べるようにする

エディタの難易度がビギナー・イージーの場合でも、モノクロ / カラーのトグルを有効にする。

期待動作:

```text
ビギナー選択 → カラー選択可能
イージー選択 → カラー選択可能
```

### 3. ビギナー・イージーのカラーパレットを有効化する

カラーモードを選択した場合、ビギナー・イージーでも16色パレットを使用できるようにする。

注意:

- モノクロ時はチケット15の仕様どおり、1番のみ有効
- カラー時は16色すべて有効

### 4. ゲーム画面でもビギナー・イージーカラー問題に対応する

ゲーム画面でビギナー・イージーのカラー問題を開いた場合も、カラーパレットやカラー判定が動作するようにする。

注意:

- チケット10で「ノーマル以上」としていたパレット表示条件を見直す
- 難易度ではなく、パズルの `colorMode` / `mode` が color かどうかでパレット表示を判断する
- モノクロ問題では従来の表示を維持する

### 5. 判定処理を難易度ではなくモード基準にする

カラー判定は難易度ではなく、パズルデータのモードで判断する。

期待動作:

```text
beginner + color → 色ID一致まで判定
beginner + mono → 従来のモノクロ判定
easy + color → 色ID一致まで判定
easy + mono → 従来のモノクロ判定
```

### 6. 既存データ互換を維持する

既存のビギナー・イージーのモノクロ問題が壊れないようにする。

注意:

- 既存データに `colorMode` がない場合は mono 扱い
- モノクロ問題でカラーパレットが不要に出ないようにする
- 既存のタイマー、セルサイズ、ヒント、ギブアップ、エディットプレイを壊さない
