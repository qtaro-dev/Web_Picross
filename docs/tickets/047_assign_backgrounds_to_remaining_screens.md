# チケット47: 未設定画面への背景画像割り当て

## 目的

チケット45・46でゲーム画面、メニュー画面、ランキング画面には背景画像を設定したが、まだ背景画像が割り当てられていない画面がある。

以下の画面にも `E:\Dev\web_picross_Ver2\image` 配下のJPEG背景画像を割り当て、アプリ全体の見た目を統一する。

対象画面:

```text
- ログイン / ユーザー登録 画面
- ゲームセレクト 画面
- オプション 画面
- ヘルプ 画面
- クレジット 画面
```

クレジット画面については、単一背景ではなく、複数画像を定期的に切り替えながら表示する。切り替えはフェードイン・フェードアウトで自然に行う。

- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\config.js`
- `E:\Dev\web_picross_Ver2\js\render.js`

- `E:\Dev\web_picross_Ver2\README.md`

必要に応じて新規作成:

- `E:\Dev\web_picross_Ver2\js\backgrounds.js`

## 実装内容

### 1. 背景設定を画面別に整理する

背景画像の設定を、画面別に管理できるようにする。

設定例:

```js
backgrounds: {
  login: "image/login_background.jpg",
  select: "image/select_background.jpg",
  options: "image/options_background.jpg",
  help: "image/help_background.jpg",
  credits: [
    "image/credits_background_01.jpg",
    "image/credits_background_02.jpg",
    "image/credits_background_03.jpg"
  ],
  menu: "image/menu_background.jpg",
  game: "image/game_background.jpg",
  ranking: "image/ranking_background.jpg"
}
```

既にチケット45・46で背景設定が実装済みの場合は、その構造を壊さずに拡張する。

### 2. ログイン / ユーザー登録画面に背景を設定する

対象:

```text
ログイン / ユーザー登録 画面
```

仕様:

```text
- 背景画像は最背面に表示する
- ログインフォーム、ユーザー登録フォーム、メッセージは背景より前面に表示する
- 入力欄の文字が読みやすいこと
- 背景画像は暗めに表示する
- 背景画像は操作に干渉しない
```

### 6. クレジット画面に背景スライドショーを実装する

対象:

```text
クレジット画面
```

仕様:

```text
- クレジット画面では複数の背景画像を使用する
- 一定時間ごとに背景画像を切り替える
- 切り替え時はフェードイン・フェードアウトを使う
- 背景切り替え中も、クレジット文字のスクロールは継続する
- クレジット文字は背景より前面に表示する
- 戻るボタンは常に操作できる
- 背景画像は操作に干渉しない
- 背景画像は暗めに表示する
```

推奨仕様:

```text
切り替え間隔: 8〜12秒
フェード時間: 1.5〜3秒
画像表示方式: cover / center
ループ: あり
```

CSS例:

```css
.credits-background-layer {
  position: fixed;
  inset: 0;
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
  pointer-events: none;
  opacity: 1;
  transition: opacity 2s ease;
  z-index: 0;
}

.credits-background-layer.is-fading {
  opacity: 0;
}
```

または、2枚の背景レイヤーを交互に切り替えるクロスフェード方式でもよい。

### 7. 背景共通CSSを整備する

背景レイヤーは可能な限り共通クラス化する。

例:

```css
.screen-background {
  position: fixed;
  inset: 0;
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
  pointer-events: none;
  z-index: 0;
}

.screen-background::after {
  content: "";
  position: absolute;
  inset: 0;
  background: rgba(0, 0, 0, 0.55);
}
```

各画面のUIは背景より前面に出す。

```css
.screen-content {
  position: relative;
  z-index: 1;
}
```

### 8. 背景画像が存在しない場合のフォールバックを用意する

設定された画像が存在しない、または読み込めない場合でも画面が壊れないようにする。

仕様:

```text
- 背景画像が読み込めない場合は黒背景に戻す
- コンソールエラーでアプリ進行が止まらないようにする
- 画像未設定でも既存の黒背景表示を維持する
```

### 9. 既存画面に干渉しない

以下の既存機能を壊さない。

```text
- ログイン
- ユーザー登録
- メニュー画面
- ゲームセレクト
- ゲーム画面
- ランキング画面
- ユーザーデータ画面
- オプション画面
- ヘルプ画面
- クレジット画面
- エディタ画面
```

エディタ画面は今回の必須対象ではない。背景を適用する場合も、エディタUIの視認性を損なわないこと。
