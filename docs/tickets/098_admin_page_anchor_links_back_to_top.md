# チケット98：管理者ページのページ内リンク化とトップへ戻るボタン追加

## 背景

管理者ページ上部には、以下のセクション見出しボタンが表示されている。

```text
ユーザー管理
ユーザー進行状況
ランキング管理
アカウント削除申請
デバッグ操作
システム情報
```

しかし現状では、これらのボタンを押しても該当セクションへ移動しない。

管理者ページは縦に長くなってきており、各管理項目へ素早く移動できる導線が必要。

また、下の方へスクロールしたあとにページ最上部へ戻る操作もやや手間なので、左下に「一番上へ戻る」ボタンを固定表示したい。

## 目的

管理者ページ上部の各ボタンをページ内リンクとして機能させる。

クリックすると、該当する管理セクションへスムーズにスクロールする。

さらに、画面左下に「一番上へ戻る」矢印ボタンを追加し、管理者ページ内の操作性を改善する。

## 対象ファイル

推定対象:

```text
js/admin.js
js/render.js
js/actions.js
js/config.js
styles.css
README.md
docs/ticket_status.json
```

実装状況によっては、管理者ページの描画を担当している既存ファイルに合わせて調整する。

## 実装内容

### 1. 管理者ページ各セクションにIDを付与する

管理者ページ内の各セクションに、ページ内リンク用のIDを付与する。

対象セクション:

```text
ユーザー管理
ユーザー進行状況
ランキング管理
アカウント削除申請
デバッグ操作
システム情報
```

ID例:

```text
admin-section-users
admin-section-progress
admin-section-rankings
admin-section-delete-requests
admin-section-debug
admin-section-system
```

既存の命名規則がある場合は、それに合わせる。

### 2. 上部ボタンをページ内リンクとして機能させる

管理者ページ上部の各ボタンをクリックしたとき、対応するセクションへ移動する。

期待する対応:

```text
ユーザー管理 → ユーザー管理セクション
ユーザー進行状況 → ユーザー進行状況セクション
ランキング管理 → ランキング管理セクション
アカウント削除申請 → アカウント削除申請セクション
デバッグ操作 → デバッグ操作セクション
システム情報 → システム情報セクション
```

移動方法は、既存設計に合わせて以下のいずれかで実装する。

```text
button click + scrollIntoView
a href="#section-id"
```

可能であれば、スムーズスクロールにする。

### 3. 固定ヘッダーや余白を考慮する

セクションへ移動したとき、見出しが画面上端に詰まりすぎないようにする。

CSSで `scroll-margin-top` を設定するなどして、見出しが見やすい位置に来るよう調整する。

例:

```css
.admin-section {
  scroll-margin-top: 24px;
}
```

実際のクラス名は既存CSSに合わせる。

### 4. 左下に「一番上へ戻る」ボタンを追加する

管理者ページ表示中、画面左下にトップへ戻るための固定ボタンを表示する。

表示例:

```text
↑
```

または

```text
▲
```

ボタンの役割が分かるように、title / aria-label を設定する。

例:

```text
一番上へ戻る
```

クリック時の動作:

```text
管理者ページの最上部へスクロールする
```

### 5. 管理者ページ以外では表示しない

トップへ戻るボタンは、管理者ページでのみ表示する。

通常メニュー、ゲーム画面、ログイン画面、エディタ画面では表示しない。

### 6. レイアウトを既存テーマに合わせる

新しいボタンは既存のUIテーマに合わせる。

注意点:

```text
既存ボタンデザインから浮かない
左下に固定してもメイン操作を邪魔しない
スマホ幅でも画面外にはみ出さない
押しやすいサイズにする
```

### 7. 既存処理は変更しない

このチケットでは、ページ内リンクとトップへ戻るボタンのみを対象にする。

以下は変更しない。

```text
ユーザー管理処理
進行状況編集処理
ランキング編集処理
削除申請処理
デバッグ処理
システム情報表示内容
管理者権限判定
```

## 受け入れ条件

### 上部ボタン

管理者ページで上部ボタンをクリックする。

期待結果:

```text
ユーザー管理ボタンでユーザー管理セクションへ移動する
ユーザー進行状況ボタンでユーザー進行状況セクションへ移動する
ランキング管理ボタンでランキング管理セクションへ移動する
アカウント削除申請ボタンでアカウント削除申請セクションへ移動する
デバッグ操作ボタンでデバッグ操作セクションへ移動する
システム情報ボタンでシステム情報セクションへ移動する
```

### スクロール位置

各セクションへ移動したとき、セクション見出しが見える位置に表示される。

期待結果:

```text
見出しが画面外に隠れない
見出しが上端に詰まりすぎない
セクション内容が自然に見える
```

### トップへ戻るボタン

管理者ページを下までスクロールし、左下の矢印ボタンを押す。

期待結果:

```text
管理者ページの最上部へ戻る
上部ボタン群が見える位置へ戻る
```

### 表示範囲

管理者ページ以外を表示する。

期待結果:

```text
ログイン画面ではトップへ戻るボタンが出ない
通常メニューではトップへ戻るボタンが出ない
ゲーム画面ではトップへ戻るボタンが出ない
エディタ画面ではトップへ戻るボタンが出ない
```

### レスポンシブ

画面幅を狭くして確認する。

期待結果:

```text
上部ボタンが崩れない
トップへ戻るボタンが画面外にはみ出さない
他のボタンや入力欄を邪魔しない
```

## 確認観点

```text
ページ内リンクが全セクションで正しく動くこと
セクションIDの重複がないこと
スクロール先の位置が自然であること
トップへ戻るボタンが管理者ページ以外に出ないこと
既存の管理者機能に影響がないこと
```

## メモ

このチケット98では、管理者ページの操作性改善のみを対象にする。

チケット97のパスワードクリア機能とは分離し、認証・DB更新・ユーザー管理機能の仕様変更は行わない。
