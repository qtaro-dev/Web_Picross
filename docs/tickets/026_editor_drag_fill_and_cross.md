# チケット26: エディットモードのドラッグ連続入力対応

## 目的

ゲーム中に実装済みのドラッグ連続入力と同等の操作を、エディットモードでも使えるようにする。

現在のゲーム中操作では、以下のような挙動を行う。

```text
左クリック押下中にセルへ入る
→ 連続で塗る

右クリック押下中にセルへ入る
→ 連続で×を付ける
```

これと同じ考え方をエディタ盤面にも適用し、パズル作成時に複数セルを連続で編集できるようにする。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\editor.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. エディットモード用のdragModeを用意する

エディットモードでも、ドラッグ中の入力状態を管理する。

状態候補:

```text
dragMode:
- none
- fill
- cross
```

または、既存のゲーム用drag状態がある場合は、エディタ用に安全に流用または分離する。

期待状態遷移:

```text
mousedown 左
→ dragMode = fill

mousedown 右
→ dragMode = cross

mouseup
→ dragMode = none

mouseleave
→ dragMode = none

mouseover / pointerenter
→ dragMode に応じてセル更新
```

注意:

- ゲーム画面用のドラッグ状態と混線しないようにする
- 画面遷移時にdragModeが残らないようにする
- モーダル表示中はドラッグ処理を止める

### 2. エディタ盤面で左ドラッグ塗りを実装する

エディタ盤面で左クリックを押したままセルへ入った場合、連続でセルを塗れるようにする。

モノクロモード:

```text
左mousedown → dragMode = fill
セルへ入る → 塗り状態にする
```

カラーモード:

```text
左mousedown → dragMode = fill
セルへ入る → 選択中カラーで塗る
```

注意:

- ドラッグ中はトグルではなく set 処理にする
- 同じセルを再通過しても反転しない
- カラーモードでは選択中カラーで上書きする
- モノクロモードでは通常の塗り値で上書きする

### 3. エディタ盤面で右ドラッグ×または消去を実装する

エディタ盤面で右クリックを押したままセルへ入った場合、連続で×を付ける、またはエディタ上の未入力/消去状態にする。

今回の指定では、右クリック押下中にセルへ入ると連続で×を付ける。

期待動作:

```text
右mousedown → dragMode = cross
セルへ入る → ×を付ける
```

注意:

- エディタ上で×を問題データとして保存するか、編集補助マークとして扱うかを既存設計に合わせる
- 既存エディタで右クリックが消去として実装されている場合、既存仕様との衝突を確認する
- 右ドラッグで色が変更されないようにする
- 右ドラッグで選択中パレットが変わらないようにする
- コンテキストメニューが出ないように `contextmenu` を抑止する

### 4. 単発クリックの既存挙動を維持する

エディットモードの単発クリック挙動は壊さない。

維持する挙動候補:

```text
左クリック単発:
- モノクロなら塗りON/OFF
- カラーなら選択色で塗り/解除

右クリック単発:
- ×を付ける/解除
- または既存仕様に従う
```

注意:

- 単発クリックとドラッグ入力が二重発火しないようにする
- mousedown時点で1セル目を反映する
- pointerenter/mouseover時はドラッグ中だけ反映する

### 5. pointerイベントまたはmouseイベントを整理する

可能であれば、エディタ盤面でもゲーム画面と同じイベント設計を使う。

候補:

```text
pointerdown
pointerenter
pointerup
pointerleave
contextmenu
dragstart
```

または既存実装に合わせて:

```text
mousedown
mouseover
mouseup
mouseleave
contextmenu
```

注意:

- ブラウザ差異が出にくい方式を選ぶ
- 既存ゲーム画面のドラッグ処理を参考にする
- pointer系とmouse系を両方入れる場合、二重発火に注意する

### 6. 画面外mouseupでもdragModeを解除する

ドラッグ中にマウスが盤面外やブラウザ外へ出ても、mouseupでdragModeが解除されるようにする。

期待動作:

```text
window mouseup / pointerup
→ dragMode = none
```

注意:

- エディタを閉じる、メニューへ戻る、エディットプレイへ移動する際も解除する
- dragModeが残って次の操作に影響しないようにする

### 7. カラー・モノクロ両対応にする

エディタの現在モードに応じて、ドラッグ入力を切り替える。

モノクロ:

```text
fill → 塗り
cross → ×
```

カラー:

```text
fill → 選択中カラー
cross → ×
```

注意:

- モノクロ時はパレット1のみ有効というチケット15の仕様を維持する
- カラー時は選択中カラーを使う
- 右ドラッグでは色を使わない
- 塗りと×が同時に成立しないようにする

### 8. 保存・JSON出力との整合性を保つ

ドラッグで編集した内容が、既存の保存・スロット保存・JSON出力に正しく反映されるようにする。

確認対象:

```text
- スロット保存
- JSON同名出力
- JSON別名出力
- 一時保存
- エディットプレイ
```
