# チケット72fix4: パスワード欄レイアウト調整と16文字制限の再修正

## 目的

チケット72 / 72fix / 72fix2 後のパスワード入力欄について、以下の不具合を修正する。

- パスワード入力フィールドが右に行きすぎており、表示 / 非表示ボタンとの区切りが分かりにくい
- パスワード補足文がまだ「8〜72文字」になっている
- 実際の入力欄もまだ72文字まで入力できてしまう
- パスワードは仕様どおり **8〜16文字** に統一する

## 背景

現在の画面では、パスワード欄の右側に「非表示」ボタンが追加されているが、入力フィールドとボタンの境界が詰まりすぎている。

また、チケット72修正版ではパスワード上限を16文字に変更したが、実画面では以下の問題が残っている。

```text
補足文: 8〜72文字 / 半角英数字・記号
実入力: 16文字を超えて入力できる
```

そのため、表示文言・HTML属性・JSバリデーションをすべて16文字上限に統一する。

## 対象ファイル（推定）

```text
js/render.js
js/actions.js
js/supabaseAuth.js
js/config.js
styles.css
README.md
```

## 実装内容

### 1. パスワード文字数上限を16文字に統一する

以下をすべて確認し、72文字指定が残っている場合は16文字へ変更する。

```text
画面表示の補足文
HTML input の maxlength
JS側バリデーション
パスワード強度メーターの判定文言
エラーメッセージ
READMEなどの説明
```

仕様:

```text
パスワード最小: 8文字
パスワード最大: 16文字
```

表示文言例:

```text
8〜16文字 / 半角英数字・記号
```

エラー文言例:

```text
パスワードは8〜16文字で入力してください
```

### 2. 実際の入力欄で16文字を超えて入力できないようにする

パスワード入力欄に `maxlength="16"` を設定する。

対象:

```text
ログイン / ユーザー登録画面のパスワード欄
ユーザーデータ画面の新しいパスワード欄
ユーザーデータ画面の新しいパスワード確認欄
その他パスワード入力欄があれば同様に対応
```

ただし、HTML属性だけに頼らず、JS側でも16文字超過を検証する。

### 3. パスワード入力フィールドを左に詰める

現在、入力フィールドが右側の「表示 / 非表示」ボタンに近すぎる、または重なり気味に見える。

修正方針:

```text
入力フィールド本体を少し左に詰める
表示 / 非表示ボタンとの間に区切りを作る
入力欄とボタンが一体化しすぎないようにする
```

具体例:

```text
入力欄エリアとボタンエリアを flex で分ける
入力欄は flex: 1
ボタンは固定幅
入力欄とボタンの間に border-left または gap を入れる
```

### 4. 表示 / 非表示ボタンとの区切りを分かりやすくする

パスワード入力欄と表示ボタンの境界が分かるようにする。

候補:

```text
入力欄とボタンの間に細い区切り線を入れる
gapを入れる
ボタン側の背景をわずかに変える
角丸を調整する
```

既存テーマに合わせ、目立ちすぎない区切りにする。

### 5. 既存動作を壊さない

以下の動作は維持する。

```text
通常時は type="password"
表示ボタン押下で type="text"
再度押下で type="password"
入力値は消えない
コピペ可能
パスワードマネージャー自動入力を妨げない
パスワード強度メーターが動作する
```

## UI仕様

- パスワード入力欄と表示 / 非表示ボタンの区切りが分かる
- 入力欄が右に寄りすぎない
- 入力文字が表示ボタン側へ食い込まない
- 表示 / 非表示ボタンは大きすぎない
- 既存テーマを壊さない
- ダークテーマ上で見やすい
- スマホ幅でも崩れない
- パスワード強度メーターや補足文と重ならない

## 受け入れ条件

- パスワード補足文が `8〜16文字 / 半角英数字・記号` になっている
- 画面上に `72文字` の文言が残っていない
- ログイン / ユーザー登録画面のパスワード欄で17文字以上入力できない
- ユーザーデータ画面の新しいパスワード欄で17文字以上入力できない
- 新しいパスワード確認欄がある場合、そこでも17文字以上入力できない
- JS側バリデーションでも17文字以上を拒否する
- 17文字以上の場合、日本語エラーが出る
- パスワード入力欄と表示 / 非表示ボタンの間に区切りがある
- パスワード入力欄が右に寄りすぎていない
- 表示 / 非表示ボタンの動作が壊れていない
- 表示切り替えしても入力値が消えない
- パスワード強度メーターが壊れていない
- コピペができる
- パスワードマネージャーの自動入力を妨げない
- 既存のログイン・登録・パスワード変更処理が壊れていない
- Supabase未設定時のローカル導線が壊れていない
- `node --check` が通る
- ビルド番号を +1 する
