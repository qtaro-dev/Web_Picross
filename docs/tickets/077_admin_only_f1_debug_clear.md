# チケット77: F1デバッグクリアを管理者ユーザー専用に制限する

## 目的

ゲーム中に `F1` キーで即クリアできるデバッグ機能を、管理者ユーザーだけが使えるように制限する。

一般ユーザーが誤って、または意図的にF1デバッグクリアを使ってランキングやクリア状況を更新できないようにする。

## 背景

現在、ゲーム中に `F1` キーを押すと即クリアになるデバッグ機能が残っている。

この機能は開発・管理者確認用としては便利だが、一般ユーザーにも使える状態だと以下の問題がある。

```text
一般ユーザーが即クリアできてしまう
ランキングに不正な記録が入る
クリア状況が正しくなくなる
Supabaseのuser_progress / play_history / ranking_recordsに不正データが入る
```

そのため、F1デバッグクリアは `profiles.role = admin` のSupabase管理者ユーザーだけが使えるようにする。

## 前提

- 管理者判定は `profiles.role === 'admin'` を使う
- ユーザー名が `admin` で始まるかどうかでは判定しない
- ローカル固定 `admin/admin` は管理者扱いにしない
- 未ログイン状態ではF1デバッグクリアを無効にする
- 一般ユーザーではF1デバッグクリアを無効にする
- service role key はフロントに出さない

## 実装内容

### 1. F1デバッグクリアの実行箇所を特定する

ゲーム中のキー入力処理を確認し、`F1` 押下で即クリアしている処理を特定する。

想定箇所:

```text
keydownイベント
F1キー判定
debug clear処理
クリア処理呼び出し
```

### 2. 管理者判定を追加する

F1デバッグクリアを実行する前に、現在ログイン中のユーザーが管理者か確認する。

判定条件:

```text
Supabaseログイン中
profiles.role === 'admin'
```

許可:

```text
role = admin
```

拒否:

```text
role = user
未ログイン
ローカル保存ユーザー
ローカル固定 admin/admin
profiles未取得
Supabase未設定
```

### 3. 一般ユーザーの場合は何もしない

一般ユーザーがF1を押しても、即クリアされないようにする。

挙動:

```text
ゲームは継続する
クリア扱いにしない
user_progressを更新しない
play_historyを追加しない
ranking_recordsを追加しない
```

必要に応じて、画面下部や通知エリアに短く日本語メッセージを表示する。

表示例:

```text
F1デバッグクリアは管理者専用です
```

ただし、一般ユーザーにデバッグ機能の存在を強く知らせたくない場合は、何も表示しなくてもよい。

### 4. 管理者ユーザーの場合は従来通り実行する

`profiles.role === 'admin'` の場合のみ、F1デバッグクリアを従来通り実行する。

ただし、ランキングへの扱いは現行仕様を維持する。

現行仕様:

```text
F1デバッグクリアは通常クリア扱い
ランキング対象
```

将来的に `debug_clear` としてランキング除外する場合は、別チケットで対応する。

### 5. 管理者ページのデバッグ操作との整合性を取る

管理者ページにデバッグ操作を移動済みの場合、F1デバッグクリアも管理者専用デバッグ機能として扱う。

READMEまたはコメントに、以下の方針を記載する。

```text
F1デバッグクリアはSupabase管理者ユーザー専用
一般ユーザー・未ログイン・ローカルユーザーでは無効
```

### 6. イベント抑制

F1キーはブラウザのヘルプなどに使われる可能性があるため、管理者デバッグクリアを処理する場合は必要に応じて以下を行う。

```text
event.preventDefault()
event.stopPropagation()
```

ただし、一般ユーザーで無効にする場合も、既存挙動に合わせて必要最小限にする。

## 受け入れ条件

- `profiles.role = admin` のSupabaseユーザーだけがF1デバッグクリアを使える
- `profiles.role = user` の一般ユーザーはF1を押しても即クリアされない
- 未ログイン状態ではF1を押しても即クリアされない
- ローカル保存ユーザーではF1を押しても即クリアされない
- ローカル固定 `admin/admin` ではF1を押しても即クリアされない
- 一般ユーザーがF1を押しても `user_progress` が更新されない
- 一般ユーザーがF1を押しても `play_history` が追加されない
- 一般ユーザーがF1を押しても `ranking_records` が追加されない
- 管理者ユーザーでは従来通りF1デバッグクリアが動作する
- 管理者ユーザーでF1デバッグクリアした場合、現行仕様通り通常クリア扱いになる
- 既存の通常クリア処理が壊れていない
- 既存のギブアップ・失敗・ヒント処理が壊れていない
- 管理者ページの表示制御が壊れていない
- `node --check` が通る
- ビルド番号を +1 する
- `docs/ticket_status.json` にこのチケットを追加し、初期状態を `未修整` にする

## 確認手順

```text
1. 一般ユーザーでログインする
2. ゲーム開始
3. F1を押す
4. 即クリアされないことを確認
5. Supabaseの user_progress / play_history / ranking_records が更新されないことを確認

6. 管理者ユーザーでログインする
7. ゲーム開始
8. F1を押す
9. 即クリアされることを確認
10. 現行仕様通り、通常クリア扱いで保存されることを確認
```
