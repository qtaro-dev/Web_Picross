# チケット76: 管理者専用ランキング修正・デバッグ機能

## 目的

管理者専用ページから、ランキング記録の確認・修正・削除、およびデバッグ用操作を行えるようにする。

通常ユーザー画面からデバッグ機能を完全に分離し、管理者のみが安全に扱えるようにする。

## 背景

ランキングデータやデバッグクリア記録は、テスト中に不正確なデータが混ざる可能性がある。

現在はDBを直接確認・編集する必要があるため、管理者専用ページから分かりやすく修正できるようにする。

## 前提

- チケット74で管理者専用ページが追加済みであること
- チケット75で管理者向けユーザー確認UIが追加済みであること
- 管理者判定は `profiles.role = admin` を使う
- service role key はフロントへ絶対に出さない
- RLS上できない操作は無理に実装せず、管理者用APIやEdge Functionを後続で検討する

## 対象ファイル（推定）

```text
js/render.js
js/actions.js
js/state.js

styles.css
README.md

```

## 実装内容

### 1. ランキング記録一覧

管理者ページにランキング記録一覧を追加する。

表示項目:

```text
難易度
ステージ番号
ユーザー名
表示名
メールアドレス
ベストタイム
クリア日時
記録ID
ユーザーID
```

UI仕様:

```text
難易度フィルター
ステージ番号フィルター
ユーザー検索
日付順ソート
タイム順ソート
更新ボタン
```

### 2. ランキング記録詳細

ランキング記録を選択すると詳細表示する。

表示候補:

```text
ranking_recordsの全情報
profilesとの紐づき情報
対象puzzle情報
play_historyとの関連情報
```

### 3. ランキング修正

管理者がランキング記録を修正できるようにする。

編集候補:

```text
best_clear_time_ms
cleared_at
表示対象フラグ
備考
```

既存スキーマに表示対象フラグや備考が無い場合は、無理に追加せず、必要ならSQL追加を提案する。

### 4. ランキング削除・非表示

テスト記録や誤記録をランキングから除外できるようにする。

安全な方針:

```text
物理削除よりも非表示フラグを優先
```

既存スキーマに非表示フラグが無い場合は、以下の追加を検討する。

```text
is_visible boolean default true
admin_note text
updated_at timestamp
```

ただし、このチケットでSQL変更を行う場合は、既存データを壊さないようにする。

### 5. F1デバッグクリアの扱い

F1デバッグクリアをランキングに含めるか、管理者側で確認できるようにする。

推奨方針:

```text
通常ユーザー向けランキングには含めない
管理者ページでは debug_clear として確認できる
```

既存データに `debug_clear` 判定が無い場合は、後続チケットで保存時にフラグを付与することを検討する。

### 6. デバッグ操作

管理者専用ページに、開発中に使うデバッグ操作を移動する。

移動候補:

```text
ユーザーデータJSON出力
現在ユーザーJSON出力
クリア状況リセット
ユーザーデータ削除
ランキング再読込
Supabase接続状態確認
現在ログインユーザー情報確認
```

危険操作には必ず確認ダイアログを挟む。

### 7. 誤操作防止

- 削除系ボタンは赤系にする
- 確認ダイアログを必須にする
- 削除対象のユーザー名・難易度・ステージ番号を確認画面に表示する
- 操作成功 / 失敗を日本語で表示する
- 一般ユーザーには絶対に表示しない

## UI仕様

- ランキング一覧は表形式で分かりやすくする
- フィルターを上部に配置する
- 危険操作は通常操作と見た目を分ける
- DBカラム名だけでなく日本語ラベルを付ける
- スマホ幅でも最低限確認できる
- 大量データでも重くなりすぎないよう、必要なら件数制限を入れる

## 受け入れ条件

- 管理者のみランキング管理画面を開ける
- 一般ユーザーはランキング管理画面を開けない
- ranking_recordsの一覧が表示される
- 難易度でフィルターできる
- ステージ番号でフィルターできる
- ユーザー名で検索できる
- ランキング記録の詳細を確認できる
- ランキング記録を修正できる、またはRLS上できない場合は未対応として表示される
- ランキング記録を非表示または削除できる、またはRLS上できない場合は未対応として表示される
- 危険操作には確認ダイアログが出る
- 通常ランキング画面が壊れていない
- デバッグ操作が通常ユーザー画面に表示されない
- service role key をフロントに出していない
- `node --check` が通る
- ビルド番号を +1 する
