# チケット109fix1：パズル管理のファイル選択欄UI修正

## 背景

チケット109で、管理者ページの「パズル管理」UIを調整した。

その後の本番画面確認で、JSONファイル選択欄の見た目に問題があることを確認した。

現在の表示では、以下のようにファイル選択欄全体が大きなボタンのように見えている。

```text
[ ファイルを選択　選択さ...ません ]
```

本来は、ブラウザ標準のファイル選択UIとして、以下のように見えるのが望ましい。

```text
[ファイルを選択]  ファイルを選択してください
```

つまり、「ファイルを選択」だけがボタンに見え、その右側の説明テキストは通常テキストとして表示される状態にしたい。

## 目的

管理者ページのパズル管理セクションで、JSONファイル選択欄の見た目を自然なファイル入力UIに修正する。

## 対象ファイル（推定）

- `styles.css`
- `js/render.js`
- `js/admin.js`
- `js/actions.js`
- `js/config.js`
- `README.md`
- `docs/vercel_supabase_production_checklist.md`
- `docs/ticket_status.json`

## 実装内容

### 1. ファイル選択欄全体がボタンのように見える状態を修正する

現在、ファイル入力欄全体にボタン風の枠・背景・フォーカス装飾が適用されている可能性がある。

以下のような見た目にならないように修正する。

```text
[ ファイルを選択　選択さ...ません ]
```

修正後は、以下のイメージに近づける。

```text
[ファイルを選択]  ファイルを選択してください
```

要件：

- 「ファイルを選択」部分だけがボタンに見える
- 右側の未選択表示は通常テキストに見える
- 入力欄全体が巨大なボタンに見えない
- 青いフォーカス枠が外側全体に大きく出すぎないようにする

### 2. ファイル選択ボタンの位置は維持する

チケット109で上下段に分離したレイアウトは維持する。

現在の基本配置：

```text
[難易度選択] [JSONファイル選択]

[アップロード前チェック] [反映実行]
```

これは維持する。

変更対象は、ファイル選択欄の見た目のみ。

### 3. 未選択時の文言を分かりやすくする

未選択時の表示は、可能であれば以下にする。

```text
ファイルを選択してください
```

ブラウザ標準の `選択されていません` を利用する場合でも、文字が途中で切れないようにすること。

NG例：

```text
選択さ...ません
```

OK例：

```text
ファイルを選択してください
```

または

```text
選択されていません
```

### 4. ファイル名が長い場合の表示

ファイル選択後にファイル名が長い場合は、横幅に収まるように省略表示してよい。

例：

```text
108_admin_puzzle_json_upload...
```

ただし、未選択時の基本文言は切れないことを優先する。

### 5. 既存機能を壊さない

このチケットはUI修正のみを目的とする。

以下の仕様は変更しない。

- 難易度選択
- JSONファイル選択処理
- アップロード前チェック
- 反映実行
- 検証結果テーブルのスクロール表示
- `/api/admin-upload-puzzles`
- `puzzles.id` uuid維持
- `puzzle_key` 管理
- `is_published=false` による非公開化

### 6. ドキュメント・Build更新

以下を更新する。

- `docs/ticket_status.json` に `109fix1` を追加
- 必要に応じてREADMEまたは本番チェックリストに、パズル管理UIのファイル選択欄を修正した旨を追記
- Build番号を更新する

## 受け入れ条件（目視確認基準）

### ファイル選択欄の見た目

1. `AdminQtaro` でログインする
2. 管理者ページを開く
3. パズル管理セクションを見る

OK：

```text
「ファイルを選択」部分だけがボタンに見える
右側に「ファイルを選択してください」または「選択されていません」が通常テキストとして表示される
ファイル選択欄全体が大きなボタンのように見えない
文字が途中で切れていない
```

NG：

```text
ファイル選択欄全体がボタンのように見える
「選択さ...ません」のように文字が切れている
青いフォーカス枠が外側全体に大きく出る
```

### レイアウト

OK：

```text
難易度選択とファイル選択は上段にある
アップロード前チェックと反映実行は下段にある
ボタン配置は109の方針を維持している
```

NG：

```text
アップロード前チェックと反映実行がファイル選択欄と同じ横一列に戻る
ファイル選択欄がカード外にはみ出す
```

### ファイル選択後

1. `data/beginner.json` を選択する

OK：

```text
選択したファイル名が表示される
長いファイル名でもUIが崩れない
アップロード前チェックを実行できる
```

NG：

```text
ファイルを選択しても状態が変わらない
ファイル名表示でレイアウトが崩れる
アップロード前チェックが動かなくなる
```

### 既存機能

OK：

```text
アップロード前チェックが従来通り動く
検証結果テーブルが表示される
反映実行ボタンが従来通り動く
```

NG：

```text
UI修正後にファイル選択イベントが動かない
アップロード前チェックが失敗する
```

対象は、管理者ページのパズル管理セクションにあるJSONファイル選択欄の見た目修正のみとする。
