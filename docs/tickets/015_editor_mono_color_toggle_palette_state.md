# チケット15: エディタモードのモノクロ・カラー切り替えUI改善

## 目的

エディタモードのモノクロ / カラー切り替えを、分かりやすいトグルスイッチUIへ改善する。  
現在どちらが選択されているかを明確に表示し、選択モードに応じてカラーパレットの有効状態を切り替える。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\editor.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. モノクロ / カラーをトグルスイッチ化する

現在の「モノクロ」「カラー」ボタンを、どちらか一方が必ず選択されているトグルUIにする。

期待表示:

```text
[ モノクロ ] [ カラー ]
```

期待動作:

```text
- モノクロを選ぶとモノクロモードになる
- カラーを選ぶとカラーモードになる
- 選択中の側が視覚的に分かる
- 非選択側も押せる状態にする
```

### 2. 選択中の状態を明確にする

選択中のボタンは、既存テーマに合わせて強調する。

候補:

```text
- 枠線を明るくする
- 背景色を少し変える
- selected / active クラスを付ける
- aria-pressed を設定する
```

注意:

- 見た目だけでなく、DOM上でも選択状態が分かるようにする
- 既存の黒背景・白文字・枠線デザインを維持する

### 3. モノクロ時はパレットの1番のみ有効にする

モノクロモードの場合、カラーパレットは「1」だけを有効にする。

期待動作:

```text
モノクロモード:
- パレット1のみ有効
- その他の色は無効化または非表示
- セルにはモノクロ塗りとして保存される
```

注意:

- 0は空白・未入力として扱う可能性があるため、塗り色として使うのは1番を基本とする
- 既存仕様でモノクロ塗りに別の値を使っている場合は既存仕様を優先する
- 無効色をクリックしても選択色が変わらないようにする

### 4. カラーモード時は全パレットを有効にする

カラーモードの場合、チケット9の16色パレットをすべて有効にする。

期待動作:

```text
カラーモード:
- 0〜9、A〜F を選択できる
- 選択中カラーが分かる
- セルクリックで選択色を配置できる
```

### 5. モード変更時の既存盤面データを安全に扱う

モノクロ・カラー切り替え時に、既存の編集中盤面を壊さないようにする。

方針候補:

```text
- カラー → モノクロに切り替える場合、確認ダイアログを出す
- カラー情報を単純な塗り情報へ変換する
- モノクロ → カラーに切り替える場合、既存の塗りを色1として扱う
```

最小実装では確認ダイアログを出して、変換またはクリアを選ばせてもよい。

### 6. JSON読込時もモードUIを同期する

JSONを読み込んだとき、読み込んだパズルの `mode` / `colorMode` に合わせてトグル状態とパレット有効状態を更新する。

期待動作:

```text
mono を読み込む → モノクロが選択状態、パレット1のみ有効
color を読み込む → カラーが選択状態、全パレット有効
```

## 受け入れ条件

- エディタ画面を開ける
- モノクロ / カラーがトグルUIとして表示される
- 現在どちらが選択されているか明確に分かる
- モノクロ選択時、パレット1のみ有効になる
- モノクロ選択時、他色を押しても選択色が変わらない
- カラー選択時、16色すべてを選べる
- カラー選択時、選択色でセルを塗れる
- JSON読込時にモードUIが読み込みデータに同期する
- モノクロ → カラー切り替えで既存盤面が壊れない
- カラー → モノクロ切り替えで既存盤面が安全に扱われる
- JSON出力時にモード情報が正しく保存される
- エディットプレイ導線が壊れない
- 通常ゲームセレクト導線が壊れない
- `node --check js/editor.js` が通る
- `node --check js/render.js` が通る
- `node --check js/state.js` が通る
- 変更したJSファイルすべてで `node --check` が通る
