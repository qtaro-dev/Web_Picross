# チケット54: 難易度ごとのヒント使用回数制限

## 目的

ヒントを大量に使用して、そのまま面クリアできてしまう状態を防ぐ。

難易度ごとにヒント使用回数の上限を設定し、ゲーム中に残りヒント回数を表示する。

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\config.js
E:\Dev\web_picross_Ver2\js\actions.js
E:\Dev\web_picross_Ver2\js\engine.js
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 実装内容

### 1. 難易度ごとのヒント回数を定義する

```text
ビギナー: 2回
イージー: 3回
ノーマル: 3回
ハード: 5回
エンドレス: 5回
```

設定例:

```js
hintLimitsByDifficulty: {
  beginner: 2,
  easy: 3,
  normal: 3,
  hard: 5,
  endless: 5
}
```

### 2. ゲーム開始時に残りヒント回数を初期化する

新しい問題開始時、現在の難易度に応じて残りヒント回数を初期化する。

### 3. ヒントボタンに残り回数を表示する

表示例:

```text
ヒント 2
ヒント 1
ヒント 0
```

### 4. ヒント使用時に残り回数を減らす

```text
- ヒント表示に成功した時だけ減らす
- ヒント対象が存在しないなどで失敗した場合は減らさない
- 残り0の場合は使用できない
```

### 5. 残り0の場合はヒントを使えないようにする

表示例:

```text
ヒントを使い切りました。
```

### 6. やりなおし時の扱い

「やりなおし」で面をリセットした場合、ヒント回数も初期値に戻す。

## 受け入れ条件

```text
- ビギナーはヒント2回まで使える
- イージーはヒント3回まで使える
- ノーマルはヒント3回まで使える
- ハードはヒント5回まで使える
- エンドレスはヒント5回まで使える
- ヒント使用後、残り回数が減る
- 残り0でヒントを押しても盤面が開示されない
- 残り0時に分かりやすいメッセージが出る
- ゲーム開始時に難易度ごとのヒント回数で初期化される
- やりなおし時にヒント回数が初期化される
- node --check が変更したJSファイルすべてで通る
```
