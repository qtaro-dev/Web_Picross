# チケット36: 新規登録ユーザーのパズルセレクトでサムネイルを確実に非表示にする

## 目的

新規登録したユーザーでも、ゲームセレクト画面でパズルの完成サムネイルが表示されてしまっている問題を修正する。

チケット32ではサムネイルとクリアフラグの分離を行ったが、このチケットではさらに、新規ユーザー・未クリアユーザーでは完成サムネイルを確実に表示しない仕様にする。

つまり、サムネイルは以下の条件で表示する。

```text
現在ユーザーがその問題をクリア済み
→ 完成サムネイルを表示

現在ユーザーが未クリア
→ 完成サムネイルは表示しない
→ 既存の？画像/プレースホルダーを表示
```

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\data.js`
- `E:\Dev\web_picross_Ver2\js\thumbs.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 現状の問題

新規登録ユーザーでログインしても、パズルセレクトに完成サムネイルが表示されている。

これはゲームとして以下の問題がある。

```text
- 未クリアなのに答えが見えてしまう
- 新規ユーザーなのに進行済みに見える
- クリアフラグなし表示と矛盾する
```

## 実装内容

### 1. パズルセレクトのサムネイル表示条件を変更する

パズルセレクトの各パネルで、完成サムネイルを表示する条件を「現在ユーザーがクリア済み」に限定する。

期待ロジック:

```text
if currentUser has cleared puzzle:
  show solved thumbnail
else:
  show placeholder thumbnail
```

注意:

- 問題データにサムネイル生成用情報があっても、未クリアなら表示しない
- `grid` から完成図を生成できても、未クリアなら表示しない
- チケット30のサムネイル生成機能は維持するが、表示タイミングを制御する

### 2. 未クリア時はプレースホルダーを表示する

未クリア問題では、既存のプレースホルダー画像を表示する。

候補:

```text
- ? Beginner 画像
- 難易度別のプレースホルダー
- 黒背景に ? 表示
```

期待動作:

```text
新規ユーザー:
#1 〜 #20 すべて未クリア
→ すべてプレースホルダー表示
→ クリア数 0 / 20
```

### 3. クリア後にサムネイルへ切り替える

問題をクリアしたら、そのユーザーのクリアフラグを保存し、パズルセレクトへ戻ったときに該当問題だけ完成サムネイルを表示する。

期待動作:

```text
新規ユーザーで #1 をクリア
→ セレクトへ戻る
→ #1 のみ完成サムネイル表示
→ #2以降はプレースホルダー
→ クリア数 1 / 20
```

### 4. ユーザーごとのクリア状況を参照する

サムネイル表示判定は、必ず現在ログイン中ユーザーのクリア状況を参照する。

期待動作:

```text
admin が #1 クリア済み
test は未クリア

adminでログイン:
#1 サムネイル表示

testでログイン:
#1 プレースホルダー表示
```

注意:

- グローバル共通クリア状態を参照しない
- localStorageやuserDataのキーがユーザー別になっていること
- ユーザー切り替え時に表示を更新する

### 5. 開発データやデバッグ表示と整合させる

デバッグパネルでは、現在ユーザーのクリア状況を表示する。

表示例:

```text
現在ユーザー: test
クリアフラグ: なし
クリア数: 0 / 20
```

### 6. エディットプレイやエディタのサムネイルは別扱いにする

このチケットの対象は、通常のゲームセレクト画面。

エディタ左カラムのスロットサムネイルは、作成中データの確認用なので表示してよい。

```text
ゲームセレクト:
- 未クリアなら完成サムネイル非表示

エディタ:
- 作成確認用としてサムネイル表示可
```
