# チケット46: メニュー画面・ランキング画面の背景画像設定

## 目的

メニュー画面、ランキング画面にも `E:\Dev\web_picross_Ver2\image` 配下のJPEG背景画像を設定できるようにする。

ゲーム画面と同じく、背景は最背面レイヤーとして表示し、ボタン、テーブル、ランキング一覧などのUIに干渉しないようにする。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\config.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\styles.css`
- `E:\Dev\web_picross_Ver2\README.md`

## 実装内容

### 1. メニュー画面に背景レイヤーを追加する

メニュー画面の最背面に背景画像を表示する。

仕様:

```text
- 背景画像はメニュー画面の最背面に配置する
- メニュータイトル、ボタン、ユーザー名表示は背景より前面に表示する
- 背景画像は暗めに表示する
- 背景画像は操作に干渉しない
```

### 2. ランキング画面に背景レイヤーを追加する

ランキング画面の最背面に背景画像を表示する。

仕様:

```text
- 背景画像はランキング画面の最背面に配置する
- 難易度タブ、ランキング表、現在順位表示、戻るボタンは背景より前面に表示する
- 背景画像は暗めに表示する
- 背景画像は操作に干渉しない
```

### 3. 画面別に背景画像を設定できる構造にする

今後の拡張を考え、画面ごとに背景画像を変えられる構造にする。

設定候補:

```js
backgrounds: {
  menu: "image/menu_background.jpg",
  game: "image/game_background.jpg",
  ranking: "image/ranking_background.jpg"
}
```

または、同じ背景を複数画面で使い回す場合:

```js
backgrounds: {
  menu: "image/menu_background.jpg",
  ranking: "image/menu_background.jpg"
}
```

### 4. 背景レイヤー処理を共通化する

チケット45のゲーム背景と同じ考え方で、背景表示処理を共通化できるなら共通化する。

推奨方針:

```text
renderBackgroundLayer(screenName)
```

またはCSSクラスで管理する。

例:

```text
screen--menu
screen--game
screen--ranking
```

### 5. 背景を暗めに表示する

メニュー・ランキングでも、UIの視認性を優先する。

実装方法:

```text
- 背景画像を表示
- 黒の半透明オーバーレイを重ねる
- UIパネルは背景より前面に配置
```

CSS方針:

```css
pointer-events: none;
background-size: cover;
background-position: center;
background-repeat: no-repeat;
```

### 6. 必要であれば他画面にも流用できる余地を残す

今回の必須対象は以下。

```text
- メニュー画面
- ランキング画面
```

ただし、実装構造としては以下にも流用できるようにしてよい。

ただし、今回の実装範囲を広げすぎて既存画面を壊さないこと。
