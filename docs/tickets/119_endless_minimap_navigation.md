# チケット119：Endless専用ミニマップナビゲーション追加

## 目的

Endlessモードの大盤面で、横スクロール・縦スクロールが必要になっても、ユーザーが現在位置を把握しやすく、目的の位置へ移動しやすいようにする。

将来的に50×50以上、または100×100級の巨大パズルを作れるように、Endlessモード専用でミニマップ型のナビゲーションビューを追加する。

## 対象ファイル（推定）

- `index.html`
- `styles.css`
- `js/render.js`
- `js/actions.js`
- `js/state.js`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. Endlessモード専用で表示する

- ミニマップは、実プレイ画面のEndlessモードでのみ表示対象とする。
- Beginner / Easy / Normal / Hard では表示しない。
- Endless以外の通常問題に影響を出さない。

### 2. ミニマップ表示エリアを追加する

- 実プレイ画面の右上付近に、ミニマップ用の小型パネルを追加する。
- 盤面や操作パネルを極端に邪魔しない位置・サイズにする。
- 大盤面時でも、ミニマップが盤面本体を大きく押し出さないようにする。
- ミニマップは `canvas` 描画を基本とする。
- ミニマップ描画で大量のDOMセルを生成しない。

### 3. 表示 / 非表示切り替えを追加する

- ミニマップの表示 / 非表示を切り替えるボタンを追加する。
- 表示例：
  - `ミニマップを表示`
  - `ミニマップを隠す`
- 表示状態は `localStorage` に保存する。
- 再読み込み後も、前回の表示 / 非表示状態が維持されるようにする。

### 4. 現在表示範囲を枠で表示する

- ミニマップ上に、現在の盤面コンテナ表示範囲を枠で表示する。
- ユーザーが盤面コンテナをスクロールしたとき、枠位置も更新する。
- ユーザーが拡大 / 縮小 / 100% を押したときも、枠位置と枠サイズが大きく破綻しないようにする。

### 5. ミニマップクリックで盤面位置へ移動する

- ミニマップ上をクリックした位置へ、盤面コンテナのスクロール位置を移動できるようにする。
- 例：
  - ミニマップ左上をクリックすると盤面左上付近へ移動する。
  - ミニマップ右下をクリックすると盤面右下付近へ移動する。
- 移動後、盤面本体のクリック位置やセル操作がズレないようにする。
- 既存のスクロール位置保持処理を壊さない。

### 6. ミニマップ倍率を追加する

- ミニマップ自体の表示倍率を切り替えられるようにする。
- 倍率候補：
  - `1倍`
  - `1.5倍`
  - `2倍`
  - `2.5倍`
  - `3倍`
  - `3.5倍`
  - `4倍`
- この倍率は、盤面本体の拡大率ではなく、ミニマップ表示専用の倍率とする。
- 盤面本体の `縮小 / 100% / 拡大` とは独立して動作する。
- 倍率状態は `localStorage` に保存する。
- 再読み込み後も前回のミニマップ倍率が復元されるようにする。

### 7. セル更新時にミニマップも更新する

- Endless盤面でセルを塗ったとき、ミニマップ上にも反映する。
- セルを消したとき、ミニマップ上でも消える。
- 右クリックで×を付けた場合、ミニマップでは必要に応じて簡略表示する。
- カラーEndlessの場合、ミニマップ上でも色の違いが大まかに分かるようにする。
- ミニマップ更新で重くならないように、必要な範囲だけ更新するか、軽量な再描画にする。

### 8. 既存仕様を壊さない

- 既存の実プレイ画面レイアウトを大きく破壊しない。
- 左操作パネル折りたたみ機能を維持する。
- 盤面コンテナ内スクロール保持を維持する。
- 大盤面の描画負荷軽減を維持する。
- 既存のセルクリック、右クリック、ドラッグ操作を維持する。
- 判定、ヒント、ギブアップ、やりなおし、メニューへ戻る、セレクトに戻るの動作は変更しない。
- 判定ボタンの内部挙動調整は本チケットでは行わない。
- 既存テーマ・ライブラリ構成を維持する。
- ハードコード文字列は禁止。
- ICommand構造を崩さない。

## 受け入れ条件（目視確認基準）

### Endlessのみ表示

- ユーザーがEndless #01を開く。
- OK：ミニマップ表示ボタン、またはミニマップ本体が表示されること。
- ユーザーがBeginner / Easy / Normal / Hardを開く。
- OK：ミニマップが表示されないこと。
- NG：通常問題にもミニマップが出てUIを圧迫すること。

### 表示 / 非表示

- ユーザーがEndlessを開く。
- ユーザーが `ミニマップを表示` 相当のボタンを押す。
- OK：ミニマップが表示されること。
- ユーザーが `ミニマップを隠す` 相当のボタンを押す。
- OK：ミニマップが非表示になること。
- ページを再読み込みする。
- OK：前回の表示 / 非表示状態が維持されること。

### ミニマップ倍率

- ユーザーがEndlessを開く。
- ユーザーがミニマップ倍率を `1倍` から `4倍` まで切り替える。
- OK：ミニマップ本体の表示サイズ、または表示倍率が変わること。
- OK：盤面本体の拡大率は勝手に変わらないこと。
- ページを再読み込みする。
- OK：前回のミニマップ倍率が維持されること。

### 現在表示範囲の枠

- ユーザーがEndless #01を開く。
- ユーザーが盤面コンテナを横スクロールする。
- OK：ミニマップ上の現在表示範囲枠が横方向に移動すること。
- ユーザーが盤面コンテナを縦スクロールする。
- OK：ミニマップ上の現在表示範囲枠が縦方向に移動すること。
- NG：枠が動かない、または実際の表示位置と大きくズレること。

### ミニマップクリック移動

- ユーザーがEndless #01を開く。
- ユーザーがミニマップ右下付近をクリックする。
- OK：盤面コンテナが右下付近へ移動すること。
- ユーザーがミニマップ左上付近をクリックする。
- OK：盤面コンテナが左上付近へ移動すること。
- NG：クリックしても移動しない、または極端に違う位置へ飛ぶこと。

### セル操作との連動

- ユーザーがEndlessでセルを塗る。
- OK：ミニマップ上でも塗ったセルが反映されること。
- ユーザーがセルを消す。
- OK：ミニマップ上でも消えること。
- ユーザーが右クリックで×を付ける。
- OK：盤面本体の×操作が壊れないこと。
- NG：ミニマップ追加後にセルクリック、右クリック、ドラッグ操作が壊れること。

### カラーEndless

- ユーザーがカラーのEndless問題を開く。
- ユーザーが色を選択してセルを塗る。
- OK：ミニマップ上でも色の違いが大まかに確認できること。
- NG：色選択が壊れる、別の色で塗られる、ミニマップ更新で重くなること。

### 左操作パネル折りたたみとの併用

- ユーザーがEndlessを開く。
- ユーザーが左操作パネルを隠す。
- OK：ミニマップが使用できること。
- ユーザーが左操作パネルを表示する。
- OK：ミニマップと操作パネルが重なりすぎないこと。
- NG：操作パネルを開閉するとミニマップが操作不能になること。

### 大盤面操作感

- ユーザーがEndless #01 / Endless #02を開く。
- ユーザーがミニマップで位置移動しながらセルを操作する。
- OK：スクロールバーを手動で細かく動かさなくても、目的の場所へ移動しやすいこと。
- OK：画面全体が極端に重くならないこと。
- NG：ミニマップ表示中だけ操作が極端に重くなること。

### 既存機能の回帰確認

- ユーザーがBeginner / Easy / Normal / Hardを開く。
- OK：通常問題で従来どおりプレイできること。
- OK：やりなおし、判定、ヒント、ギブアップ、メニューへ戻る、セレクトに戻るが従来どおり動くこと。
- NG：Endless専用ミニマップ追加の影響で、通常問題のUIや操作が壊れること。
