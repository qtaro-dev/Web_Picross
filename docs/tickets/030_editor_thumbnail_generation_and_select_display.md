# チケット30: エディタ完成サムネイル生成・保存とパズルセレクト表示対応

## 目的

エディットモードで作成した完成時のピクロス盤面から、正方形サムネイルを生成して保存できるようにする。

生成したサムネイルは、パズルセレクト画面の各パズルパネル部分に表示する。  
盤面サイズや縦横比にかかわらず、基本的には正方形の枠内に収める。  
画面に収まらない場合や長方形盤面の場合は、拡大縮小して正方形サムネイル内に収まるようにする。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\editor.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\data.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\thumbs.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. エディタ盤面からサムネイルを生成する

エディットモードで現在編集中の完成盤面からサムネイルを生成する。

対象:

```text
- モノクロ問題
- カラー問題
```

生成方式候補:

```text
- CSSグリッドによる表示用サムネイル
- canvasによる画像生成
- SVG文字列生成
```

既存に `thumbs.js` がある場合は、できるだけ既存構造を利用する。

### 2. サムネイルは正方形に収める

サムネイル表示枠は正方形とする。

期待仕様:

```text
- 正方形のサムネイル枠を使う
- 盤面全体が枠内に収まる
- 5x10 や 10x5 など長方形盤面も正方形枠内に収める
- 縦横比は壊さず、必要に応じて余白を作る
```

注意:

- 盤面を無理やり正方形に引き伸ばさない
- セル自体の正方形は維持する
- 余白は黒背景や既存テーマに合わせる

### 3. 大きい盤面は縮小して表示する

20x20、50x50など大きな盤面でも、サムネイル枠内に収まるように縮小する。

### 4. サムネイルを保存データに含めるか、再生成できるようにする

推奨方針:

```text
- JSONにはサムネイル画像のbase64を保存しない
- grid / colorMode / w / h から表示時に再生成する
```

ただし、実装上どうしても保存が必要な場合は、JSONが巨大化しない方式にする。

### 5. スロット一覧のサムネイルと統一する

チケット19で実装したエディタ左カラムのスロットサムネイルと、同じ生成ロジックを使う。

### 6. パズルセレクト画面のパネルにサムネイルを表示する

ゲームセレクト画面の各パズルパネルに、生成したサムネイルを表示する。

期待動作:

```text
パズルセレクト
→ #1 のパネルに #1 の完成サムネイルを表示
→ #2 のパネルに #2 の完成サムネイルを表示
```

注意:

- サムネイルがない場合は既存のプレースホルダー画像を表示してよい
- 既存の `? Beginner` 画像などがある場合は、サムネイル未生成時のフォールバックとして維持する
- クリア済み/未クリアの表示やCLEARバッジがある場合は壊さない

### 7. JSON読込時にサムネイルが再現されるようにする

エディタで作成・出力したJSONを再読み込みしたとき、gridからサムネイルを再生成できるようにする。

### 8. カラー問題のサムネイルに対応する

カラー問題では、セルのカラーIDをMinecraftカラーコード定義に従って反映する。

### 9. 既存機能を壊さない

以下を維持する。

```text
- エディタ盤面編集
- スロット保存
- JSON同名出力
- JSON別名出力
- JSON読込
- エディットプレイ
- ゲームセレクト
- 通常プレイ
- クリア済みバッジ
```
