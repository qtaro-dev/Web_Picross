# チケット43: ランキング画面の実装

## 目的

現在、メニューの「ランキング」から遷移した画面がユーザーデータ画面になっている。

ランキング画面はユーザーデータ画面とは別画面として実装し、難易度ごとのクリアタイムランキングを表示する。

ランキングに表示する内容は以下とする。

```text
- 難易度ごとのランキング
- クリア時間
- クリアユーザー名
- 最大掲載数100件
- 現在ログイン中ユーザーの順位
```

## 対象ファイル（推定）

フロント側:

- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\main.js`
- `E:\Dev\web_picross_Ver2\js\userData.js`
- `E:\Dev\web_picross_Ver2\styles.css`
- `E:\Dev\web_picross_Ver2\README.md`

サーバ側:

- `E:\Dev\web_picross_Ver2\server.js`
- `E:\Dev\web_picross_Ver2\user\*.json`

必要に応じて新規作成:

- `E:\Dev\web_picross_Ver2\js\ranking.js`

## 現状の問題

メニュー画面の「ランキング」を押したときに、ランキング画面ではなくユーザーデータ画面が表示されている。

期待される画面:

```text
ランキング画面
```

現在の実際の画面:

```text
ユーザーデータ画面
```

このため、ランキング機能として使えない。

## 実装内容

### 1. ランキング画面をユーザーデータ画面と分離する

「ランキング」ボタンの遷移先を、ユーザーデータ画面ではなくランキング画面にする。

画面種別例:

```js
screen: "ranking"
screen: "userData"
```

注意:

- ユーザーデータ画面は残す
- メニューの「ユーザーデータ」ボタンはユーザーデータ画面へ遷移する
- メニューの「ランキング」ボタンはランキング画面へ遷移する
- 両者を混同しない

### 2. ランキング画面の基本レイアウトを作る

ランキング画面には、上部ヘッダーと戻るボタンを配置する。

表示例:

```text
[← 戻る]

ランキング

[ビギナー] [イージー] [ノーマル] [ハード] [エンドレス]

現在の自分の順位:
ビギナー #1  3位 / 15人中  00:28

ランキング一覧
```

戻るボタン:

```text
← 戻る
```

遷移:

```text
ランキング画面
→ 戻る
→ メニュー画面
```

### 3. 難易度ごとのランキングタブを作る

ランキング画面に難易度タブを用意する。

対象:

```text
- ビギナー
- イージー
- ノーマル
- ハード
- エンドレス
```

期待動作:

```text
ビギナータブ
→ ビギナーのランキングを表示

イージータブ
→ イージーのランキングを表示
```

注意:

- 既存の難易度ボタンデザインに合わせる
- 選択中タブを分かりやすく表示する
- 初期表示はビギナーでよい

### 4. ランキングデータをユーザーデータから集計する

Node.jsサーバ環境では、以下のユーザー別JSONを読み取ってランキングを作成する。

```text
E:\Dev\web_picross_Ver2\user\*.json
```

対象データ:

```text
progress
history
stats
```

基本は各ユーザーの各面ごとの `bestClearTimeMs` または `latestClearTimeMs` を参照する。

優先順位:

```text
1. bestClearTimeMs
2. latestClearTimeMs
3. clearTimeMs
```

該当データがない場合はランキング対象外。

### 5. ランキング表示項目

ランキング一覧は表形式で表示する。

表示項目:

```text
- 順位
- 難易度
- 面
- パズル名
- クリア時間
- ユーザー名
- クリア日時
```

表示例:

```text
| 順位 | 面 | パズル名 | クリア時間 | ユーザー名 | クリア日時 |
|---:|---:|---|---:|---|---|
| 1 | #01 | クロス | 00:04 | admin | 2026/05/18 15:30:22 |
| 2 | #01 | クロス | 00:28 | 02 | 2026/05/18 15:36:15 |
```

### 6. 最大掲載数を100件にする

各難易度のランキング表示は最大100件までとする。

仕様:

```text
- クリア時間が短い順
- 最大100件
- 101件目以降は表示しない
```

同タイムの場合の並び順:

```text
1. クリア時間が短い順
2. クリア日時が早い順
3. ユーザー名順
```

### 7. 現在の自分の順位を表示する

ランキング画面に、現在ログイン中ユーザーの順位を表示する。

表示内容:

```text
現在の自分の順位
- 難易度
- 面
- 順位
- クリア時間
- 対象人数
```

表示例:

```text
現在の自分の順位:
ビギナー #01  2位 / 4人中  00:28
```

未クリアの場合:

```text
現在の自分の順位:
まだこの難易度のクリア記録がありません。
```

注意:

- 現在選択中の難易度に対する自分の順位を表示する
- 複数面がある場合は、面ごとの順位を一覧表示してもよい
- 最小実装では、その難易度内で現在ユーザーの最高順位を表示する

### 8. 面ごとのランキング扱いを明確にする

ランキングは「難易度ごと」とするが、同じ難易度内に複数の面があるため、以下のどちらかの方式で実装する。

推奨:

```text
難易度タブ
→ 面ごとにランキングを分けて表示
```

表示例:

```text
ビギナー

#01 クロス
1位 admin 00:04
2位 02    00:28

#02 はな
1位 admin 01:20
```

最小実装:

```text
難易度内の全クリア記録をまとめて、面番号付きで表示
```

注意:

- どちらの方式にしたか最終報告に書く
- 将来的には面ごとのランキングに拡張しやすい構造にする
