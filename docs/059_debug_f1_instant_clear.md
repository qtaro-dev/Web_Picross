# チケット59: デバッグ機能としてF1キーで即時クリアできるようにする

## 目的

デバッグ・動作確認を効率化するため、ゲームプレイ中に `F1` キーを押したら、現在プレイ中のパズルを即時クリア状態にできるようにする。

通常プレイ用の機能ではなく、開発・テスト用のデバッグ機能として実装する。

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\main.js
E:\Dev\web_picross_Ver2\js\actions.js
E:\Dev\web_picross_Ver2\js\engine.js
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\js\config.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 実装内容

### 1. ゲーム中のみF1キーを有効にする

`F1` キーで即時クリアできるのは、ゲームプレイ画面のみとする。

有効画面:

```text
- ゲームプレイ中
```

無効画面:

```text
- タイトル画面
- ログイン / ユーザー登録画面
- メニュー画面
- ゲームセレクト画面
- ランキング画面
- ユーザーデータ画面
- オプション画面
- ヘルプ画面
- クレジット画面
- エディタ画面
```

### 2. F1キー押下時にブラウザ標準ヘルプを抑止する

ブラウザによっては `F1` キーでヘルプが開く場合があるため、ゲーム画面中に限り標準動作を抑止する。

実装方針:

```js
event.preventDefault();
event.stopPropagation();
```

ただし、ゲーム画面以外では無理に抑止しない。

### 3. 現在のパズルを正解状態にする

F1キー押下時、現在の盤面を正解データに合わせて即時クリア状態にする。

仕様:

```text
- 正解セルは正解通りに塗る
- カラーピクロスの場合は正解色で塗る
- 非正解セルは×または空欄のどちらでもよいが、判定上クリアになる状態にする
- 既存の入力状態は上書きしてよい
```

推奨:

```text
- 正解セルをすべて埋める
- 非正解セルは×で確定表示する
```

これにより、見た目でも「完成状態」が分かりやすい。

### 4. 通常のクリア処理を呼び出す

F1キーで正解状態にした後、通常のクリア処理と同じ流れを通す。

必須:

```text
- クリアダイアログを表示する
- タイマーを停止する
- ユーザーデータへクリア記録を書き込む
- ランキング記録に反映する
- クリア済みサムネイル表示に反映する
```

ただし、デバッグクリアであることを記録したい場合は、任意で `debugClear: true` のようなフラグを付けてもよい。

### 5. デバッグクリアの扱いを明確にする

今回の最低条件としては、F1クリアも通常クリアと同じ記録でよい。

ただし、将来的に本番公開時に無効化できるよう、設定化しておく。

推奨設定:

```js
debug: {
  enableF1InstantClear: true
}
```

本番公開時に切り替えられるようにする。

```text
開発中: true
公開時: false
```

### 6. クリア済み・ロック中は二重実行しない

すでにクリア済みの状態や、クリアダイアログ表示中にF1を押しても二重クリアにならないようにする。

確認対象:

```text
- クリア数
- ベストタイム
- 最新タイム
- ランキング
- ユーザーデータ
```

仕様:

```text
- すでにクリア済みならF1を無視する
- クリアダイアログ表示中ならF1を無視する
- ゲーム画面以外ならF1を無視する
```

### 7. ヘルプ画面などのF1操作と競合させない

F1はデバッグ用としてゲーム中のみ使う。

ゲーム外画面では、今後ヘルプショートカットなどに割り当てる可能性があるため、現時点ではゲーム画面以外で処理しない。

### 8. READMEにデバッグ機能として追記する

READMEに、開発用デバッグ機能として以下を追記する。

```text
ゲームプレイ中に F1 キーを押すと、デバッグ用に現在の面を即時クリアできます。
この機能は開発・動作確認用であり、公開時には無効化する想定です。
```

### 通常確認

```text
ログイン
→ メニュー
→ ゲームセレクト
→ 任意のパズルを開始
→ F1キーを押す
→ パズルが即時クリアされる
→ クリアダイアログが表示される
```

### 記録確認

```text
F1でクリア
→ セレクトに戻る
→ パズルがクリア済み表示になる
→ ユーザーデータ画面を開く
→ クリア数・タイムが反映されている
→ ランキング画面を開く
→ 記録が反映されている
```

### 二重実行確認

```text
F1でクリア
→ クリアダイアログ表示中に再度F1を押す
→ 二重クリアにならない
→ OKでゲーム画面に戻る
→ 再度F1を押す
→ 二重クリアにならない
```

### 無効画面確認

```text
メニュー画面でF1
→ 即時クリア処理は走らない

ゲームセレクト画面でF1
→ 即時クリア処理は走らない

エディタ画面でF1
→ 即時クリア処理は走らない
```
