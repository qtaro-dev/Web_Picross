# チケット57: クリア後にゲーム画面へ戻った場合、メニューへ戻る・セレクトへ戻るボタンが動作しない不具合修正

## 目的

ゲームをクリアしたあと、クリアダイアログで `OK` を押してゲーム画面へ戻った場合に、左メニューの以下ボタンが動作しない不具合を修正する。

対象ボタン:

```text
- メニューへ戻る
- セレクトに戻る
```

プレイヤーがクリア後の盤面をじっくり見たい場合は `OK` を押してゲーム画面へ戻る導線を使うが、その後に戻る操作ができない状態になっている。

この状態を解消し、クリア後でも通常通りメニュー画面・パズルセレクト画面へ戻れるようにする。

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\actions.js
E:\Dev\web_picross_Ver2\js\engine.js
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 不具合内容

### 現在の不具合

導線1:

```text
1. ゲームをクリアする
2. クリアダイアログが表示される
3. OK を押す
4. ゲーム画面に戻る
5. 左メニューの「メニューへ戻る」または「セレクトに戻る」を押す
6. 戻れない
```

導線2:

```text
1. ゲームをクリアする
2. クリアダイアログで「セレクトへ戻る」を押す
3. パズルセレクトに戻る
```

導線2は正常想定。  
導線1も正常に動くようにする。

## 実装内容

### 1. クリア後状態でも戻るボタンを有効にする

クリア後に `OK` を押してゲーム画面に戻った場合でも、以下のボタンを操作可能にする。

```text
- メニューへ戻る
- セレクトに戻る
```

クリア済み状態では、盤面操作はロックされていてよいが、画面遷移ボタンはロックしない。

### 2. クリア後の入力ロックと画面遷移ロックを分離する

クリア後は以下のように状態を分ける。

```text
盤面入力:
- 塗り操作は禁止
- ×操作は禁止
- ヒント使用は禁止
- 判定は不要または無効でよい

画面遷移:
- メニューへ戻るは有効
- セレクトに戻るは有効
- クリアダイアログ内のセレクトへ戻るも有効
```

`isCleared` や `isGameLocked` のような状態で全操作をまとめて無効化している場合は、画面遷移ボタンまで巻き込まないように修正する。

### 3. クリアダイアログのOK後の状態を整理する

クリアダイアログで `OK` を押した場合の状態を以下にする。

```text
- ゲーム画面を表示したままにする
- クリア済み盤面を表示したままにする
- タイマーは停止したままにする
- 盤面操作は不可にする
- 左メニューの「メニューへ戻る」「セレクトに戻る」は使用可能にする
```

### 4. クリアダイアログの「セレクトへ戻る」は従来通り維持する

クリアダイアログ内にある `セレクトへ戻る` ボタンは、従来通りパズルセレクト画面へ遷移させる。

この導線は壊さない。

### 5. 戻る時に不要な確認ダイアログを出さない

クリア後はすでに記録保存済みの状態であるため、戻る操作時に以下の確認は不要。

```text
記録はクリアされます。よろしいですか？
```

ただし、未クリアのプレイ中に戻る場合は、チケット55の確認仕様を維持する。

仕様:

```text
未クリアプレイ中:
- メニューへ戻る / セレクトに戻る時に確認あり

クリア後:
- メニューへ戻る / セレクトに戻る時に確認なし
- そのまま遷移する
```

### 6. クリア済み記録を二重保存しない

クリア後に `OK` でゲーム画面に戻り、その後 `メニューへ戻る` または `セレクトに戻る` を押しても、クリア記録が二重保存されないようにする。

確認対象:

```text
- クリア数
- ベストタイム
- 最新タイム
- ランキング
- ユーザーデータ
```

### 7. 既存導線を維持する

以下の導線は壊さない。

```text
ゲームクリア
→ クリアダイアログ
→ セレクトへ戻る
→ パズルセレクトへ戻る

ゲームクリア
→ クリアダイアログ
→ OK
→ クリア済み盤面を見る
→ メニューへ戻る
→ メニューへ戻る

ゲームクリア
→ クリアダイアログ
→ OK
→ クリア済み盤面を見る
→ セレクトに戻る
→ パズルセレクトへ戻る
```
