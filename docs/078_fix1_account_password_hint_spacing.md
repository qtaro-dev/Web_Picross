# チケット78fix1: アカウント管理フォームの補足文サイズと余白調整

## 目的

ユーザーデータ画面の「アカウント管理」セクションで、パスワード補足文と強度表示周辺のレイアウトを調整する。

具体的には、`8〜16文字 / 半角英数字・記号` の文字サイズを大きくし、その下のパスワード強度表示枠との間に適度な余白を追加する。

## 背景

チケット78で `パスワード変更` と `アカウント削除申請` ボタンを下部へ移動したが、アカウント管理フォーム内の見た目が少し詰まっている。

現在の問題点:

```text
8〜16文字 / 半角英数字・記号 の文字が小さい
新しいパスワード のラベルより小さく見える
補足文とパスワード強度表示枠の間が近い
フォーム全体の縦の余白が少し窮屈
```

## 対象ファイル（推定）

```text
styles.css
js/render.js
README.md
docs/ticket_status.json
```

## 実装内容

### 1. パスワード補足文の文字サイズを大きくする

ユーザーデータ画面のアカウント管理セクションにある以下の補足文を対象にする。

```text
8〜16文字 / 半角英数字・記号
```

この文字サイズを、`新しいパスワード` ラベルと同じくらいのサイズにする。

目安:

```text
font-size: 0.95rem 〜 1rem 程度
```

既存CSSのラベルサイズに合わせること。

### 2. 補足文の下に余白を追加する

`8〜16文字 / 半角英数字・記号` の下にあるパスワード強度表示枠との間に、少し余白を追加する。

目安:

```text
margin-bottom: 8px 〜 12px 程度
```

または、パスワード強度表示枠側に `margin-top` を追加してもよい。

### 3. アカウント管理フォーム全体の縦バランスを確認する

以下の流れが自然に見えるように調整する。

```text
新しいパスワード
入力欄 + 表示ボタン
8〜16文字 / 半角英数字・記号
適度な余白
パスワード強度表示
新しいパスワード確認
入力欄 + 表示ボタン
適度な余白
パスワード変更 / アカウント削除申請
```

### 4. 他画面への影響を確認する

同じCSSクラスがログイン / ユーザー登録画面にも使われている場合、そちらの見た目が崩れないか確認する。

必要であれば、ユーザーデータ画面のアカウント管理セクション専用クラスとして調整する。

## UI仕様

- `8〜16文字 / 半角英数字・記号` が小さすぎない
- `新しいパスワード` ラベルと同じくらいの視認性がある
- 補足文とパスワード強度表示枠の間に適度な余白がある
- 全体として縦に詰まりすぎていない
- 既存テーマを壊さない
- ダークテーマ上で見やすい
- スマホ幅でも崩れない
- パスワード表示 / 非表示ボタンの位置が崩れない
- パスワード変更 / アカウント削除申請ボタンの位置が崩れない

## 受け入れ条件

- ユーザーデータ画面の `8〜16文字 / 半角英数字・記号` が現在より大きく表示される
- 補足文の文字サイズが `新しいパスワード` ラベルと同程度になっている
- 補足文とパスワード強度表示枠の間に余白がある
- パスワード強度表示枠が入力欄や補足文と詰まりすぎていない
- パスワード確認欄との間隔が不自然ではない
- パスワード変更ボタンとアカウント削除申請ボタンの位置が崩れていない
- ログイン / ユーザー登録画面のパスワード補足文が崩れていない
- パスワード表示 / 非表示ボタンが壊れていない
- パスワード強度メーターが壊れていない
- 入力制限・バリデーションが壊れていない
- `node --check` が通る
- ビルド番号を +1 する
- `docs/ticket_status.json` にこのチケットを追加し、初期状態を `未修整` にする
