# チケット34: ゲーム中モーダル表示時のタイマー停止

## 目的

ゲームモード中にヒント確認・ヒント結果・クリア・ギブアップ・時間切れなどのアラート/ポップアップ/モーダルが表示されている間、ゲームタイマーのカウントを停止する。

特にヒント中は、メッセージを読んでいる間にも時間が進んでしまうため、ゲームとして不自然になる。  
ヒントに限らず、ゲーム中に操作不能なメッセージが表示されている間は、タイマーを一時停止する。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\engine.js`
- `E:\Dev\web_picross_Ver2\js\main.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. タイマー停止状態をstateで管理する

ゲームタイマーに、モーダル表示中の一時停止状態を追加する。

状態候補:

```js
timerPaused: true / false
pauseReason: "modal" | "hint" | "clear" | "giveup" | "timeout" | null
```

または既存のタイマー管理構造に合わせる。

期待動作:

```text
ゲーム中:
- timerPaused = false
- タイマーが進む

モーダル表示中:
- timerPaused = true
- タイマーが止まる

モーダルを閉じる:
- timerPaused = false
- タイマーが再開する
```

ただし、クリア後・ギブアップ後・時間切れ後は再開しない。

### 2. ヒント確認モーダル表示中にタイマーを止める

ヒントボタン押下後の確認モーダルが出ている間、タイマーを停止する。

対象例:

```text
ヒントを使いますか？
[キャンセル] [使う]
```

期待動作:

```text
ヒントボタン押下
→ モーダル表示
→ タイマー停止

キャンセル
→ モーダルを閉じる
→ タイマー再開

使う
→ ヒント処理
→ ヒント結果表示中もタイマー停止
```

### 3. ヒント結果メッセージ表示中にタイマーを止める

ヒント使用後に出るメッセージ表示中もタイマーを停止する。

対象例:

```text
1列目の正解部分を表示しました。
[OK]
```

期待動作:

```text
ヒント結果モーダル表示中
→ タイマー停止

OK
→ ゲーム続行ならタイマー再開
```

### 4. ゲーム中の全モーダル表示時にタイマーを止める

ヒント以外でも、ゲーム中に表示される以下のモーダルではタイマーを停止する。

対象候補:

```text
- ヒント確認
- ヒント結果
- クリア
- ギブアップ確認
- ギブアップ結果
- 時間切れ
- ユーザーデータ削除確認
- クリア状況リセット確認
- その他、ゲーム盤面操作を止めるメッセージ
```

注意:

- クリア/ギブアップ/時間切れの場合は、モーダルを閉じてもタイマーを再開しない
- ユーザーデータ削除など、ゲーム中に出る確認も止める
- ゲーム画面以外のモーダルではタイマーに影響しなくてよい

### 5. タイマー表示が一時停止中に進まないようにする

内部カウントと表示の両方が進まないようにする。

確認点:

```text
- 表示時間が進まない
- 残り時間が減らない
- clearTimeMs / elapsedMs に停止中時間が含まれない
- ランキングやクリアタイムに停止中時間が含まれない
```

### 6. モーダルを閉じた後の再開条件を整理する

モーダル種別ごとに、閉じた後タイマーを再開するか決める。

再開する:

```text
- ヒント確認をキャンセル
- ヒント結果OK
- 通常の情報メッセージOK
```

再開しない:

```text
- クリア後
- ギブアップ後
- 時間切れ後
- セレクトへ戻る場合
- メニューへ戻る場合
```

### 7. 既存タイマー機能を壊さない

以下を維持する。

```text
- 難易度別制限時間
- エンドレス無制限
- クリア時タイマー停止
- 時間切れ判定
- クリア時のタイム記録
- ユーザーデータへのクリアタイム保存
```

## 受け入れ条件

- ゲーム画面でタイマーが動く
- ヒント確認モーダル中にタイマーが止まる
- ヒント確認をキャンセルするとタイマーが再開する
- ヒント結果メッセージ中にタイマーが止まる
- ヒント結果OK後、ゲーム続行ならタイマーが再開する
- クリアモーダル中にタイマーが止まる
- クリア後はモーダルを閉じてもタイマーが再開しない
- ギブアップ確認中にタイマーが止まる
- ギブアップキャンセル後はタイマーが再開する
- ギブアップ確定後はタイマーが再開しない
- 時間切れモーダル後はタイマーが再開しない
- モーダル表示中の時間がclearTimeMs等に含まれない
- 既存のクリアタイム保存が壊れない
- エディットプレイでも同じ挙動になる
- `node --check js/state.js` が通る
- `node --check js/actions.js` が通る
- `node --check js/render.js` が通る
- `node --check js/engine.js` が通る
- 変更したJSファイルすべてで `node --check` が通る
