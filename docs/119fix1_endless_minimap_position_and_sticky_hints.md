# チケット119fix1：Endlessミニマップ配置変更とヒント固定表示改善

## 目的

チケット119でEndless専用ミニマップを追加したが、大盤面でスクロールすると、列ヒント・行ヒントの一部または全部が画面外へ流れてしまい、現在見ているセルで何マス削るべきか分かりにくくなる。

Endlessの大盤面でも、スクロール中に行・列ヒントを確認しやすくし、ミニマップもユーザーが邪魔にならない位置へ配置できるようにする。

## 対象ファイル（推定）

- `index.html`
- `styles.css`
- `js/render.js`
- `js/actions.js`
- `js/state.js`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. Endless大盤面の上ヒントを固定表示する

- Endlessの実プレイ画面で、盤面コンテナを縦スクロールしても、上側の列ヒントが見えるようにする。
- 可能であれば、盤面コンテナ内で列ヒントを `position: sticky` 相当で固定する。
- 上ヒントの数字が盤面セルと横方向にズレないようにする。
- 横スクロール時は、列ヒントが盤面の列と一緒に横移動すること。
- 縦スクロール時は、列ヒントが見える位置に残ること。
- 通常難易度の表示を壊さない。

### 2. Endless大盤面の左ヒントを固定表示する

- Endlessの実プレイ画面で、盤面コンテナを横スクロールしても、左側の行ヒントが見えるようにする。
- 可能であれば、盤面コンテナ内で行ヒントを `position: sticky` 相当で固定する。
- 左ヒントの数字が盤面セルと縦方向にズレないようにする。
- 縦スクロール時は、行ヒントが盤面の行と一緒に縦移動すること。
- 横スクロール時は、行ヒントが見える位置に残ること。
- 通常難易度の表示を壊さない。

### 3. 左上の交差部分を固定する

- 上ヒントと左ヒントが交差する左上部分が、スクロール時に不自然にズレないようにする。
- 左上角の空白部分または基準部分は、必要に応じて `top` / `left` の両方で固定する。
- 上ヒント・左ヒント・盤面セルの重なり順が破綻しないようにする。
- ヒント数字が盤面セルの下に隠れないよう、z-indexを調整する。

### 4. ミニマップを最上位レイヤー寄りに配置する

- Endlessミニマップが盤面・ヒント・操作パネルの下に埋もれないようにする。
- ミニマップは、必要に応じて `position: fixed` またはそれに近い最上位レイヤーとして表示する。
- z-indexを調整し、盤面スクロール中でもミニマップが見えるようにする。
- ただし、モーダルや重要な確認ダイアログがある場合は、それらをミニマップより上に表示する。
- ミニマップがセルクリックや通常操作を不必要に邪魔しないようにする。

### 5. ミニマップの表示位置を選択可能にする

- Endlessミニマップの表示位置をユーザーが選べるようにする。
- 候補は以下とする。
  - 左上
  - 左中央
  - 左下
  - 上中央
  - 右上
- UIは、セレクトボックスまたは小さな切り替えボタンで実装する。
- 選択した位置は `localStorage` に保存する。
- 再読み込み後も前回選択した位置を復元する。
- 既存のミニマップ表示/非表示設定、倍率設定とは独立して保存する。
- 初期位置は、既存の右上相当で問題ない。

### 6. ミニマップ表示/非表示・倍率機能を維持する

- チケット119で追加した以下の機能を維持する。
  - Endlessのみ表示
  - 表示/非表示
  - `localStorage` 保存
  - 倍率 1倍〜4倍
  - 現在表示範囲の枠表示
  - ミニマップクリックで盤面スクロール移動
  - セル更新時のミニマップ更新
- 位置変更機能の追加により、これらの機能を壊さない。

### 7. 既存仕様を壊さない

- 左操作パネル折りたたみ機能を維持する。
- 盤面コンテナ内スクロール保持を維持する。
- 大盤面の描画負荷軽減を維持する。
- 盤面本体の拡大・縮小・100%機能を維持する。
- セルクリック、右クリック、ドラッグ操作を維持する。
- 判定、ヒント、ギブアップ、やりなおし、メニューへ戻る、セレクトに戻るの動作は変更しない。
- 判定ボタンの内部挙動調整は本チケットでは行わない。
- 既存テーマ・ライブラリ構成を維持する。
- ハードコード文字列は禁止。
- ICommand構造を崩さない。
