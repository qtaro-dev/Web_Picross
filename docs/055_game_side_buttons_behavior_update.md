# チケット55: ゲーム中左メニュー系ボタンの挙動変更

## 目的

ゲーム中の左メニュー系ボタンの挙動を整理し、プレイヤーが誤って記録を失ったり、操作意図が分かりにくくなったりする状態を防ぐ。

対象ボタン:

```text
- やりなおし
- 判定
- ギブアップ
- メニューへ戻る
- セレクトに戻る
```

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\actions.js
E:\Dev\web_picross_Ver2\js\engine.js
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 実装内容

### 1. 「やりなおし」ボタンの挙動

現在の面を最初からやり直せるようにする。

```text
- 現在の面の入力状態をリセットする
- 塗りセルを全消去する
- ×マークを全消去する
- ヒントで表示したセルもリセットする
- タイマーを初期状態に戻す
- ヒント残り回数も難易度ごとの初期値に戻す
- 同じ問題を最初から開始する
```

確認メッセージ例:

```text
この面を最初からやりなおしますか？
```

### 2. 「判定」ボタンの挙動

現在の入力状態をチェックし、以下を表示する。

```text
間違い: 2個
未入力: 5個
```

判定仕様:

```text
- 正解セルに塗りがない場合は未入力として扱う
- 非正解セルに塗りがある場合は間違いとして扱う
- 正解セルに×がある場合は間違いとして扱う
- 非正解セルが空欄の場合は未入力または未確定として扱う
```

### 3. 「ギブアップ」ボタンの挙動

確認文言:

```text
記録はクリアされます。よろしいですか？
```

「はい」の場合:

```text
- 現在の面をギブアップ扱いにする
- ギブアップ回数を記録する
- ゲームセレクト画面またはメニューに戻る
```

「いいえ」の場合:

```text
- ゲーム画面に戻る
- 入力状態は維持する
```

### 4. 「メニューへ戻る」「セレクトに戻る」の挙動

確認文言:

```text
記録はクリアされます。よろしいですか？
```

キャンセル時はゲーム画面に戻す。確定時は指定画面に戻す。

### 5. 確認ダイアログ表示中はタイマーを停止する

対象:

```text
- やりなおし確認
- ギブアップ確認
- メニューへ戻る確認
- セレクトに戻る確認
- 判定結果表示
```

## 受け入れ条件

```text
- やりなおしで現在の面を最初からやり直せる
- やりなおしでヒント回数も初期化される
- 判定で間違い数と未入力数が表示される
- ギブアップで確認メッセージが出る
- ギブアップを確定するとギブアップ回数が記録される
- メニューへ戻るで確認メッセージが出る
- セレクトに戻るで確認メッセージが出る
- 確認メッセージでキャンセルした場合はゲーム画面に戻る
- 確認メッセージ表示中はタイマーが進まない
- node --check が変更したJSファイルすべてで通る
```
