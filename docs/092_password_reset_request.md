# チケット92：パスワード再設定メール送信機能の追加

## 背景

現在のログイン画面には、パスワードを忘れたユーザー向けの救済導線がない。

パスワードを間違えた場合、ユーザー自身で再設定できないため、ログイン画面に「パスワードを忘れた場合」の導線を追加する。

Supabase Auth には、メールアドレス宛にパスワード再設定メールを送信する仕組みがあるため、それを利用する。

## 現在の問題

ログイン画面でパスワードを忘れた場合、ユーザーが自力で復旧できない。

現在ないもの:

```text
パスワードを忘れた場合のリンク
パスワード再設定メール送信フォーム
再設定メール送信完了メッセージ
再設定失敗時のエラーメッセージ
```

## 期待する動作

ログイン画面に「パスワードを忘れた場合」導線を追加する。

ユーザーがメールアドレスを入力して再設定メール送信を実行すると、Supabase Auth のパスワード再設定メールを送信する。

## 対象ファイル

推定対象:

```text
index.html
js/actions.js
js/render.js
js/supabaseAuth.js
js/config.js
styles.css
README.md
docs/ticket_status.json
```

## 実装内容

### 1. ログイン画面に導線を追加する

ログイン画面に以下のリンクまたはボタンを追加する。

```text
パスワードを忘れた場合
```

配置はログインボタン周辺、またはメールアドレス欄の近くとする。

### 2. パスワード再設定メール送信用UIを追加する

「パスワードを忘れた場合」を押したら、既存モーダルまたはログイン画面内フォームでメールアドレス入力を受け付ける。

入力項目:

```text
メールアドレス
```

操作ボタン:

```text
再設定メールを送信
キャンセル
```

### 3. Supabase Auth の再設定メール送信を実装する

Supabase JS の `resetPasswordForEmail` を使って、入力されたメールアドレスにパスワード再設定メールを送信する。

注意:

```text
service role key は絶対にフロントへ出さない
フロント側では anon key の範囲で実行する
```

### 4. 送信結果メッセージを表示する

送信成功時:

```text
パスワード再設定メールを送信しました。
メールをご確認ください。
```

送信失敗時:

```text
パスワード再設定メールの送信に失敗しました。
時間をおいて再度お試しください。
```

既存のメッセージ定義がある場合は、そこに追加する。

### 5. 再設定後のパスワード変更画面は別途確認する

Supabaseの再設定メールから戻ってきた後、新しいパスワードを入力する画面が必要になる可能性がある。

このチケットでは、まず「再設定メール送信」までを対象にする。

再設定リンク後の画面処理が未実装だった場合は、別チケットで対応する。

## 受け入れ条件

### ログイン画面

ログイン画面に以下が表示される。

```text
パスワードを忘れた場合
```

### 再設定メール送信

メールアドレスを入力して送信する。

期待結果:

```text
パスワード再設定メールを送信しました。
メールをご確認ください。
```

が表示される。

### 入力チェック

メールアドレス未入力で送信した場合、送信せずにエラーを表示する。

期待結果:

```text
メールアドレスを入力してください。
```

### 既存ログイン

通常ログイン処理に影響がないこと。

期待結果:

```text
通常ログインできる
ユーザー登録できる
停止済みアカウント制御が壊れていない
```

## メモ

このチケット92では、ユーザー自身がパスワード再設定メールを送信できる導線を追加する。

管理者ページからユーザーに再設定を促す機能は、チケット93で別管理する。
