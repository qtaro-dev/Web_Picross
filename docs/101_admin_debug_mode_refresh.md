# チケット101：管理者デバッグモード刷新とADMIN表示追加

## 背景

現在の `js/config.js` には以下の共通デバッグ設定が存在する。

```js
export const DEBUG_CONFIG = { enableF1InstantClear: true };
```

F1即クリア機能は、既にSupabase管理者ユーザー専用に制限されている方針だが、共通のconfigに `enableF1InstantClear: true` があると、保守時に「全ユーザー向けのデバッグ設定」のように見えてしまう。

また、管理者でログインしている時に、画面上で管理者状態が明確に分かる表示がほしい。

## 目的

デバッグ機能を「管理者専用機能」として整理し、一般ユーザーや未ログインユーザーから完全に切り離す。

管理者ログイン中は、常に管理者状態が分かるように画面左上などへ `ADMIN` バッジを表示する。

## 重要方針

### 1. デバッグ機能は管理者専用

F1即クリアなどのデバッグ機能は、設定ファイルのON/OFFだけで使える状態にしない。

必ず、現在ログインしているユーザーがSupabase管理者かどうかを判定する。

### 2. 一般ユーザーには一切表示しない

一般ユーザー、未ログインユーザー、停止ユーザーには、デバッグ機能やADMIN表示を出さない。

### 3. 管理者状態を明確に表示する

Supabase管理者ユーザーでログイン中は、常に画面上に `ADMIN` バッジを表示する。

## 対象ファイル

推定対象:

```text
js/config.js
js/actions.js
js/render.js
js/admin.js
js/supabaseAuth.js
js/state.js
styles.css
README.md
docs/ticket_status.json
```

必要に応じて追加:

```text
js/adminDebug.js
```

## 実装内容

### 1. DEBUG_CONFIGの扱いを見直す

`DEBUG_CONFIG.enableF1InstantClear` を一般設定として扱わないようにする。

対応方針は以下のいずれか。

```text
A. DEBUG_CONFIGを削除し、管理者判定のみでF1即クリア可否を決める
B. DEBUG_CONFIGをadminDebug専用設定へ移動し、管理者判定と併用する
```

推奨はAまたはB。どちらの場合も、一般ユーザーが設定だけでデバッグ機能を使える構造にはしない。

### 2. 管理者判定関数を共通化する

F1即クリア、管理者ページ表示、管理者ショートカット、デバッグ操作などで、同じ管理者判定を使う。

判定条件:

```text
Supabaseログイン済み
profiles.role = admin
profiles.account_status が disabled ではない
```

既存の `is_admin()` 相当の考え方とズレないようにする。

### 3. ADMINバッジを追加する

管理者ユーザーでログインしている場合、画面左上などに固定表示する。

表示例:

```text
ADMIN
```

デザイン案:

```text
赤背景
白文字
小さめ
画面左上固定
z-index高め
クリック不可
```

表示対象:

```text
メニュー画面
ゲーム画面
ランキング画面
ユーザーデータ画面
エディタ画面
管理者ページ
```

非表示対象:

```text
未ログイン
一般ユーザー
停止ユーザー
パスワードクリア強制再設定中の一般ユーザー
```

### 4. F1即クリアの実行条件を再確認する

F1キー押下時、以下の場合だけ即クリアできるようにする。

```text
Supabase管理者ユーザーでログイン中
ゲーム画面を表示中
現在のパズルが存在する
アカウント停止中ではない
パスワード再設定強制中ではない
```

NG条件:

```text
未ログインでF1即クリアできる
一般ユーザーでF1即クリアできる
ローカル固定admin/adminだけでF1即クリアできる
停止ユーザーでF1即クリアできる
```

### 5. 管理者ページのデバッグ操作と整合させる

管理者ページ内の「デバッグ操作」セクションと、F1デバッグ機能の権限判定を揃える。

管理者でない場合、デバッグ操作は表示しないか、押しても拒否する。

### 6. READMEに管理者デバッグ仕様を追記する

READMEに以下を追記する。

```text
F1即クリアはSupabase管理者ユーザー専用
一般ユーザーや未ログイン状態では無効
管理者ログイン中はADMINバッジを表示
```

## 受け入れ条件

### 管理者ログイン

AdminQtaroでログインする。

期待結果:

```text
画面左上にADMINバッジが表示される
管理者ページへ入れる
管理者ショートカットが表示される
F1即クリアが管理者のみ実行できる
```

### 一般ユーザーログイン

testuserなどの一般ユーザーでログインする。

期待結果:

```text
ADMINバッジが表示されない
管理者ページへ入れない
管理者ショートカットが表示されない
F1即クリアが実行できない
```

### 未ログイン

ログインしていない状態で画面を開く。

期待結果:

```text
ADMINバッジが表示されない
F1即クリアが実行できない
```

### 停止ユーザー

account_status = disabled のユーザーでログインを試す。

期待結果:

```text
ログイン画面に停止メッセージが出る
ADMINバッジが表示されない
F1即クリアが実行できない
```

## NG条件

```text
一般ユーザーにADMINバッジが出る
一般ユーザーでF1即クリアできる
未ログインでF1即クリアできる
ローカル固定admin/adminが管理者扱いになる
管理者なのにADMINバッジが出ない
```

## メモ

このチケットでは、管理者向けの見える化とデバッグ権限の整理のみを行う。

パスワードクリア、RLSポリシー、Supabase接続設定は別チケットで扱う。
