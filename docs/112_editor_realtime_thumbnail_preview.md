# チケット112：エディタ盤面のリアルタイムサムネイルプレビュー追加

## 背景

エディタ画面で大きな盤面を作成していると、現在見えている範囲だけでは完成イメージを把握しづらい。特に50×50などの大きな盤面では、細部編集と全体確認を切り替える必要がある。

## 目的

エディタ画面に、現在の盤面データをリアルタイムで反映するサムネイルプレビューを追加する。

## 対象ファイル（推定）

- `js/render.js`
- `js/actions.js`
- `js/state.js`
- `styles.css`
- `js/config.js`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. サムネイルプレビュー枠を追加する

エディタ画面に、現在の盤面全体を表示するプレビュー枠を追加する。

配置候補：

```text
右上の操作エリア内
または盤面上部の空き領域
```

表示名例：

```text
完成プレビュー
```

### 2. リアルタイム更新

セルを塗るたびに、サムネイル表示を更新する。

反映対象：

- モノクロ盤面
- カラー盤面
- 消去状態
- サイズ変更後の盤面
- JSON読込後の盤面
- スロット読込後の盤面

### 3. 盤面全体を収める

50×50など大きな盤面でも、プレビュー枠内に全体が収まるようにする。

要件：

```text
プレビュー枠は固定サイズまたは最大サイズを持つ
盤面の縦横比を維持して縮小表示する
セルが大きすぎて一部しか見えない状態にしない
```

### 4. 色表示

カラー盤面では、現在のパレット色を反映する。

モノクロ盤面では、塗りセルと空セルが区別できるようにする。

### 5. パフォーマンス配慮

セル操作ごとに重くなりすぎないようにする。

実装方針例：

```text
canvasで描画する
または小さいgridをCSSで描画する
```

50×50程度で実用的に動作すること。

### 6. 既存機能を壊さない

以下の既存機能は維持する。

- セル編集
- カラー選択
- モノクロ/カラー切替
- JSON読込
- JSON出力
- スロット保存
- エディットプレイ
- 盤面サイズ変更

### 7. Build / ドキュメント更新

- `js/config.js` のBuild番号を更新
- `docs/ticket_status.json` に `112` を追加
- 必要に応じてREADMEに追記

## 受け入れ条件（目視確認基準）

### プレビュー表示

1. エディタ画面を開く
2. 完成プレビュー枠を見る

OK：

```text
盤面全体が小さく表示される
50×50でも全体が枠内に収まる
```

NG：

```text
一部しか表示されない
プレビュー枠が画面外にはみ出す
```

### リアルタイム更新

1. セルを塗る
2. 別のセルを消す
3. カラーを変更して塗る

OK：

```text
操作直後にプレビューへ反映される
モノクロ/カラーの違いが分かる
```

NG：

```text
プレビューが更新されない
色が反映されない
古い状態のまま残る
```

### JSON / スロット読込後

OK：

```text
JSON読込後にプレビューが更新される
スロット読込後にプレビューが更新される
サイズ変更後にプレビューが更新される
```

NG：

```text
読込前のプレビューが残る
サイズ変更後に表示が崩れる
```

## 備考

このチケットは比較的大きめのUI追加である。チケット110のスロット折りたたみ、チケット111の拡大・縮小とは別チケットとして扱う。
