# チケット70: ユーザーデータ管理画面の拡張

## 目的

登録済みユーザーが、自分のアカウント情報や進行データを確認・管理できるようにする。

## 背景

Supabase Authによるユーザー登録・ログインが可能になり、`profiles` に以下の情報が保存されるようになった。

```text
username
display_name
role
email
```

次に、ユーザーデータ画面から登録メールアドレスやアカウント情報を確認できるようにし、パスワード変更やアカウント削除の導線を検討・実装する。

## 対象ファイル（推定）

```text
js/supabaseAuth.js
js/supabaseProgress.js
js/render.js
js/actions.js
js/state.js
js/config.js
styles.css
README.md
```

## 実装内容

- ユーザーデータ画面に登録メールアドレスを表示する
- Supabase Authのユーザー情報と `profiles` の情報を確認できるようにする
- 表示候補:
  - ユーザー名
  - 表示名
  - メールアドレス
  - 権限
  - 登録日時
  - 最終ログイン日時
- パスワード変更導線を追加する
  - 新パスワード入力
  - 新パスワード確認入力
  - 成功メッセージ
  - 失敗メッセージ
- Supabase Authで直接パスワード変更できる場合は `updateUser` 等を使う
- メール再認証やリセットメールが必要な場合は、安全な導線にする
- アカウント削除導線を検討する
  - すぐ削除しない
  - 必ず確認ダイアログを挟む
  - 削除対象を整理する
    - Authユーザー
    - profiles
    - user_progress
    - play_history
    - ranking_records
- Authユーザー削除に service role が必要な場合、フロント直実装しない
- service role key をフロントへ絶対に出さない
- フロントから削除できない場合は、まずは「削除申請」または「未実装表示」に留める
- ビルド番号を +1 する

## 受け入れ条件

- ユーザーデータ画面に登録メールアドレスが表示される
- ユーザー名 / 表示名 / 権限が表示される
- パスワード変更ができる、または安全な変更導線がある
- アカウント削除は危険操作として確認が入る
- service role key をフロントに出していない
- Supabase未設定時に画面が壊れない
- 既存のプロフィール表示・ログイン状態表示が壊れていない
- `node --check` が通る
