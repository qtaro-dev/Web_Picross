# チケット17: パズル中のクロスヘア表示強化

## 目的

パズル中、マウスカーソルが盤面上にあるとき、現在どのセルを操作対象にしているかを明確にする。  
クロスヘアの中心点となるセルの枠を太い線で表示し、左クリックでどこを塗るか、右クリックでどこに×を置くかを分かりやすくする。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 実装内容

### 1. ホバー中セルをstateで管理する

盤面セルにマウスカーソルが乗ったとき、現在の行・列をstateに保持する。

状態候補:

```js
hoverCell: {
  row: 0,
  col: 0
}
```

盤面からマウスが出たら、ホバー状態を解除する。

```js
hoverCell: null
```

### 2. 中心セルの枠を太線で表示する

ホバー中のセルに対して、通常より太い枠線を表示する。

期待表示:

```text
- ホバー中セルの外枠が太くなる
- 他のセルより明確に現在位置が分かる
```

注意:

- セルサイズや盤面グリッドが歪まないようにする
- 太線表示でレイアウトがずれないように、outlineやbox-shadow等の利用も検討する
- チケット13の等間隔グリッドを壊さない

### 3. 可能であれば行・列のクロスハイライトも追加する

中心セルだけでなく、同じ行・同じ列を薄くハイライトできると望ましい。

優先度:

```text
必須:
- 中心セルの枠を太線表示

任意:
- 同じ行・同じ列を薄く表示
```

最小実装では中心セルだけでよい。

### 4. 左クリック・右クリック・ドラッグ操作と共存させる

クロスヘア表示は操作補助であり、既存入力を壊してはいけない。

維持する操作:

```text
- 左クリック単発で塗りON/OFF
- 右クリック単発で×ON/OFF
- 左ドラッグで連続塗り
- 右ドラッグで連続×
- カラー問題の左クリック/左ドラッグ色配置
- 右クリックは常に×
```

注意:

- ホバー更新でドラッグ処理が二重発火しないようにする
- pointerenter / pointermove / mouseenter 等の既存イベントと競合しないようにする
- モーダル表示中はホバー更新や入力を止める

### 5. カラー・モノクロ両方で視認性を確保する

カラー問題ではセルの色によって枠が見えづらくなる可能性がある。  
どの色の上でもホバー枠が見えるようにする。

候補:

```text
- 白系outline
- 黒系shadow
- 二重線
- 既存テーマに合う明るいアクセント線
```

### 6. 盤面外に出たら表示を消す

盤面外にマウスが出たら、クロスヘア表示を消す。

期待動作:

```text
盤面上: ホバー枠表示
盤面外: ホバー枠非表示
```

## 受け入れ条件

- ゲーム画面を開ける
- 盤面セルにマウスを乗せると、そのセルの枠が太く表示される
- どのセルを操作対象にしているか分かりやすい
- 盤面外に出るとホバー枠が消える
- 太線表示で盤面グリッドが歪まない
- 5x5でも見やすい
- 10x10でも見やすい
- 20x20でも極端に邪魔にならない
- カラー問題でもホバー枠が見える
- モノクロ問題でもホバー枠が見える
- 左クリック操作が壊れない
- 右クリック操作が壊れない
- 左ドラッグ操作が壊れない
- 右ドラッグ操作が壊れない
- モーダル表示中に盤面入力が進まない
- エディットプレイでも同じように表示される
- `node --check js/state.js` が通る
- `node --check js/actions.js` が通る
- `node --check js/render.js` が通る
- 変更したJSファイルすべてで `node --check` が通る
