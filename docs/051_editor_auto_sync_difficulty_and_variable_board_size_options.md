# チケット51: エディットモードでJSONファイル名に応じて難易度・盤面サイズ候補を自動連動する

## 目的

エディットモードで以下の固定ファイル名のJSONを読み込んだ時、そのファイル名に応じて難易度ドロップダウンを自動設定し、さらに盤面サイズドロップダウンの候補も難易度ごとの対応サイズに可変させる。

対象ファイル名:

```text
beginner.json
easy.json
normal.json
hard.json
endless.json
```

現在は、読み込んだJSONの難易度・盤面サイズと、画面上の難易度ドロップダウン・盤面サイズドロップダウンの表示がズレる可能性がある。

## 対象ファイル（推定）

```text
E:\Dev\web_picross_Ver2\js\editor.js
E:\Dev\web_picross_Ver2\js\actions.js
E:\Dev\web_picross_Ver2\js\render.js
E:\Dev\web_picross_Ver2\js\state.js
E:\Dev\web_picross_Ver2\js\config.js
E:\Dev\web_picross_Ver2\styles.css
E:\Dev\web_picross_Ver2\README.md
```

## 実装内容

### 1. ファイル名固定で難易度を判定する

読み込んだJSONファイル名が以下の場合のみ、自動連動する。

```text
beginner.json
easy.json
normal.json
hard.json
endless.json
```

ファイル名と難易度の対応:

```text
beginner.json → ビギナー / beginner
easy.json     → イージー / easy
normal.json   → ノーマル / normal
hard.json     → ハード / hard
endless.json  → エンドレス / endless
```

それ以外のファイル名の場合は、自動判定しない。

対象外例:

```text
edit_puzzles_20260520_003935.json
custom.json
test.json
```

### 2. 難易度ごとの盤面サイズ候補を定義する

盤面サイズドロップダウンの候補は、難易度ごとに以下の通りにする。

```text
ビギナー:
- 5x5
- 5x10

イージー:
- 10x10
- 5x10
- 10x5

ノーマル:
- 15x10
- 10x10
- 5x10
- 10x5

ハード:
- 20x20
- 15x10
- 10x10

エンドレス:
- 20x20
- 25x25
- 30x30
- 40x40
- 50x50
```

この定義は、コード内に散らばらせず、設定として一箇所で管理する。

推奨例:

```js
boardSizeOptionsByDifficulty: {
  beginner: [
    { w: 5, h: 5, label: "5 x 5" },
    { w: 5, h: 10, label: "5 x 10" }
  ],
  easy: [
    { w: 10, h: 10, label: "10 x 10" },
    { w: 5, h: 10, label: "5 x 10" },
    { w: 10, h: 5, label: "10 x 5" }
  ],
  normal: [
    { w: 15, h: 10, label: "15 x 10" },
    { w: 10, h: 10, label: "10 x 10" },
    { w: 5, h: 10, label: "5 x 10" },
    { w: 10, h: 5, label: "10 x 5" }
  ],
  hard: [
    { w: 20, h: 20, label: "20 x 20" },
    { w: 15, h: 10, label: "15 x 10" },
    { w: 10, h: 10, label: "10 x 10" }
  ],
  endless: [
    { w: 20, h: 20, label: "20 x 20" },
    { w: 25, h: 25, label: "25 x 25" },
    { w: 30, h: 30, label: "30 x 30" },
    { w: 40, h: 40, label: "40 x 40" },
    { w: 50, h: 50, label: "50 x 50" }
  ]
}
```

### 3. JSON読込時に盤面サイズドロップダウン候補を差し替える

固定ファイル名のJSONを読み込んだ時、難易度に対応した盤面サイズ候補にドロップダウンリストを差し替える。

例:

```text
beginner.json を読み込む
→ 難易度: ビギナー
→ 盤面サイズ候補: 5x5, 5x10

hard.json を読み込む
→ 難易度: ハード
→ 盤面サイズ候補: 20x20, 15x10, 10x10
```

### 4. 読み込んだパズルの w / h に一致するサイズを選択する

読み込んだJSON内の現在選択スロット、または先頭パズルに `w` / `h` がある場合、そのサイズに一致する盤面サイズ候補を自動選択する。

例:

```text
beginner.json 内のパズルが w:5, h:10
→ 盤面サイズドロップダウンは 5x10 を選択する
```

一致する候補がない場合:

```text
- 難易度ごとの先頭サイズを選択する
- ただし、読み込んだ盤面自体は壊さない
- 必要であれば「この盤面サイズは候補外です」とメッセージ表示してもよい
```

### 5. 難易度を手動変更した時も盤面サイズ候補を更新する

エディットモード上でユーザーが難易度ドロップダウンを手動変更した場合も、盤面サイズ候補をその難易度に合わせて差し替える。

例:

```text
難易度をビギナーに変更
→ 盤面サイズ候補: 5x5, 5x10

難易度をエンドレスに変更
→ 盤面サイズ候補: 20x20, 25x25, 30x30, 40x40, 50x50
```

### 6. ファイル名対象外の場合は勝手に難易度変更しない

対象外のJSONファイルを読み込んだ場合、難易度は自動変更しない。

ただし、読み込んだパズルデータに `difficulty`、`w`、`h` があり、既存仕様としてそれを反映している場合は、既存仕様を壊さない。

今回の主目的は「固定ファイル名で読み込んだ時のみ、難易度と盤面サイズ候補を確実に連動させること」。

### 7. UI表示と内部状態を一致させる

ドロップダウン表示だけでなく、内部状態も同期する。

確認対象:

```text
- state側の難易度
- state側の盤面サイズ
- エディタの現在スロット
- パズル名
- モノクロ / カラー種別
- 面数
```

見た目だけ変わって内部状態が変わっていない状態は禁止。

### 8. 読込結果メッセージに反映する

対象ファイル名で連動した場合:

```text
beginner.json を読み込みました。難易度と盤面サイズ候補を自動設定しました。
```

対象外ファイルの場合:

```text
JSONを読み込みました。
```

### 9. 既存のJSON読み書きを壊さない

維持する機能:

```text
- JSON読込
- 読み込み済みJSONスロット表示
- スロット読込
- スロット保存
- 空きへ追加
- 読込ファイル名でJSON出力
- 別名でJSON出力
- エディットプレイ
- モノクロ / カラー切り替え
```
