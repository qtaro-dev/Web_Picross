# チケット41: ゲーム中タイトル表示とセレクト画面ステージ表示の整理

## 目的

ゲームプレイ中の盤面上部に、現在はパズル作成時のタイトルが表示されている。

例:

```text
クロス (5×5)
```

しかし、ゲーム中に表示したいのはパズル名ではなく、現在の難易度と面数である。  
そのため、ゲーム中のタイトル表示を以下の形式へ変更する。

```text
Beginner #01
Easy #01
Normal #01
Hard #01
Endless #01
```

また、この表題は角丸四角形で囲う。

さらに、ゲームセレクト画面のステージ表示について、未クリア時とクリア済み時で表示を分ける。

```text
未クリア:
#01

クリア済み:
#01 クロス
```

クリア済みの場合のみ、ステージナンバーに加えてパズル名を表示する。

- `E:\Dev\web_picross_Ver2\js\render.js`

## 実装内容

### 1. ゲームプレイ中のタイトル表示を変更する

ゲーム画面の盤面上部に表示されているタイトルを、パズル作成時タイトルではなく、難易度と面数に変更する。

変更前:

```text
クロス (5×5)
```

変更後:

```text
Beginner #01
```

表示形式:

```text
<難易度英名> #<2桁面数>
```

例:

```text
Beginner #01
Beginner #12
Easy #03
Normal #20
Hard #05
Endless #01
```

注意:

- 面数は2桁ゼロ埋めにする
- `stageNo` が存在する場合は `stageNo` を使う
- `stageNo` が存在しない場合は、既存の表示番号を使う
- 難易度英名は既存のdifficulty値から変換する
- パズル名はゲーム中タイトルには表示しない

### 2. ゲーム中タイトルを角丸四角形で囲う

ゲーム中タイトルは、既存テーマに合わせた角丸四角形の枠で囲う。

表示イメージ:

```text
┌────────────────┐
│ Beginner #01   │
└────────────────┘
```

CSS要件:

```text
- 角丸
- 既存ボタンやパネルと同じトーンの枠線
- 黒背景 / 白文字
- 中央揃え
- 盤面と重ならない
```

### 3. ゲーム中タイトル周りの余白を調整する

タイトル文字を角丸四角形で囲うため、左右と上下のスペースを少し広げる。

調整対象:

```text
- タイトル枠の左右padding
- タイトル枠の上下padding
- タイトル枠と盤面の間隔
- タイトル枠と左右パネルの干渉
```

注意:

- 5x5、5x10、10x5、10x10、20x20などで破綻しない
- 小さい盤面でも窮屈に見えない
- 大きい盤面でもタイトルが盤面に被らない

### 4. パズルセレクトのステージ表示を変更する

ゲームセレクト画面のパズルパネル下にあるステージ表示を、クリア状態によって切り替える。

未クリア時:

```text
#01
#02
#03
```

クリア済み時:

```text
#01 クロス
#02 はな
#12 階段
```

注意:

- 未クリア時はパズル名を出さない
- クリア済み時だけパズル名を出す
- クリア済み判定は現在ログイン中ユーザーのクリアフラグを参照する
- 他ユーザーのクリア状態を混ぜない
- サムネイル表示条件と同じクリア判定を使う

### 5. セレクト画面のステージ表示に余白を追加する

パズル名が追加されると文字が長くなるため、ステージ表示部分の左右・上下スペースを広げる。

調整内容:

```text
- パネル下部のラベル幅を少し広げる
- ラベルの左右paddingを追加
- ラベルの上下paddingを追加
- 長いパズル名は省略表示または折り返し制限
```

候補:

```css
text-overflow: ellipsis;
white-space: nowrap;
overflow: hidden;
```

注意:

- `#01 クロス` が読みやすいこと
- 未クリアの `#05` だけ表示でも位置が不自然にならないこと
- 隣のパネルと重ならないこと

### 6. クリア後にセレクトへ戻った場合の表示更新

ゲームをクリアしてセレクト画面へ戻った場合、その面だけ表示が更新される。

期待動作:

```text
クリア前:
#01

#01をクリア
→ セレクトへ戻る
→ #01 クロス
```

合わせて、クリア済みサムネイルとCLEARバッジも既存仕様どおり表示される。

### 7. パズルタイトルの扱いを整理する

パズルタイトルは、以下の用途に限定する。

```text
ゲーム中:
- 表示しない

ゲームセレクト未クリア:
- 表示しない

ゲームセレクトクリア済み:
- ステージ番号の後ろに表示する

ユーザーデータ画面:
- 必要なら表示してよい

エディタ:
- 編集項目として表示する
```

### 8. 難易度表記の変換を統一する

ゲーム中タイトルで使う難易度英名を統一する。

変換例:

```text
beginner → Beginner
easy → Easy
normal → Normal
hard → Hard
endless → Endless
```

日本語UIのままにしたい箇所は既存仕様を維持する。  
今回のゲーム中タイトルは、指定どおり英名表記にする。
