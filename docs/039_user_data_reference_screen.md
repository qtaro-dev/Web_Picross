# チケット39: ユーザーデータ参照画面の追加とメニュー画面ヘッダー整備

## 目的

ログイン中ユーザーのユーザーデータを画面上で確認できる専用画面を追加する。

メニュー画面上部に表示されているアカウント名、例 `admin` の右側に「ユーザーデータ」ボタンを追加し、そこからユーザーデータ画面へ遷移できるようにする。

また、現在のメニュー画面には「メニュー画面」などの画面タイトルがないため、一番上にヘッダーとして画面タイトルを追加する。

## 対象ファイル（推定）

- `E:\Dev\web_picross_Ver2\js\state.js`
- `E:\Dev\web_picross_Ver2\js\actions.js`
- `E:\Dev\web_picross_Ver2\js\render.js`
- `E:\Dev\web_picross_Ver2\js\main.js`
- `E:\Dev\web_picross_Ver2\js\userData.js`
- `E:\Dev\web_picross_Ver2\styles.css`

## 画面遷移仕様

### 1. メニュー画面からユーザーデータ画面へ遷移する

メニュー画面上部のアカウント名表示の右側に「ユーザーデータ」ボタンを追加する。

配置イメージ:

```text
[メニュー画面]

admin  [ユーザーデータ]

[ゲームセレクト]
[ランキング]
[オプション]
[ヘルプ]
[クレジット]
[エディタ]
[ログアウト]
```

画面遷移:

```text
アカウント名 admin の右の「ユーザーデータ」をクリック
→ ユーザーデータ画面へ遷移
```

### 2. ユーザーデータ画面からメニュー画面へ戻る

ユーザーデータ画面の左上に「← 戻る」ボタンを設置する。

画面遷移:

```text
ユーザーデータ画面
→ 左上の「← 戻る」
→ メニュー画面へ戻る
```

注意:

- ブラウザバックに頼らない
- 既存のメニューへ戻る導線と同じ見た目にする
- 戻る先はログイン後のメニュー画面

### 3. メニュー画面にヘッダーを追加する

メニュー画面の一番上に画面タイトルとして「メニュー画面」を表示する。

表示例:

```text
メニュー画面
```

注意:

- 既存テーマに合わせる
- アカウント名表示と重ならない
- 他画面にもタイトルが必要な場合は、共通ヘッダー化してもよい

## ユーザーデータ画面の表示内容

### 1. 基本情報

ユーザーデータ画面には、ログイン中ユーザーの基本情報を表示する。

表示項目:

```text
- ユーザー名
- ユーザーID
- 作成日時
- 最終更新日時
- 保存方式
- ユーザーデータファイル名または保存キー
```

例:

```text
ユーザー名: admin
ユーザーID: user_admin
保存方式: userフォルダJSON
ユーザーファイル: user/admin.json
```

Live Server時:

```text
保存方式: localStorage
保存キー: picross_v2_user_data
```

### 2. 難易度別クリアデータ

難易度別にクリア状況を表示する。

対象難易度:

```text
- ビギナー
- イージー
- ノーマル
- ハード
- エンドレス
```

表示項目候補:

```text
- クリア数
- プレイ数
- 失敗数
- ギブアップ数
- 合計プレイ時間
- ベストタイム
```

表示例:

```text
ビギナー
クリア数: 3
プレイ数: 5
失敗数: 1
ギブアップ数: 1
合計プレイ時間: 00:18:24
ベストタイム: #1 00:42
```

### 3. 各面ごとのクリアフラグとタイム

各面ごとの進行状況を確認できるようにする。

表示項目:

```text
- 難易度
- 面番号
- パズルID
- クリア済み / 未クリア
- クリアタイム
- ベストタイム
- クリア日時
- ギブアップ回数
- 失敗回数
```

表示形式は表形式が望ましい。

例:

```text
| 難易度 | 面 | 状態 | ベストタイム | 最新タイム | ギブアップ | 失敗 |
|---|---:|---|---:|---:|---:|---:|
| ビギナー | #1 | クリア | 00:53 | 01:10 | 0 | 0 |
| ビギナー | #2 | 未クリア | - | - | 1 | 0 |
```

### 4. ゲームプレイ時間

ユーザー全体のゲームプレイ時間を表示する。

表示項目:

```text
- 合計プレイ時間
- 難易度別プレイ時間
- 最新プレイ時間
```

注意:

- チケット34のモーダル中停止時間は含めない
- クリア・失敗・ギブアップ時に記録されたプレイ時間を集計する
- エンドレスは制限時間なしでもプレイ時間に含める

### 5. ギブアップ回数

ユーザー全体と難易度別、各面ごとのギブアップ回数を表示する。

表示項目:

```text
- 合計ギブアップ回数
- 難易度別ギブアップ回数
- 各面ごとのギブアップ回数
```

### 6. 失敗回数

ゲーム失敗時の回数も表示する。

表示項目:

```text
- 合計失敗回数
- 難易度別失敗回数
- 各面ごとの失敗回数
```

### 7. JSON出力ボタンを設置する

ユーザーデータ画面内に、現在ユーザーのデータをJSON出力できるボタンを設置する。

ボタン名候補:

```text
ユーザーデータJSON出力
現在ユーザーJSON出力
```

期待動作:

```text
クリック
→ admin.json または user_admin.json をダウンロード
→ 開くと整形JSONで読める
```

### 8. ユーザーデータ再読込ボタンを設置する

Node.jsサーバやlocalStorageから、現在ユーザーのデータを再読込するボタンを設置する。

ボタン名候補:

```text
ユーザーデータ再読込
```

期待動作:

```text
クリック
→ 現在ユーザーの最新データを読み直す
→ 画面表示を更新
```

### 9. データなしの場合の表示

新規ユーザーなど、まだプレイ記録がない場合は、空表示でなく分かりやすいメッセージを出す。

表示例:

```text
まだプレイ記録がありません。
ゲームをクリア、失敗、またはギブアップすると記録されます。
```

### 10. 既存導線を壊さない

以下を維持する。

```text
- タイトル
- ログイン
- メニュー
- ゲームセレクト
- ランキング
- エディタ
- ログアウト
```
