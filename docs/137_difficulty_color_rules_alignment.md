# チケット137：難易度別カラー可否の仕様整合

## 目的

コードレビューで、過去仕様では Beginner / Easy がモノクロのみである一方、現在の `DIFFICULTY_RULES` では `color: true` になっている可能性が指摘された。

難易度別のサイズ・カラー可否ルールを再確認し、エディタ、アップロード、通常プレイの仕様が一致するように整理する。

## 対象ファイル（推定）

- `js/config.js`
- `js/editor.js`
- `js/actions.js`
- `js/render.js`
- `docs/006_difficulty_board_rules.md`
- `README.md`
- `docs/ticket_status.json`

## 実装内容

### 1. 現行仕様を確認する

- Beginner / Easy / Normal / Hard / Endless のカラー可否を確認する。
- 過去仕様と現在仕様が異なる場合、どちらを採用するか明記する。
- ユーザー意図として、Beginner / Easy はモノクロのみでよいか確認済みの前提で進める場合は、READMEへ記載する。

### 2. DIFFICULTY_RULESを修正する

- Beginner / Easy をモノクロのみとする場合、`color: false` に戻す。
- Normal / Hard / Endless のカラー可否は既存仕様に合わせる。
- サイズ制限も既存ルールとズレがないか確認する。

### 3. エディタとアップロード検証を合わせる

- エディタで難易度別に選べるカラー種別が仕様と一致するようにする。
- JSONアップロードやパズル管理で、難易度別カラー可否を検証する。
- Beginner / Easy にカラー問題をアップロードできないようにする、または自動拒否する。
- 拒否時は分かりやすいエラー表示にする。

### 4. 既存データへの影響を確認する

- 既存のBeginner / Easyデータにカラー問題がないか確認する。
- もし既存データに仕様外カラー問題がある場合は、扱いを明記する。
  - 修正する
  - 非公開にする
  - 例外扱いにする
- 既存の正規問題が壊れないようにする。

## 受け入れ条件（目視確認基準）

### Beginner / Easy

- Beginner / Easyの問題選択やエディタを確認する。
- OK：モノクロのみ扱えること。
- NG：仕様外のカラー問題を作成・アップロードできること。

### Normal / Hard / Endless

- Normal / Hard / Endlessの問題選択やエディタを確認する。
- OK：既存仕様どおりカラー問題を扱えること。
- NG：本来カラー可能な難易度までカラー不可になること。

### アップロード検証

- Beginner / Easy向けにカラーJSONをアップロードする。
- OK：エラー表示され、反映されないこと。
- NG：仕様外カラー問題が登録されること。

### 回帰確認

- 既存のモノクロ問題を開く。
- 既存のカラー問題を開く。
- OK：仕様内の既存問題は従来どおり遊べること。
- NG：仕様修正により正規問題まで壊れること。
