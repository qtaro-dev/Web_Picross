# チケット90fix1：管理者ページの状態ボタン高さ揃え修正

## 背景

チケット90で管理者ページのユーザー詳細エリアにある `状態: 利用停止` 表示のサイズ調整を行った。

しかし、修正後も `状態: 利用停止` ボタンの高さが `ユーザー情報保存` ボタンや `利用停止解除` ボタンと完全には揃っていない。

ユーザー詳細の上段操作エリアでは、入力欄・権限セレクト・状態表示・操作ボタンが横並びになるため、各要素の高さが揃っていないとレイアウトが不自然に見える。

## 現在の問題

管理者ページのユーザー詳細エリアで、以下の要素の高さが揃っていない。

```text
状態: 利用停止
ユーザー情報保存
利用停止解除
```

特に `状態: 利用停止` が他の操作ボタンより低く、横並びの見た目が揃っていない。

## 期待する動作

`状態: 利用停止` の表示高さを、隣接する操作ボタンと同じ高さに揃える。

基準にする要素:

```text
ユーザー情報保存
利用停止解除
```

期待する見た目:

```text
表示名入力欄
権限セレクト
状態: 利用停止
ユーザー情報保存
利用停止解除
```

これらが横並びになったとき、ボタン・状態表示の高さと縦位置が自然に揃っていること。

## 対象ファイル

推定対象:

```text
styles.css
js/admin.js
README.md
docs/ticket_status.json
```

主に確認する箇所:

```text
管理者ページのユーザー詳細エリア
状態バッジ / 状態ボタン / 利用停止表示のCSS
ユーザー情報保存ボタンのCSS
利用停止解除ボタンのCSS
```

## 実装内容

### 1. 状態表示の高さを操作ボタンと揃える

`状態: 利用停止` の表示要素について、`ユーザー情報保存` ボタンと同じ高さになるようCSSを調整する。

調整候補:

```text
height
min-height
padding
line-height
align-items
box-sizing
```

既存のボタンスタイルがある場合は、可能な限り同じ共通クラスまたは同等の指定を使う。

### 2. 縦位置も揃える

高さだけでなく、横並び時の縦位置も揃える。

親要素がflexの場合は、必要に応じて以下を確認する。

```text
align-items: end;
align-items: flex-end;
align-items: center;
```

ただし、表示名入力欄や権限セレクトとの既存レイアウトを崩さないこと。

### 3. 状態表示を過度に大きくしない

`状態: 利用停止` は操作ボタンではなく状態表示なので、幅は必要最小限にする。

ただし、高さは操作ボタンと揃える。

### 4. 他の状態表示にも影響を確認する

`状態: 通常` など、他の状態表示がある場合も、同じレイアウトで崩れないことを確認する。

## 受け入れ条件

### 利用停止ユーザーを選択した場合

管理者ページで `account_status = disabled` のユーザーを選択する。

期待結果:

```text
状態: 利用停止 の高さが ユーザー情報保存 ボタンと揃っている
状態: 利用停止 の縦位置が ユーザー情報保存 ボタンと揃っている
利用停止解除 ボタンとも高さ・縦位置が揃っている
```

### 通常ユーザーを選択した場合

管理者ページで `account_status = active` または通常状態のユーザーを選択する。

期待結果:

```text
状態表示がある場合は同じ高さで表示される
ユーザー情報保存ボタンのレイアウトが崩れない
不要な余白や巨大化が発生しない
```

### 既存機能

期待結果:

```text
ユーザー情報保存が通常通り動作する
利用停止解除が通常通り動作する
管理者ページのユーザー一覧・ユーザー詳細表示が壊れない
```

## メモ

このチケット90fix1では、機能追加は行わない。

対象は管理者ページのユーザー詳細エリアにある `状態: 利用停止` 表示の高さ・縦位置調整のみ。
